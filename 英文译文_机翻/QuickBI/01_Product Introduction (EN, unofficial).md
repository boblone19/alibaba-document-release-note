# Quick BI — Product Introduction

> **Note on this file.** The international documentation portal has **never published an English Quick
> BI manual for Apsara Stack** (including V3.18.6). This document is an unofficial English translation
> of the Chinese V3.18.6 manual (product version `v3.18.6-SP2607`, document date 2026-07-29), for
> internal reading only. The Chinese source title reads "BI 产品简介"; the body refers to Quick BI.

Quick BI's mission is **to let everyone consume data in all scenarios and make business decisions
within reach**. Through intelligent data analysis and visualization, it helps enterprises build data
analysis systems: users can create dashboards, complex-format spreadsheets, and data portals with a
clear analytical storyline. Quick BI also provides intelligent data modelling tools that greatly
reduce the cost and the barrier to obtaining and using data. With drag-and-drop operations and rich
visualization chart controls, users can easily complete pivot analysis, self-service data extraction,
business data exploration, report creation, and data portal building. Quick BI is more than a tool for
business staff to view data — it turns everyone into a data analyst and helps enterprises achieve
data-driven operations.

## Product details

Quick BI provides rich data source connectivity with a built-in high-speed data cloud computing
engine that computes and responds to hundreds of millions of records in seconds; it provides rich
visualization components, flexible and intelligent analytical capability and spreadsheets, and offers
a data sharing system of portals, self-service extraction and data entry forms to lower the barrier to
using data; it also provides organisation and permission management and row/column-level data
permissions for fine-grained data access control.

**Data sources**

Adapts to various cloud data sources — including MaxCompute, HybridDB for MySQL, AnalyticDB for
PostgreSQL and AnalyticDB — and encapsulates standard query interfaces for the metadata and the data
of these sources.

**Data modelling**

Handles the OLAP modelling process of data sources, turning them into multi-dimensional analysis
models that support standard semantics such as dimensions (date dimensions and geo-spatial
dimensions), measures and star-schema models, and supports calculated fields so users can further
process dimensions and measures with the SQL syntax of the current data source.

**Data analysis**

*Dashboards* — assembles visualization chart controls into dashboards. Supports line charts, pie
charts, bar charts, funnel charts, tree maps, bubble maps, colour maps, indicator dashboards and more;
supports five basic controls (query conditions, TAB, embedded pages, images and text boxes); supports
data linkage between charts.

*Spreadsheets* — provides online workbook operations, covering row/column filtering, normal or
advanced filtering, subtotals, auto-sum and conditional formatting, and supports data export plus text
and table processing.

*Ad-hoc analysis* — aimed at front-line business staff, providing drag-and-drop table analysis so
that people who understand the business can analyse data themselves. **Note**: in Apsara Stack,
ad-hoc analysis is a value-added module that must be purchased separately according to business needs.

**Data application**

*Data portals* — assembles dashboards into data portals, supporting embedded links (dashboards) and
external links (third-party URLs), with basic settings for templates and menu bars.

*Self-service data extraction* — downloads report data to a local machine or a server for further
processing or analysis. IT support staff can define metrics on Quick BI datasets, and other business
staff can extract data by dragging fields; this removes the backend data extraction and processing
work of IT staff and improves the efficiency of ad-hoc data requests. **Note**: in Apsara Stack,
self-service extraction is a value-added module that must be purchased separately and requires extra
machine resources; purchase according to business needs.

*Data entry forms* — provides online data collection so enterprises complete data reporting in one
place, with rich form components, batch upload, data management and review, flexible drag-and-drop
layout, and a secure data permission system — for example, warehouse stock-in/stock-out management
where every transaction is entered for inventory counting and historical traceability. **Note**: in
Apsara Stack, data entry forms are a value-added module that must be purchased separately according to
business needs.

**Organization and permission control**

*Organization permission management* — a two-level permission architecture of organization management
and workspace management, plus the user role system within a workspace, implementing basic permission
control so that different people can see different content in the same report.

*Row-level permission management* — row-level data access control, so that different people can view
different data in the same report.

*Sharing and publishing* — spreadsheets, dashboards and data portals can be shared with other users,
and dashboards can be published to the Internet for non-signed-in viewers.

## Product advantages

Quick BI helps customers complete data analysis, business data exploration and report creation with
ease, helps enterprises build a top-down decision analysis system, makes data assets flow faster, and —
by combining BI with AI — uncovers the value behind data, deepening and accelerating data consumption
across enterprise scenarios.

| Perspective | Value |
|---|---|
| IT department | Converges data platforms, unifies metric definitions, reduces duplicated work, shortens response time, and focuses on underlying data modelling. |
| Business departments | Flexible self-service analysis, more time to insight into business problems, quick iteration in response to business change, building a business analysis system, and data supporting fast business operation. |
| Enterprise management | Grasps the operating state of the enterprise, adjusts strategy execution in time, empowers efficiency upgrades, shapes core competitiveness, and uncovers possibilities for sustained growth. |

## Scenarios

**Everyone is a data analyst** — benchmarked against IBM Cognos, self-service analysis supports
low-barrier drag-and-drop exploration of hundreds of millions of records, letting the business merge
and split any rows and columns for component-based analysis with great self-service flexibility. Used
for exploring uncertain questions, flexible statistical analysis during meetings, and the fast
creation and change of reports in fast-moving business scenarios.

**Building a business analysis system and productising data** — with rich visualization components,
portal features and interactions, data products can be created to make analysis systematic,
automated and productised.

**From people looking for data to data finding people** — quickly build the enterprise data analysis
system: connect rich data sources, build analytical models and dashboards, and distribute them to the
business side through data portals.
