# 云安全中心（态势感知） 云安全管理中心产品简介

## 什么是云安全管理中心

阿里云安全-云盾-云安全管理中心（Aliyun Yundun Cloud Security Operations Center，简称SOC）是阿里云原生的一体化安全管理中心，适用于混合云和专有云环境的整体安全运营管理，可以围绕SOC构建云环境风险预测发现、防御控制、检测分析、响应管理的闭环安全运营体系，通过SOC实现专有云网络环境的高风险威胁发现、深度溯源取证、综合安全评估、可视化监控、自动化响应处置、云资产接入管理、场景化运营等安全能力，支撑混合云和专有云的安全运营工作。

## 产品优势

本文介绍云安全管理中心的产品优势。

**全量数据采集，消除监控盲区**

通过多种方式采集云盾安全网元、第三方网元的数据，供运营中心、态势监控、风险分析使用，从多维度呈现资产中的安全风险。

**综合关联分析，打破信息孤岛**

通过关联检索聚合分析、攻击场景关联分析、攻击联想关联分析、威胁情报管理分析和业务场景关联分析，完成风险信息的过滤、归并、提炼、关联，降低安全分析技术门槛，屏蔽由于分析方法、逻辑、经验的不同所造成的安全风险判定的有效性，从而提升云安全运营效率。

**云原生中心，云内资产全面监控**

绘制云主机及虚拟实例资产风险画像，进行资产风险全面评估。从安全漏洞、云外暴露、安全基线、网络攻击、资产行为、异常行为等方面为资产提供风险画像。

**自动化响应编排，一体化安全运营**

通过智能编排，把人、过程和技术整合起来，提升安全运营工作效率。在收到安全告警时，可以一键下发联动策略，快速处置安全风险。

**数据采集层**

主要为SOC采集获取数据源原始日志或告警数据的处理逻辑，其中云盾安骑士、云防火墙、Web应用防火墙、流量安全监控等安全网元的原始日志和安全告警数据通过MetaQ、SLS、RDS、API等数据通道完成采集获取，其他第三方安全网元则是通过Syslog和SLS协议完成原始数据的采集获取。

**数据整理层**

主要为SOC针对所有采集获取的原始数据进行统一预处理的逻辑，包括数组数据拆分、无效数据过滤、数据格式解析、标准化字段映射、数据去重归并以及数据标记等处理，从而完成原始数据的规范化处理，支撑进一步的大数据挖掘、分析、存储等处理逻辑。

**数据分析层**

主要为SOC针对预处理后的实时流数据和非实时离线数据的分析处理逻辑，实时流数据通过MetaQ消息队列同步到Dipper流数据分析处理引擎，以完成规范化数据的机器学习、数学建模和行为分析等数据分析处理逻辑，非实时离线数据通过定时任务，基于安全分析模型进行离线数据的图计算、关联分析、风险判定等数据分析处理。

**数据存储层**

主要为SOC进行规范化数据和分析结果数据的分布式存储逻辑，规范化数据作为热数据存储于SLS中，以支撑数据统计、数据查询、数据挖掘的数据应用消费，基于流式数据和离线数据分析后新产生的结果数据、资产信息数据作为冷数据存储于RDS中，以支撑数据消费层的数据分析结果呈现。

**数据消费层**

主要为SOC针对分析处理后的数据消费的应用逻辑，直接面向云安全运营管理者提供数据服务，包括场景化安全运营、云安全态势监控、网络风险分析、风险响应编排、云主机资产管理、日志管理和数据报表等，支撑安全运营管理者完成云环境的一系列安全运营工作。

## 应用场景

SOC广泛适用于政府、金融、能源、央企、各大部委等行业云、政务云、混合共建云的安全体系建设，支撑各行各业的云计算网络环境的场景化运营。

**全局统一安全运营**

在数字化转型驱动业务上云和护网行动场景下，为了保障业务持续、稳定、安全发展，势必存在生态化的网络安全体系。因此，需要一个一体化的云环境网络运营中心来整合安全生态中各个安全网元的数据信息，以进行具备全局视野的整体安全运营。

**高级持续性威胁检测及处置**

在以政治和经济获益为目的的驱使下，网络攻击将会持续存在且不断变化，需要同时应对传统信息安全风险和云环境网络的新型网络威胁，高级持续性威胁具有针对性强、隐蔽性强、持续时间长、组织系统化的特点，需要充分利用新兴网络安全技术，并能够基于单点信息进行综合关联分析的判断，快速完成安全策略部署，以进行安全风险的发现和处置。

**云环境资产风险管理**

在企业或机构的核心业务上云以后，需要面向互联网提供持续的、高质量的、安全的业务服务，因此，针对承载核心业务的云主机资产和虚拟化资产的运行状态、网络状态、安全状态等维度的监控管理变得至关重要。

**租户运营安全监管**

云租户作为一个相对独立的VPC，其内部对云上计算资源的应用风险，会给云平台和其他云租户带来相应的安全隐患。因此，云租户需要对自身的安全负责，同时云平台运营方在进行自身安全运营管理的基础上，仍然需要对云租户的资产和业务风险进行监管和控制，以保障云平台和其他云租户的网络安全。

**网络及安全日志集中审计**

在现行的网络安全体系中，存在多个安全厂商、多种类型安全产品的情况，一方面满足政策性、合规性等监管要求，需要对网络安全日志进行集中审计并存储180天以上；另一方面，在安全左移的技术趋势下，同样需要对各业务系统的日志进行存储和备份，以防止被篡改和删除。
