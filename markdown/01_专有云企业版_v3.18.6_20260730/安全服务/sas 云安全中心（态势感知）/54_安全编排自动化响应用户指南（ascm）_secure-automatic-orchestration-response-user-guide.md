## 安全编排自动化响应 SOAR

### 风险处置

#### 案件管理

案件管理用于集中管理和调查安全事件。本文介绍如何查看案件信息、创建案件、调查案件、查看案件统计情况。

**概述**

案件可以是SOC告警事件自动生成，也可以是用户手动创建。 SOC告警事件自动生成订阅SOC攻击防护和安全告警消息后，收到对应的告警时，SOAR会读取SOC告警的详细信息，并生成一个新的案件： 案件名称为SOC中告警事件的名称，或攻击防护事件的名称。 案件状态为SOC告警事件状态。 创建时间为SOC告警事件上报时间。 创建人为事件创建租户账号名称。 用户手动创建用户可以根据实际业务，创建有针对性的案件。更多信息，请参见创建案件。

**查看案件统计情况**

1. 登录Apsara Uni-manager运营控制台。
2. 在控制台右上方，单击**安全**，选择**安全管理** > **安全编排自动化响应****SOAR** 。在**安全编排自动化响应**
**SOAR**授权页面，选择**地域**并单击**角色授权访问**。
3. 在左侧导航栏，选择**风险处置** > **案件管理**。
4. 在**案件管理**页面，查看案件统计情况。

| 功能 | 描述 |
|---|---|

| 新增案件 | 用于统计当前阿里云账号新增的案件数。 |
|---|---|
| 待处置案件 | 当前阿里云账号需要安全管理员关注和进一步处理的案件的数量。 |
| 自动响应案件 | 展示当前阿里云账号统计周期内自动响应的案件数量。 |
| 自动封禁威胁数 | 展示当前阿里云账号今天、本周已经通过剧本自动封禁的威胁数量。 |
| 案件列表 | 在案件管理页面的案件列表，查看案件详情。 搜索案件：通过设置搜索条件，可以查看符合条件的案件信息。 删除案件：单击指定案件的删除，即可在案件列表中删除选定案件。 快速设置案件状态为已处置：单击指定案件的设为已处置，即可将案件状态列显示为已处置。 批量修改案件状态：选中多个案件，单击案件列表下方的修改状态，选择要修改的状态。 |

**创建案件**

在**案件管理**页签，单击**新建**，完成如下配置后，单击**确定**。

| 配置项 | 说明 |
|---|---|
| 所属组织 | 下拉列表选择案件所属组织。 |
| 案件名称 | 输入需要新建的案件名称。最大为128个字符，支持中英文数字，可包含半角句号（.）、 下划线（ ）、短划线（-）、括号（（））和空格（ ）等。 _ |
| 案件状态 | 单击下拉列表，选择该案件所处的状态。 |
| 备注 | 设置案件备注信息。 |

**调查案件**

创建案件后，可在案件详情中，对安全事件展开调查、分析和取证。
1. 定位到目标案件，单击**操作**列的**详情**。
2. 在案件详情页面，查看并配置案件基础信息。
支持查看所属组织、案件状态、优先级、指派人、案件ID、案件来源、创建人、案件UUID、更新时间、 备注等信息。 支持配置案件名称、案件状态、优先级、指派人、备注等信息。
3. 在**相关实体**页签，设置要提取的实体。

**说明**

用户也可以通过在剧本中使用EventHouse组件并执行该剧本，自动将剧本中的实体添加到相关实体中。如何查看组件详情，请参见组件列表；如何创建剧本，请参见剧本列表。 单击**新增**，配置**监测实体**、**实体类型**、**处置状态**。

**说明**

实体是指某一种固定类型的数据，此处实体类型有：
**服务器****IP**、**主机名**、**应用名**、**域名**、**数据库**、**cna**、**文件****hash**、**进程**、**AccesskeyID**、邮
箱、**Aegis****文件**、**文件****MD5**。 单击**设置**，配置**自动生成关联实体**（IP等）、**实体类型**。
4. 在**构成要素**页签，单击**添加要素**。在**添加要素**对话框，完成如下配置后，单击**确认**。

| 配置项 | 说明 |
|---|---|
| 要素内容 | 将已添加的相关实体添加到要素内容作为构成要素的内容。仅支持JSON格式。 |
| 标签 | 设置要素标签。 |

用户可在要素列表查看该要素，并支持以下操作： 以表格或JSON格式，**查看**要素。
**编辑**要素。如果修改了**要素内容**，该变更会同步到**相关实体**中。
将要素**添加为证据**。 用户可以在**研判证据**页签，查看或编辑已添加的证据。同时，用户也可以在**联合作战室**查看添加为证据的信息。 单击**配置表头**，选择相应的key添加至表头。

**说明**

默认表头不可取消。 选中多个要素，单击**批量操作**，批量**添加至案件**、**更改标签**、**删除**。 单击**添加至案件**，将要素添加到已有案件中。 如果要素已添加到其他案件，将鼠标悬停在**来源**列的消息图标上，可查看并跳转到对应案件。 成功添加要素后，当满足案件要求的安全事件发生时，系统将在**案件保留周期**和**案件实体归并周期**内，第一时间将安全事件加入到**联合作战室**，并开始案件的调查处置，案件相关的信息会显示在作战室中。安全分析员可以将事件中的相关恶意指标加入情报中持续监控，并通过**操作记录**查看在事件调查和响应过程中执行过的所有操作的记录。

**说明**

用户也可以通过在剧本中使用EventHouse组件并执行该剧本，自动将剧本中的要素添加到构成要素中。如果自动添加的要素与手动添加的要素重复，系统会自动去重。如何查看组件详情，请参见组件列表；如何创建剧本，请参见剧本列表。
5. 用户也可以在**联合作战室**页签，定位到目标案件，手动在消息文本框内输入@**贾维斯**和指令，或单击**执行**
**剧本**/**动作**，选择并配置**标准动作**、**云内动作、剧本**，然后单击**确定**。
通过**执行剧本**/**动作**，可带参数进入到联合作战室，并转换为@机器人的内容，即进入作战室之前就通过一系列交互把输入框的最终文本拼好。

**说明**

用户也可以在输入框中@其他成员，对其他人发送消息。 群成员可以支持多人在联合作战室中协同工作，发送消息、共享安全告警信息和事件调查的结果，实现安全事件的协同处置。 系统将在文本框返回执行结果。
6. 在**操作记录**页签，查看在案件调查和响应过程中执行过的所有操作的记录。
7. 在**研判证据**页签，针对证据展示可人工录入、编辑、删除等操作。

#### 剧本列表

剧本管理自动化编排通过将安全运营日常工作自动化、流程化，提升安全响应速度，简化安全专家的日常工作，集中精力对抗高级持续攻击APT（Advanced Persistent Threat）。安全运营的日常工作可编译为可视化、可解释、可执行的剧本沉淀在产品中，更利于运营经验的传承。本文介绍如何查看、创建和编辑剧本。

**新手引导**

首次进入**剧本列表**页面时，系统提供快速入门指导。您可以通过新手引导、使用模板、直接编排方式创建剧本。

**新手引导**

新手引导提供步骤向导式配置指导，逐步完成剧本设定。只有在剧本成功发布之后，才能进行调试和运行操作。 打开新手引导的**不再提醒**后，再次进入**剧本列表**页面时，系统不会再弹出快速入门向导。在**剧本列表**页面的右上角，单击**快速入门**可以再次进入向导对话框。

**使用模板**

若需通过模板创建剧本，请参见通过模板创建剧本的相关说明，借助预设模板能够高效地构建剧本内容。

**直接编排**

若选择直接创建剧本，请参见创建剧本中的详细教程，实现从零开始创建剧本。

**内置**类型剧本是指系统预设的剧本，用户亦可通过复制内置剧本来创建自定义剧本。

**重要**

建议使用剧本模板来创建自定义剧本，内置剧本将不再维护。
**全局共享**类型剧本仅支持在安全编排自动化响应SOAR平台侧创建，并且当**全局共享**类型剧本的应用范
围为**租户**时，创建后会自动同步到租户侧公共剧本列表中。
**自定义剧本**仅支持**私有**类型。

**SOAR**授权页面，选择**地域**并单击**角色授权访问**。

##### 升级中心概述

升级中心通过自动和手动方式，对专有云云盾的特征库和版本进行升级等操作，确保专有云及时获取最新的安全保障。 升级时，用户可以按照如下步骤，进行升级：
1. 配置升级包导入方式。
升级中心支持**在线自动导入**、**离线手动导入**。 专有云环境和公网互通，可以选择**在线自动导入**升级包方式。 统配置专有云环境和公网不通，可以选择**离线手动导入**升级包方式。选择该种方式时，需要下载升级包。
2. 升级特征库、版本。具体操作，请参见升级特征库或版本。

##### 升级特征库或版本

升级中心支持通过离线手动导入、在线自动导入升级包的方式，升级特征库或版本。本文介绍如何进行升级操作。

**操作步骤**

1. 登录云盾运维中心。
2. 在左侧导航栏，单击**升级中心**。
3. 在**升级配置**页签，配置升级包导入方式。

**离线手动导入**

如果专有云环境无法与公网连通，可以通过离线手动导入升级包的方式更新特征库和版本。 a. 选择升级包导入方式为**离线手动导入**，单击**生成升级标识符**，下载升级包。 b. 单击上传导入升级包，将已下载的升级包拖动到上传虚拟框内，或单击图标，上传升级包。

**说明**

上传升级包前，请先单击**手动导入离线升级包**对话框的网站链接，并信任此证书。 升级包导入成功后，用户可在特征库和版本升级页面查看升级包，执行升级操作。

**在线自动导入**

如果专有云环境无法与公网连通，可以通过在线自动导入升级包的方式更新特征库和版本。

**说明**

导入提示： 1、需要云盾产品服务能够访问互联网。 2、申请或使用已有阿里云公有云账号（不建议使用个人账号），该账号将作为在线自动获取升级包的用户标识。 3、配置完成后，将自动获取云盾及相关规则库的最新升级包并自动导入，导入成功后，即可在特征库和版本更新页面查看升级包，执行升级操作。 统配置 a. 选择升级包导入方式为**在线自动导入**，完成如下配置。

| 配置项 | 说明 |
|---|---|
| 阿里云账号ID | 输入阿里云账号ID。 |
| Access Key | 输入Access Key。 |
| Access Secret | 输入Access Secret。 |
| 自动升级时间段 | 选择自动升级的时间段。支持选择： 0~6时 0~8时 0~24时 22~6时 |
| SLB IP | 可以连接公网的SLB的IP地址。 |

b. 单击**连通性测试**。 c. 无问题后，用户可以选择开启**自动更新**开关。 启用**自动更新**后，系统能定期下载升级包。
4. 特征库或版本升级。

**特征库升级**

一键批量升级：在**特征库升级**页签，单击**一键升级**。 单个云盾产品升级：在**特征库升级**页签，定位到需要升级的产品，单击**操作**列的**立即升级**。 升级完成后，云盾产品对应的状态为**升级成功**。用户可以执行如下操作： 如果升级失败，用户可以单击**操作**列的**升级记录**，定位到升级失败的特征库版本，单击操作列的重试。 如果升级成功，用户可以执行如下操作： 在**特征库升级**页签，单击**操作**列的**版本详情**，查看该产品已升级的特征库版本，**重新升级**特征库中的单个规则库。 在**特征库升级**页签，单击**操作**列的**升级记录**，查看该产品已升级的特征库版本。 在**特征库升级记录**面板，单击特征库版**操作**列的**详情**，查看特征库升级包详细信息。单击规则库名称**操作**列的**重新升级**，升级单个规格库。

**版本升级**

一键批量升级：在**版本升级**页签，单击**一键升级**。 单个云盾产品升级：在**版本升级**页签，定位到需要升级的产品，单击**操作**列的**立即升级**。 升级完成后，云盾产品对应的状态为**升级成功**。 如果升级失败，用户可以单击**操作**列的**升级记录**，定位到当前版本中，升级失败的特征库版本，单击操作列的**重试**。 统配置如果升级成功，用户可以执行如下操作： 单击**操作**列的**升级记录**，查看该版本已升级成功的特征库版本，支持**重新升级**和**回滚**。
