# 云安全中心（安骑士） 容器安全产品简介

## 产品概述

**云上安全先行者**

阿里云安全团队自2005年起，致力于保障阿里巴巴集团内部所有业务系统的信息安全。自成立以来，团队面对来自全球的网络攻击，迄今为止未曾失利。近年来，随着云计算技术的持续发展与广泛应用，传统数据中心逐步向云计算架构进行过渡和迁移，各行各业的数字化转型使得业务及数据上云成为必然需求。为确保云服务的安全性，阿里云安全团队于2011年推出云盾产品。随着专有云业务的持续增长，2013年阿里云安全团队发布了首个专有云云盾的正式版本，为专有云及行业云用户提供IaaS层的安全保障能力。 阿里云技术不断发展，阿里巴巴在核心系统全面云原生化方面取得了重大技术突破。基于云原生架构，企业能够最大化利用云的能力，专注于自身业务的发展。同时，开发者也可以依托云原生的技术和产品，提高开发效率，将更多精力集中于业务逻辑的实现。由此可见，云原生技术正逐渐成为释放云价值的最有效途径。 作为云原生发展的基石，容器安全无疑成为攻防技术竞争的焦点。阿里云安全团队基于多年积累的安全技术，以智能化和自动化运营为理念，推出了云盾-容器安全产品。该产品面向阿里云用户，涵盖容器、 Kubernetes及微服务等开发环境，提供PaaS资源/节点资产安全管理、CI/CD风险检测以及容器运行时防护能力，旨在为企业和开发者提供高质量的容器安全保障服务。

**产品定位**

产品中文名：阿里云安全-云盾-容器安全（简称CSS）。 产品英文名：Alibaba Cloud Security-Container Guard Advanced Edition。 容器安全产品（CSS）是针对基于Docker和Kubernetes的安全统一管理运营平台。通过对代码、开发基础设施、供应链及镜像等开发产出物进行自动化安全检测，CSS能够有效降低其脆弱性风险，从而减少开发、 测试和运营团队因安全问题而产生的重复工作，同时减轻安全团队的线上防守压力。在容器运行时安全方面，CSS能够覆盖容器及其基础设施，提供运行时漏洞检测与修复、容器及基础设施异常发现、容器逃逸检测、基于文件与进程的主动防御能力以及威胁溯源等功能，从而有效抵御基于零日漏洞或盲区的黑客入侵。 在容器资产管理领域，容器安全产品能够提供多维度的资产管理功能，包括集群、命名空间、容器组、应用及镜像等视角。用户可根据实际业务部署的形态，选择适合的视角对Kubernetes全局资产进行安全管理。 此外，结合丰富的风险统计和趋势报表，用户能够快速而精准地掌握庞大容器集群的实时安全状态，进一步协助管理集群的安全水平。 在应用全生命周期安全层面，云盾容器安全的目标是协助用户实现DevSecOps，赋予DevOps每个环节自动化且易用的安全检测方法，使各个团队能够获得安全能力，降低安全左移的阻力。确保已知的安全隐患在前置环节能够得到有效收敛，从而降低容器化环境与业务应用的安全风险及修复成本。 Code、Build：容器安全提供对代码仓库进行安全扫描的能力。通过安全引擎的更新触发和定时触发等扫描机制，能够对构建过程中的应用代码、开源组件、基础镜像、供应链和基础设施等进行安全扫描，检测其中可能存在的风险插件/中间件、恶意文件及基础镜像漏洞等问题，从而有效减少开发过程中产生的安全隐患，提高研发效率。 Test：基于应用被动插桩技术，容器安全能够实现应用安全灰盒测试。插桩技术对应用内部数据流进行实时监控，结合动态五点分析技术（DTA），在程序运行时对标记污点的传播过程进行动态跟踪，从而能够准确判断代码是否存在安全漏洞，实现代码的动态安全检测。 Release、Deploy：容器安全镜像安全扫描服务能够持续对镜像仓内的镜像进行安全水位监控，检测其中包含的基线风险、系统漏洞、应用漏洞及恶意文件等问题。此外，通过镜像可信签名功能，系统可以验证传输到宿主机的镜像是否为可信镜像，从而严格管控镜像仓与宿主机之间的镜像传输过程的安全性。 Operate、Monitor：容器安全通过Agent插件在K8s集群节点层面实现对K8s环境、资源、节点和容器的安全监控，并对文件、进程、网络等要素进行全程监控和分析。容器运行时防护策略和数据源源自于多年的积累，依托阿里云平台，服务于超过百万级的用户，每天面临多达几十万次的各类攻击。阿里云安全团队对公共云上每日产生的超过10TB的安全数据进行深入分析，构建恶意IP库、恶意行为库、恶意样本库、安全漏洞库等基础安全能力。

**应用场景**

云盾容器安全产品广泛应用于政府、金融、能源、央企及各大部委等行业的云计算、政务云、XC云及混合共建云的安全体系建设，支撑各行各业的云容器安全管理与运营。

**CI/CD自动化安全检测**

从开发提交代码开始，到应用正式交付上线，每位开发者均会遭遇在集成开发环境（IDE）、开源代码、供应链及基础设施等环节引入的安全隐患。例如，开源代码中可能引用了存在漏洞的中间件、build镜像时使用了恶意的基础镜像等。在采用持续集成/持续交付（CI/CD）方法进行高速迭代的环境中，面对大量的提交物，安全产品只有通过自动化且符合实际的检测方法，才能有效融入开发流程。 云盾-容器安全产品基于默认安全概念，对开发过程中产生的应用代码、引用的开源代码、供应链、镜像及基础设施等软件资产进行管理，并实施实时自动化安全检测，确保在CI/CD的任何环节中引用均不产生安全隐患。此外，该产品对应用迭代速度几乎没有影响，能够有效降低开发、测试及运营等团队因安全问题所导致的重复工作，从而提升协作效率。 Integrated Test 自动测试 Push

**基于微服务的开发场景**

在微服务架构下，传统安全以操作系统为基础的资产管理理念已不再适用，必须有安全产品能够适应云原生概念，以应用为核心，进行与之相关的要素威胁描述，从而准确表达云原生资产的安全状态。阿里云容器安全产品充分利用云原生的优势，能够对应用中包含的容器，以及其所依赖的阿里云PaaS、BaaS和FaaS资源进行聚合处理，从开发者的视角梳理应用的安全状态。 在传统安全概念中，基于部署于操作系统层的客户端的C/S架构，已无法全面覆盖微服务架构下的异常监控点。阿里云容器安全在EDR的基础上整合了RASP，对容器内应用的数据流进行监控和检测，能够精准识别请求流量中的漏洞，并提供专业的修复方案，无论是在集成测试还是运行时均展现出良好的漏洞检测效果。 云函数（FaaS） JavaScript… </> </> </> Android</> 应用 IOS C# 云API（BaaS） 微服务微服务 … PDS API OSS API MQ API Regis API 微服务微服务 K8S资源（Paas） volumes network workloader setting

**病毒查杀**

阿里云安全专家团队通过对海量病毒样本持久化攻击方式的自动化分析，推出了阿里云机器学习病毒查杀引擎。容器安全基于此引擎的能力，提供对指定范围的服务器发起病毒查杀的功能，对发现的病毒可进行清理、忽略、加白、手动处理等操作。 支持查杀的病毒类型：勒索病毒、挖矿程序、DDoS木马、木马程序、后门程序、恶意程序、高危程序、蠕虫病毒、可疑程序、自变异木马。

| 防护管理 | 针对不同的源/目的网络对象设置防护策略。可支持： 容器对象与容器对象。 容器对象与IP对象/DNS对象。 IP对象/DNS对象与容器对象。 |

**容器文件防御**

容器文件防御功能基于阿里云自研插件SecWebGuard，可实时监控容器内目录或文件，并在容器内目录或文件被恶意篡改时产生告警或拦截篡改行为，避免您的应用被植入非法信息或恶意代码文件，保障容器环境正常运行。

**前提条件**

需要在待防护的集群部署的服务器/节点上安装了容器安全Agent，并确保SecWebGuard插件能正常运行。

| 配置项 | 描述 |
|---|---|
| 规则名称 | 输入规则名称。长度为6~50个字符，以字母或者中文字符开头，可包含数字、下划线（ ）和短划线（-）。 _ |

| 规则配置 | 文件防护目录 | 设置需要防护的目录。配置文件防护目录需满足以下要求： 以/开始。仅支持输入一个目录。 防护目录路径长度需小于500字符。 一条规则只能防护一个目录。如需防护多个目录。您可以单击操作的增加，配置多条目录。 单个容器文件防御规则最多支持配置10条防护目录。 |
|---|---|---|
|  | 进程白名单 | 设置可以修改防护目录的进程名单，加入白名单的进程修改文件时不会触发告警或拦截。配置进程白名单需满足以下要求： 仅支持配置容器视角的进程路径。 单个进程长度不超过50字符。 多个进程用半角分号（;）分隔。 一个文件防护目录下，最多支持配置10个白名单进程。 |
|  | 执行动作 | 在下拉列表中选择检测到篡改行为时的执行动作。可选项： 告警：容器安全识别到文件防护目录被篡改时，只产生告警。 拦截：容器安全识别到文件防护目录被篡改时，产生告警并拦截对应进程。 说明建议您先开启告警模式。在确定正常情况下业务不会触发文件防御告警后， 再开启拦截模式，以避免误拦截正常进程。如果正常业务被拦截，您可以将相应进程加入进程白名单。 |

**容器主动防御**

容器主动防御功能从镜像自身安全、运行时安全、运行环境安全多维度主动检测容器运行时存在的安全风险。通过配置相应规则，您可以拦截不可信进程和阻断容器逃逸行为，提升整体容器运行环境的安全水位。

**风险镜像阻断**

创建**风险镜像阻断**规则后，在指定集群内使用镜像创建资源时，容器安全会对镜像进行安全校验，对命中风险镜像阻断规则的镜像执行拦截或告警动作，确保集群内启动的镜像符合您的安全要求。

**管理系统规则**

为集群创建风险镜像阻断规则后，当您在该集群内使用镜像创建资源时（如创建Pod），会触发安全风险校验请求至容器安全，容器安全会按照该集群的风险镜像阻断规则，校验该镜像是否存在规则配置内的风险， 对命中风险镜像阻断规则的镜像，容器安全会对其执行告警或拦截操作，对于执行告警、拦截动作的镜像， 会产生一条关于该镜像安全风险校验结果的告警事件。 同一集群配置多条规则时，每条规则都会生效；命中多条规则时，会上报多条告警并执行相应操作。 如果您在同一规则内同时配置了多个配置项，命中任意一项配置后，容器安全会立即执行规则动作，不会继续匹配其他配置项。规则内配置项匹配的顺序依次为：白名单 > 黑名单 > 其他（其中，恶意样本 > 未扫描镜像 > 基线 > 漏洞）。

**非镜像程序防御**

在容器环境下基础软件已包含在容器镜像中，在容器运行过程中无需安装和修改软件。基于此情况，在容器运行期间来源于镜像外的程序启动属于异常行为，该行为很可能是黑客植入木马等恶意软件。非镜像程序防御功能提供此类异常行为的检测和拦截能力，为容器环境提供运行时安全防护。

**管理系统规则**

容器安全默认提供非镜像程序防御系统规则，且为未配置过非镜像程序防御自定义规则的用户默认开启系统规则。系统规则会为所有已接入容器安全的集群开启非镜像程序启动告警。您可以在容器安全控制台容器主动防御页面的非镜像程序防御规则的系统规则页签下，查看非镜像程序防御系统规则。 系统规则的规则动作为告警，即发生非镜像程序启动行为时，容器安全只提供告警，不拦截。支持启用或关闭系统规则，修改系统规则生效的集群范围。如果集群有变更或者新增集群资产时，系统规则会自动将新增集群加入防护范围。 初次使用非镜像程序防御功能时，建议您充分观察系统规则告警是否存在误报。系统规则不支持设置白名单，也不支持拦截风险行为。如果您需要设置白名单或拦截风险行为，您可以新建自定义规则。新建自定义规则后，系统规则会被自动关闭且不支持再次开启。如需开启系统规则，需要删除所有自定义规则。

**容器防逃逸**

容器场景中由于容器与宿主服务器共享操作系统内核（安全容器除外），攻击者可利用容器漏洞提升权限实现对宿主服务器系统或其他容器的访问控制，影响整个系统安全性。通过配置容器防逃逸规则您可以有效阻断逃逸行为，保障容器运行时安全。 该功能仅支持检测同时满足以下条件的集群：

**ACK专有集群或已接入容器安全Agent的自建K8s集群。**

| 配置项 | 说明 |
|---|---|
| 规则名称 | 输入规则名称。 |
| 规则类型 | 在下拉列表中选择规则类型。 您可以根据防护需求，在容器安全提供的规则类型中选择所需类型。选择规则类型后，默认选中该类型支持的所有检测项。如果您不需要开启指定检测项，您可以取消选中该检测项的复选框。请在控制台查看支持选择的规则类型和检测项详情。 |
| 防御动作 | 选择防御动作。可选项： 告警：容器安全识别到规则中定义的风险时，只产生告警。 拦截：容器安全识别到规则中定义的风险时，产生告警并拦截对应进程或操作。 重要在某些正常业务场景下可能会触发规则。配置规则时，建议您在告警模式下充分观察后，再为该规则开启拦截模式。 |

| 加白名单 | 单击+新增规则填写需要加入白名单的镜像名。最多可设置20个白名单。 支持填写部分关键字进行模糊匹配。以镜像地址yundun-example- registry.cn-hangzhou.aliyuncs.com/yundun-example/yun-repo:test为例，您可以填写部分关键字进行模糊匹配。以下白名单配置方式均有效： yun-repo test yun-repo:test repo:test 重要将镜像加入规则白名单后，容器安全不会对该镜像检查逃逸行为，请您谨慎操作。 |

**容器签名**

容器签名功能可实现对容器镜像的可信签名，确保只允许部署您认可的容器镜像，防止未经签名授权的镜像启动，从根本上帮助您提升资产的安全性。

### 日志检索

**快速检索**

提供进程快照、网络连接、进程启动的日志查询，支持前缀模糊匹配查询。

**支持的日志类型：**

进程快照：某一时刻主机上的进程运行信息。 网络连接：主机对外主动连接的日志。 进程启动：主机上进程启动的相关信息。
