# 云安全中心（安骑士） 安骑士产品简介

## 产品概述

**云上安全先行者**

阿里云安全团队自2005年起，护航阿里巴巴集团内部所有业务系统的信息安全。团队从成立开始就直面来自全球的网络攻击，至今未尝败绩。近些年云计算技术的不断发展和广泛运用，传统数据中心已经逐步开始向云计算架构进行过渡和迁移，各行各业的数字化转型，使得业务和数据上云成为刚需。为保障云服务安全，阿里云安全团队2011年推出云盾产品。随着专有云业务不断的增长，2013年阿里云安全团队发布第一个专有云云盾的正式版本，为专有云、行业云用户提供IaaS层安全保障能力。 十年攻防，一朝成盾。阿里云安全团队结合多年云上实战经验，打造云盾安骑士（Aegis）-主机安全产品。 安骑士是一个集威胁识别、分析预警、处置修复于一体的泛资产安全管控系统，能够提供精准的资产漏洞、 基线、暴露面等脆弱性检查修复能力，也支持对0/1/Nday进行应急响应。并通过自研的多引擎体系，安骑士可提供云查杀、特征查杀、启发式查杀、进程恶意行为检测、勒索病毒诱捕、大数据模型规则检测等威胁检测能力。也可根据用户业务实际情况，提供基于文件、进程、网络的规则保护能力，有效防止线上业务系统行为被篡改。安骑士可收集并呈现10余种类型的日志和云上资产指纹，并结合网络实体威胁情报进行安全态势分析，扩大安全可见性，实现威胁检测、响应、溯源的自动化安全运营闭环，保护云上资产和本地服务器并满足监管合规要求。

**产品定位**

阿里云安全-云盾-安骑士（Alibaba Cloud Security-Server Guard Advanced Edition，简称Aegis）是阿里云原生的终端安全检测及响应系统。通过安全告警实时抵御恶意入侵，使用漏洞和基线配置检测消除系统弱点、预防恶意攻击，提供安全态势分析和安全可视化界面、满足事后追溯和分析需求，建立完善的云环境终端安全体系。 安骑士在服务器系统内核层面通过Agent插件实现云上文件和进程行为的全局监控和实时分析，对海量病毒样本持久化攻击方式的自动化分析，有效绕过顽固木马和恶意程序的反查杀能力；还可以基于程序行为分析，挖掘出黑名单未能辨识的恶意威胁，实现主动拦截；其云端病毒库实时更新，集成了国内外主流杀毒引擎、阿里云自研沙箱和机器学习引擎等前沿技术，可以避免因病毒库更新不及时而造成的损失， 防护策略和数据源自于多年的积累，是阿里云上多达百万级的用户，每天面临多达几十万次的各种攻击。阿里云安全团队充分利用了这些安全攻防的数据积累，每天对公共云上10多TB的安全数据进行分析，形成恶意IP库、恶意行为库、恶意样本库、安全漏洞库等基础安全能力，并及时应用到态势感知的各个防护模块中，提升防护能力，为用户带来更好的安全保障。

**应用场景**

安骑士广泛适用于政府、金融、能源、央企、各大部委等行业云、政务云、XC云、混合共建云的安全体系建设，支撑各行各业的云服务器安全管理运营。

**多云多芯片泛资产统一安全管控**

安骑士支持在混合云/多云、一云多芯场景下，实现对租户侧泛资产的产品化集中纳管，设备层包括在 x86_32/64_Intel/AMD、x86_64_海光、ARM_64_飞腾/鲲鹏等环境下运行的阿里云ECS、底座物理机、 OnECS云盾服务器、云外IDC主机、他云虚拟机、他云物理机等。并且提供自动化安全监控、安全规则可运营、威胁态势数据关联分析等能力，能够覆盖专有云/行业云/混合云/异构云/多云/xc云/一云多芯等日常安全运营场景

**等保合规建设**

等级保护2.0要求，应根据云服务商和云服务客户的职责划分，管理各自控制部分的资产脆弱性问题、威胁事件等资产风险，实现各自控制部分资产的，漏洞风险、基线风险、病毒木马、黑客入侵事件的处置修复。

**护网防御体系建设**

安骑士能够提供资产盘点+资产暴露面盘点能力，梳理云环境对外提供服务的资产、应用、网络链路情况； 并提供主机操作系统、网站应用等层面的资产加固能力，能够有效减少资产可被暴露面。同时安骑士能够准确识别外部入侵行为，并进行进程级实时拦截。

**云环境APT威胁防御**

安骑士提供BD、小红伞等杀毒行业头部引擎，配合阿里云查杀引擎，提供强大的二进制威胁检测能力。自研的GLE多引擎集成了静态匹配检测、通用语法树(AST)动态污点模拟执行、异常启发式检测为一体的动静结合能力，能够精准检出webshell以及恶意脚本。 对于威胁事件以及APT，安骑士通过Dipper引擎提供了350+的威胁检测模型，能够从上层数据中挖掘潜在的安全隐患。

**平台侧资产安全运营**

平台物理机作为云环境基础，其内部对底座业务计算资源的应用风险，会给云平台和其他云租户带来相应的安全隐患。因此平台用户需要对物理机资产和业务风险进行监管和控制。安骑士提供平台物理机的安全情况进行监控能力，以保障云平台安全和其他云租户的业务稳定性。

## 产品设计

**产品架构**

安骑士管理模式采用C/S架构。安骑士客户端（简称Agent）可安装在云内经典网络物理机、云内ECS、云外主机/他云主机等云环境服务器上，Agent与安骑士服务器端通过TCP长连接进行通信，通过HTTP方式从服务器端获取需要的脚本、规则、安装包等文件。安骑士客户端Agent分为Windows版本和Linux版本，客户端Agent自动连接到安骑士服务器端进行在线升级。此外安骑士会持续从云原生环境中获取SLB、 DNAT、EIP、安全组等网络环境数据以及资产基本信息和云盘信息，丰富云环境资产的状态描述信息。

**客户端**

服务端主要分成以下几个模块： 基础能力：云盾通用能力，提供控制台和OpenAPI。 客户端管理：负责管理客户端连接、配置、规则、补丁包等。 核心能力：包括资产、告警、日志、文件采集、安全报告等。 检测防御：包括漏洞、基线、文件、网络、进程的检测防御能力。 检测引擎：包括商业病毒检测引擎、阿里自研病毒检测引擎、大数据计算引擎。

## 产品功能说明

### 安全总览

安全总览页面，作为安骑士的安全运营中心，实时展示当前账户下所有资产统计数据以及安全趋势，协助用户进一步统一管理所有资产。页面可展示数据包括： 资产操作系统分布、客户端活跃状态。 漏洞、基线、病毒木马、入侵事件等维度的风险趋势。 威胁事件事实告警。

### 资产中心

**主机列表**

以列表形式，展示当前账户下所有服务器的安全状态描述信息；统计所有服务器、存在风险的服务器、未受保护的服务器、未启动的服务器、新增服务器等分类资产梳理；还可管理服务器组、供应商、VPC等资产的隶属关系。 支持批量下发资产安全检查，数据导出，以及云外主机解绑等操作，资产漏洞、风险基线数据单次导出最大支持50台，基线全量数据单次导出最大支持15台，客户端日志仅支持单台导出。 如该账户是租户侧账户，则展示其租户ECS、云外主机；如该账户是物理机安骑士账号，则展示平台侧物理机，物理机账号具体操作入口为吊顶菜单系统配置。 主机列表资产信息类型：服务器名称、公网IP、私网IP、自定义标签、所属VPC、操作系统、快照恢复风险、服务器状态、客户端状态、云外暴露、漏洞风险、基线风险、入侵告警、服务器风险状态。

**主机详情**

展示所选服务器的详情，可分为基本信息、安全策略以及风险情况三个方面。安全策略包含服务器安全登录时间范围、地点范围等，可在此页面手动修改；风险情况包括资产漏洞信息、安全告警处理、基线检查、云外暴露、资产指纹调查等。此外服务器如果为云外主机，基本信息中则会展示其供应商信息。

**应用防护**

应用防护功能基于RASP（Runtime Application Self-Protection）技术，通过在应用运行时检测攻击并进行应用保护，为应用提供安全防御。您无需修改代码，只需在主机或容器环境的应用中安装RASP探针， 即可为应用提供强大的安全防护能力，并抵御绝大部分未知漏洞所使用的攻击手法。

**技术原理**

应用防护使用RASP技术，在应用程序内部通过钩子（Hook）关键函数，实时监测应用在运行时与其他系统的交互过程。当应用出现可疑行为时，应用防护会根据当前上下文环境识别并阻断攻击，有效地为您主机上的Web业务进程提供应用漏洞、0day漏洞和内存马攻击等防护能力。 应用防护目前仅支持接入Java应用。

**前置条件**

使用该功能前，请先购买并导入RASP功能模块的License。 云盾-安骑士高级版-增强授权模块（RASP）。 Code：yundun_aegis_sc_online_lic_rasp。

**检测攻击类型**

| 攻击类型 | 说明 | 防护建议 |
|---|---|---|
| JNI注入 | JNI注入是一种通用的RASP（Runtime Application Self-Protection）绕过手段。当攻击者拿到代码执行权限后，可以通过Java Native函数去调用外部的恶意动态链接库，从而绕过Java层的安全防护，并隐匿具体的恶意行为。 | 您的服务器可能存在代码执行漏洞， 请检查漏洞的位置并限制执行代码的功能。 |
| SQL注入 | SQL注入手段通过把SQL命令插入到页面请求或 Web表单的查询字符串中，以达到欺骗服务器执行指定SQL语句的目的。它可以通过在Web表单中输入SQL语句，得到存在安全漏洞的网站上的数据。 | SQL注入是由拼接SQL语句引起的。 请尽可能使用预编译来处理传入的参数，或通过白名单和黑名单来限制拼接参数。 |
| XXE | 指XML外部实体注入漏洞（XML External Entity Injection）。当XML文件在引用外部实体时，通过构造恶意内容，可以导致任意文件读取，命令执行和内网攻击等不良后果。 | 请检查应用程序在解析XML时是否需要加载外部实体。如果不需要，请在 XML解析配置中禁用外部实体。 |
| 恶意DNS查询 | 恶意DNS查询存在多种利用方式。攻击者极有可能通过DNS协议来突破内网的网络限制，从而将敏感信息带出内网，也可能通过DNS协议去探测内网系统是否存在SSRF、JNDI注入等漏洞。 | 恶意DNS查询是由服务器向用户控制的参数发送请求所引起的。请检查参数并通过白名单进行限制。 |
| 恶意反射调用 | RASP自保护模块，禁止攻击者通过反射的方式去修改运行时RASP的相关数据。 | 您的服务器可能存在代码执行漏洞。 请检查漏洞的位置并限制执行代码的功能。 |
| 恶意外链 | SSRF（Server-side request forgery）服务器端请求伪造漏洞指的是攻击者通过构造由服务端发起的请求，对网站内部系统进行攻击。 | SSRF是由服务器向用户传入的参数发送请求所引起的。请检查参数并通过白名单进行限制。 |
| 恶意文件读写 | Java提供RandomAccessFile，用于文件读写操作。当使用该Class进行文件读写的时候，如果未对文件路径、文件内容进行限制，攻击者可能读取到系统敏感文件，也可能上传木马文件。 | 请检查文件读取和上传是否正常。如果出现异常，请检查函数代码，并通过黑名单进行限制。 |

| 恶意文件上传 | 对于网站提供的文件上传功能，如果未对上传文件的类型进行限制，攻击者可能通过上传木马文件来获取服务器的更大权限，从而造成严重危害。 | 请限制上传文件的类型，禁止上传具有执行权限的文件，如JSP。 |
|---|---|---|
| 命令执行 | 命令执行漏洞是指服务器没有对执行的命令进行过滤，用户可以随意执行系统命令。 | 通常远程命令执行是由Web Shell或服务器的危险代码引起的。请检查命令执行的位置。如果是Web Shell， 请及时删除。如果是服务器的正常功能，则可以通过白名单限制执行的命令。 |
| 目录遍历 | 网站自身的配置缺陷可能会使得网站目录被任意浏览，导致隐私信息泄露。攻击者可以利用该信息对网站进行攻击。 | 请检查目录遍历操作是否正常。如果异常，请检查函数的代码，并通过黑名单对相关命令（如“./”和“../”）进行限制。 |
| 内存马注入 | 内存马是一种新兴的木马技术，攻击者通过一些特殊的技术手段将木马注入到内存中，可以有效绕过 WAF和主机防御的检测。 | 您的服务器可能存在代码执行漏洞。 请检查漏洞的位置并限制执行代码的功能。 |
| 任意文件读取 | 对于网站提供的文件下载和读取功能，如果是直接通过绝对路径或目录穿越符对文件进行读取和下载，没有相关文件路径的限制，那么，攻击者就可以利用这种方式获取敏感信息，对服务器进行攻击。 | 请检查文件读取操作是否正常。如果异常，请检查函数的代码，并使用黑名单对传入参数（如“./”和“../”）进行限制。 |
| 线程注入 | 线程注入是一种通用的RASP绕过手段。当攻击者拿到代码执行权限后，可以通过新建线程的方式使 RASP丢失掉运行环境的上下文，从而影响RASP的防御能力。 | 您的服务器可能存在代码执行漏洞。 请检查漏洞的位置并限制执行代码的功能。 |
| 恶意Attach | Attach API是Java提供的动态修改字节码技术，该功能可以实现动态修改运行时应用的字节码。很多攻击者通过该手法进行Agent型内存马的注入，具有较高的欺骗性。 | 您的服务器可能存在代码执行漏洞。 请检查漏洞的位置并限制执行代码的功能。 |
| JNDI注入 | 当应用进行JNDI查询的时候，若查询的URL可以由攻击者控制，则攻击者可以用服务器去查询恶意的链接使得服务器加载一些恶意class，实现任意代码执行。 | 若该漏洞源于第三方组件，请及时进行组件版本升级。 若为自写JNDI查询代码，请对查询的URL进行限制，禁止一些危险协议的查询。 |
| 危险协议使用 | 若服务端进行访问的URL用户端可控，而应用本身又未对该URL的协议进行限制，那么攻击者可能通过 file、netdoc等危险协议对服务器上的敏感文件进行读取。 | 请对URL可以访问的协议进行限制。 |

| 反序列化攻击 | Java反序列是指把字符序列恢复为Java对象的过程，在对象生成过程中，若该对象包含一些危险度较高的代码，则攻击者可能通过控制生成对象的成员变量在对象进行反序列化的时候实现一些恶意攻击。 | 及时升级存在漏洞的组件版本。 若官方还未提供漏洞修复的组件版本，请暂时关闭该功能。 |
|---|---|---|
| 任意文件删除 | 对于网站提供的文件删除功能，文件删除的接口如果没有对文件路径进行限制，攻击者就可以通过绝对路径或目录穿越符对任意文件进行删除操作，从而对服务器进行攻击。 | 请检查文件删除操作是否正常。如果异常，请检查函数的代码，并使用黑名单对传入参数（如“./”和“../”）进行限制。 |
| 表达式注入 | 表达式组件提供了十分丰富的功能，支持在运行时查询和处理数据等，但很多表达式组件也提供了函数调用等权限较高的功能，如果未对这些功能做限制，而攻击者又能够控制表达式执行的内容，那么攻击者将很有可能通过表达式执行任意代码。 | 请对进入表达式的内容进行严格限制，禁止大部分Java函数的调用。 若是第三方组件漏洞导致，请及时升级组件版本。 |
| 引擎注入 | Java提供较多的第三方引擎组件（如rhino、 Nashorn等JS引擎，velocity、freemarker等模板引擎），这些引擎通常提供了函数调用等权限较高的功能，如果对这些功能未作限制，而攻击者又能够控制引擎执行的内容，那么攻击者将很有可能通过引擎执行任意代码。 | 请对进入引擎文件的内容进行严格限制，禁止大部分Java函数的调用。 若是第三方组件漏洞导致，请及时升级组件版本。 |
| 恶意Beans定 | Java存在一些框架支持对应用运行时Beans的参数绑定，如果未对绑定Beans的类型进行限制，攻击者就可以通过对一些敏感Beans值的修改，破坏应用的运行，甚至造成执行任意代码。 | 请对可以绑定的Beans的类型进行限制，禁止对类似于Class、 Classloader类型的Beans值进行修改。若是第三方组件漏洞导致，请及时升级组件版本。 |
| 恶意类加载 | 现阶段，很多0day、WebShell的利用均依赖于恶意类的加载，一旦恶意类加载成功，攻击者便可以通过恶意类的初始化来取得代码执行权限，从而进行一系列的恶意操作。 | 若恶意类的加载是通过WebShell 控制，请及时删除WebShell。 若恶意类的加载是框架导致，请及时升级框架版本。 |
| JSTL任意文件包含 | JSP标准标签库（JSTL）是一个JSP标签集合，它封装了JSP应用的通用核心功能。当用户可控参数被直接拼接到JSTL标签中而未对该参数进行任何限制的情况下，攻击者可以构造特殊的攻击脚本造成任意文件读取、SSRF的攻击。 | 尽可能不要将用户可控参数直接拼接到JSTL标签上，如果必须这样做，请对该参数的内容进行严格的白名单控制。 |

**病毒查杀**

阿里云安全专家团队通过对海量病毒样本持久化攻击方式的自动化分析，推出了阿里云机器学习病毒查杀引擎。安骑士基于此引擎的能力，提供对指定范围的服务器发起病毒查杀的功能，对发现的病毒可进行清理、 忽略、加白、手动处理等操作。
**支持等病毒类型：**勒索病毒、挖矿程序、DDoS木马、木马程序、后门程序、恶意程序、高危程序、蠕虫
病毒、可疑程序、自变异木马。

**扫描方式**

立即扫描：立即下发扫描任务，支持按资产分组下进行策略下发。 周期性扫描：设定扫描周期，扫描指定资产分组下的选定的服务器。

**警告**

风险暴露检查需要进行大量的资产、应用、风险等数据管理，其功能依赖Dipper引擎，如用户环境中没有该引擎，则无法使用此功能。

**实时防护**

**主动防御（Hips）**

主动防御（Hips）通过启发式行为规则，能够实时拦截具有风险动作的病毒木马、恶意程序、恶意网络连接和网站后门连接。 主动防御支持单步主防和多步主防，在入侵行为对信息系统发生影响之前，主动防御能够及时精准预警，构建智能的可识别行为主体威胁动作的防御体系，降低云服务器所面临的威胁入侵风险。并提供驱动级拦截， 可有效消除安骑士对病毒处理的滞后性。

| 防御种类 | 防御描述 |
|---|---|
| 进程行为拦截 | 基于阿里云机器学习引擎提供的启发式、正则规则库，对服务器进程及其网络行为、命令行等维度进行检测，有效发现并拦截进程风险行为。 |
| 进程链防御 | 参考进程上下文判断风险，可拦截常见漏洞利用，如通过Web漏洞执行信息探测、下载恶意代码等。 |
| 进程二进制检测 | 勒索软件、挖矿程序、木马程序、蠕虫病毒、恶意程序、后门程序、DDoS木马 、自变异木马、感染型病毒、黑客工具、漏洞利用程序、被污染的基础软件、 Rootkit。 |
| 执行脚本检测 | 支持检测脚本语言Bash、Python、Perl、PowerShell、VBS、Bat、 JScript、CSharp、C。 支持检测开源武器化框架自动生成利用脚本（Cobalt Strike、Empire、 Metasploit、Nishang）。 支持检测批量蠕虫挖矿脚本。 |

**勒索防护**

勒索防护提供勒索诱捕以及数据恢复风险的监控能力。帮助用户拦截勒索病毒运行，排查备份习惯较差的资产，降低服务器被勒索病毒攻击后的数据恢复风险。 勒索诱捕：安骑士在服务器创建随机诱饵，一旦可疑进程对诱饵进行改写，则立即会被安骑士发现并拦截勒索行为。勒索捕获诱饵文件仅用于捕获新型勒索病毒，不会对业务产生任何影响。

**说明**

仅对Windows生效。 备份风险监控：备份习惯较差的资产在被勒索后，会存在数据恢的复风险。此功能可便于用户快速发现资产备份策略存在的风险，提醒用户进行及早修复。

**网站后门防护**

安骑士支持网站后门防护功能，支持自动拦截黑客通过已知网站后门进行的异常连接行为，并隔离相关文件，有效清理隔离PHP、ASP、JSP等类型的Webshell后门。 安骑士 Webshell检测能力由自研的 GLE引擎提供。GLE引擎在阿里公有云上打磨了7年之久，其集成静态匹配检测、通用语法树（AST）动态污点模拟执行、异常启发式检测为一体的动静结合能力，能够精准分析大马、小马、一句话木马等类型webshell。 阿里云安全团队共对外公开举办四期“宙斯众测”计划，GLE引擎累计经受600+白帽子的测试，对顶尖白帽子构造的高级对抗样本检出率高达95%+。 安骑士支持对自动发现或手动添加的Web目录进行Webshell查杀以及全盘Webshell落盘查杀。

**防篡改**

安骑士防篡改功能，支持通过策略配置方式，对服务器的Web目录提供防篡改能力。策略内容包含防护文件目录、防护文件类型等主要信息。策略开启后，防篡改功能通过Agent实时监控所有对被防篡改目录下文件进行操作的进程，实时识别异常进程和异常文件变动，并对导致异常文件变动的进程进行阻断，保障重要系统的网站信息不被恶意篡改，防止出现挂马、黑链、非法植入恐怖威胁、色情等内容。 防篡改支持配置可信进程用于业务发布，可信进程可对防护目录文件进行增删改。此外可信进程发生变化后，安骑士会立即禁止其修改防护目录。

**白名单模式**

白名单模式下安骑士已将常见需要防护的文件类型默认加入防护列表。用户可以根据业务增加防护类型， 保障业务系统正常运行。

**攻击分析**

以攻击者和被攻击者视角展示最近7天、30天攻击趋势和攻击类型分布。提供展示包括攻击时间，攻击来源，被攻击资产，事件来源，攻击次数，攻击类型等具体信息。

**威胁模型检测**

基于Dipper的大数据关联分析能力，安骑士威胁检测模块具备350+威胁检测模型，能够覆盖云上95%以上的入侵事件。并按照操作系统、分析对象、攻击手法等维度进行分类，能够帮助用户快速了解云环境入侵事件。

接、异常账号、应用入侵事件、持久化后门、应用威胁检测。
**支持的告警类型：**网站后门、恶意进程（云查杀）、恶意脚本。

安骑士威胁情报检测依赖Dipper引擎，如用户环境中没有该引擎，则无法使用此功能。 如需在安骑士产品中使用威胁情报，需要另外购买阿里云威胁情报服务。

**防护模式管理**

Agent是安骑士提供的本地插件，必须在服务器操作系统上安装Agent插件才能使用安骑士提供的安全防护服务。防护模式管理功能提供多种Agent运行模式，可以满足不同应用场景下的安全需求。

**业务优先模式**

以业务运行为优先考量，使用最低的内存和CPU运行防护工作，确保业务运行无碍，适合工作量较高无法中断的服务器。

**具体性能指标描述**

业务优先模式：CPU占用峰值小于10%、内存占用峰值小于50MB。

**防护优先模式**

以安全防护为优先考量，使用相对高的系统内存和CPU进行防护工作，可以更及时的查杀病毒和威胁告警， 适合对安全等级要求较高的服务器。

**具体性能指标描述**

防护优先模式：CPU占用峰值小于20%、内存占用峰值小于80MB。

**重保模式**

重保护模式适用于重大活动的安全保障，为用户开启更严格的防御模式。开启重保护模式，安骑士将通过智能化的规则提升告警检测引擎的敏感度，对任何可疑的入侵行为和潜在的威胁提供告警，帮助您精准识别和拦截所有攻击和威胁。

**基础防护模式**

以业务运行为优先考量，客户端使用最低的内存和CPU运行防护工作。

**具体性能指标描述**

基础防护模式：CPU占用峰值小于单核10%、内存占用峰值小于200MB。

**高级防护模式**

以均衡防护为优先考量，客户端使用均衡的内存和CPU运行防护工作。

**具体性能指标描述**

高级防护模式：CPU占用峰值小于单核30%、内存占用峰值小于300MB。

**重大保障模式**

以安全防护为优先考量，客户端使用相对高的系统内存和CPU进行防护工作。

**具体性能指标描述**

主机规则管理功能用于安骑士对于主机的检测、防御规则的管理，支持对恶意行为防御的相关设置。

**恶意行为防御**

安骑士提供了系统防御规则，可以防御常见的攻击行为，例如恶意脚本执行命令、植入恶意文件等。使用恶意行为防御功能，您可以管理云安全中心提供的系统防御规则，还可以根据业务场景自定义防御规则，构建更精细化的防御体系。

| 规则类型 | 适用场景 |
|---|---|

| 系统防御规则 | 常见恶意攻击行为防御自动拦截常见恶意行为。支持通过停用系统防御规则或修改系统防御规则的生效服务器为您的资产定制防御规则，最大程度减少告警误报。 安全告警事件误报处理在处理告警类型为精准防御的告警事件时，如果您发现云安全中心的系统防御规则检测出的安全告警事件，在经过您识别后为正常的业务进程，您可以在恶意行为防御页面的系统防御规则页签下关闭该系统防御规则，或者将告警事件中的受影响服务器，从系统防御规则防御的资产的列表中移除。 |
|---|---|
| 自定义防御规则 | 如果您需要放行或重点拦截某些确定的行为时，您可以使用自定义防御规则功能，自定义适合自己业务场景的精细规则。 |

**使用限制**

需内核版本支持启用相关插件。 arm暂不支持。

**高危命令审计**

安骑士提供了对主机中执行命令行的实时监控，若检测出匹配的高危命令，会产生实时告警通知。

| 参数 | 描述 |
|---|---|
| 命令行数据来源 | 进程执行命令、Bash/Shell命令行。 |
| 匹配方式 | 进程路径+命令正则表达式。 |
| 运行状态 | 运行中：规则生效中。 未开启：规则未生效。 静默运行：一段时间内超过设置的最大触发次数限制后，该规则将进入静默状态，即不产生更多告警，直到进入下一个时间周期后恢复。 说明修改限制请登录ASO > 云盾运维中心 > 安骑士全局设置。 |

**防暴力破解**

支持设置暴力破解拦截策略与生效资产范围，针对产生暴破告警命中策略的IP自动生成对应的拦截规则， 支持自定义时间段内禁止该IP登录服务器。 支持设置自定义规则，对任意IP与端口设置网络访问拦截规则。

**使用限制**

需内核版本支持启用相关插件。 arm暂不支持。
