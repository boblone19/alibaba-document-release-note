### 登录Apsara Uni-manager运营控制

**台**

**前提条件**

登录Apsara Uni-manager运营控制台前，确认您已从部署人员处获取Apsara Uni-manager运营控制台的服务域名地址。 推荐使用Chrome浏览器。

**操作步骤**

1. 在浏览器地址栏中，输入Apsara Uni-manager运营控制台的服务域名地址，按回车键。

**说明**

单击页面右上角的当前语言可以切换其它语言。 授权登录是第三方认证中配置了全局IdP设置才会显示，且“授权登录”名称用户可按需自定义。 由于浏览器证书过期或环境开启HTTPS认证等出现多次单击继续访问或无Apsara Unimanager运营控制台地址入口等现象，此时需要安装证书才能正常访问。单击页面右上角的**浏览器证书安装**，可打开浏览器证书安装指南。
2. 输入正确的用户名及密码。

**说明**

请向运营管理员获取登录控制台的用户名和密码。 首次登录Apsara Uni-manager运营控制台时，需要修改登录用户名的密码，请按照提示完成密码修改。为提高安全性，密码长度必须为10~32位，且包含英文字母大小写、阿拉伯数字和特殊符号（感叹号（!）、at（@）、井号（#）、美元符号（$）、百分号（%）等）。
3. 单击**账号登录**。
4. 如果账号已激活MFA多因素认证，请根据以下两种情况进行操作：

**管理员强制开启MFA后的首次登录**

a. 在绑定虚拟MFA设备页面中，按页面提示步骤绑定MFA设备。 b. 按照步骤2重新输入账号和密码，单击**账号登录**。 c. 输入6位MFA码后单击**认证**。

**您已开启并绑定MFA**

输入6位MFA码后单击**认证**。

**说明**

绑定并开启MFA的操作请参见《 Apsara Uni-manager运营控制台用户指南》的**管理多因素认** 证章节。

**相关操作**

**忘记密码**

1. 用户忘记登录密码时，单击密码输入框下方的**忘记密码**。
2. 在忘记密码页面，输入**账户名**、**邮箱**和验证码后，单击**确认**。

**说明**

账户名请输入当前账号的用户名，邮箱请输入注册账号的Email地址。 重置密码的链接将发至邮箱，进入链接后用户可输入新密码。

### 密码服务

只有开通密码服务后，才能正常使用密码服务实例。本文介绍如何开通和管理密码服务。

**开通密码服务**

1. 登录Apsara Uni-manager运营控制台。
2. 在控制台顶部菜单栏，单击**安全**，选择**数据安全** > **密码服务**。在**密码服务**授权页面，选择**地域**并单击角
**色授权访问**。
3. 在左侧导航栏，单击**密码服务**。
4. 在**密码服务**页面，单击**开通服务**，完成如下配置。

| 配置项 | 说明 |
|---|---|
| 组织 | 选择密码服务所属的组织。 |
| 资源集 | 选择密码服务所属的资源集。 |
| 区域 | 区域默认选择，您无需设置。 |

| 可用区 | 选择密码服务所在的可用区。支持选择多个可用区。 |
|---|---|
| 服务类型 | 选择密码服务的类型。更多信息，请参见密码服务类型说明。 |
| 服务版本 | 选择密码服务的版本。 |
| 套餐 | 选择ECS实例规格项，支持选择标准版（4c 8G）、高级版（8c 16G）、企业版（16c 32G）。 |
| 实例数量 | 设置密码服务的实例数。最小取值为1，最大取值为配额剩余数量。 此处为单个可用区的实例数量, 若选择了N个可用区, 则会申请N*实例数量。 |
| 专有网络vpc | 密码服务VPC。该VPC默认绑定密码机实例所在VPC。 |
| 密码机分组 | 选择密码机分组。 |
| 交换机vSwitch- 1 | 选择交换机vswitch。 |

5. 单击**确定**。

**重要**

开通密码服务时，需确认当前license数量是否已达上限。若已达上限，密码服务会因license授权数量不足而无法开通。

**管理密码服务**

您可以在**密码服务**页面，查看和管理密码服务实例。

**查看密码服务实例**

您可以在密码服务实例列表查看实例的ID/实例名称、服务类型、可用实例数/总实例数、管理状态、组织、 资源集、创建时间。 密码服务实例开通需3~5分钟，请您耐心等待。 若密码服务实例**管理状态**为**创建中**，表示该实例正在开通中。 若密码服务实例**管理状态**为**创建成功**，表示该实例已开通并正常运行。

**管理密码服务实例**

单击目标实例或该实例**操作**列的**管理**，在各类密码服务页面，管理密码服务。关于不同类型的密码服务的管理操作文档，请联系您的商务经理获取。

**修改密码服务实例别名**

单击目标实例**ID/****实例名称**列的图标，并输入别名。

**查看密码服务实例详细信息**

单击目标实例**操作**列的**详情**，在详情面板，查看**实例基础信息**、**服务实例列表**以及**共享网络****VPC****信息**。

**扩容或缩容密码服务实例**

单击目标实例**操作**列的**扩容**，设置扩容或缩容的实例数规格。实例数最大规则为配额剩余数量。

**说明**

系统自动扩容密码服务后，服务访问地址不变，密码服务也无需重复初始化，应用无需更改任何配置。 扩容服务实例数时，需要判断license数量是否已达上限。若已达上限，密码服务会因license授权数量不足，无法开通。若未达上线，则开通密码服务实例，并扣减license数量。

**升级密码服务实例**

选择目标实例**操作**列的
> **升级**，设置要升级的**服务版本**。

**重要**

升级密码服务实例会导致服务重启，造成临时的服务中断。建议您在业务量低时，先停掉业务， 再进行升级。完成升级后，再重启业务系统。整个升级过程约3~5分钟，请您耐心等待。 若密码服务**管理状态**为**升级失败**，表示该实例升级不成功。

**释放密码服务实例**

选择目标实例**操作**列的
> **释放**，确认无误后，在对话框中单击**确定**。

**说明**

密码服务实例释放后，该实例不再在实例列表呈现。 密码服务实例释放后，已消耗license数量会被回收调整。

**添加共享网络VPC**

添加VPC后，这些VPC中的应用就可以访问密码服务实例。 选择目标实例**操作**列的
> **添加共享网络****VPC**，选择**共享网络****VPC**以及**交换机****vswitch**，然后单击**确定**。

**重建**

仅当您的系统环境版本低于v3.19.0时，需要执行实例重建操作，重建前不支持对密码机实例进行其他操作。
1. 选择目标实例**操作**列的**重建**。
2. 在重建对话框中选择**服务版本**，然后单击**确定**。
每个实例重建约5分钟。

| 资源集 | 选择密码机实例所属的资源集。 |
| 区域 | 默认选择，您无需设置。 |
| 可用区 | 选择密码机实例所属的可用区。 |
| 设备厂商 | 选择设备厂商。 |
| 设备型号 | 选择设备型号。您可以指定密码机设备进行实例创建，同时也可以选择在不同物理设备创建密码机实例，将由系统自动分配。 |

5. 单击新创建实例**操作**列的**配置**，在**虚拟密码机配置**对话框，填写虚拟密码机配置信息后，单击**确认**。

| 区域 | 默认选择，您无需设置。 |
|---|---|
| 专有网络VPC | 选择密码机分组所属的VPC网络。 |
| 快速创建/自定义创建 | 快速创建：选择可用区并设置设备数量，系统会自动分配密码机实例。 说明设备数量为单个可用区的设备数量,，若选择了N个可用区, 则会申请N*设备数量。 请确保有足够数量的未初始化的密码机实例，否则会创建失败。 自定义创建：添加您要加入分组的密码机实例。 重要已初始化密码机实例无法被添加到密码机分组。 若添加多个密码机实例，请确保密码机实例的VPC ID一致，否则将无法添加。 |

5. 单击目标分组**操作**列的**初始化**，在**快速初始化**对话框，设置**密码机口令**和**确认密码机口令**。

**重要**

**密码机口令**和**确认密码机口令**需一致。
您可以在密码机分组列表查看各分组中的**密码服务**、**关联密码机**、**使用率**、**使用状态**、**初始化状态**、组织、**资源集**、**创建时间**等信息。 单击目标分组**操作**列的**删除**，确认无误后在对话框单击**确定**。

**说明**

处于已使用状态的密码机分组，无法被删除，请去除与密码服务的关联后才能删除密码机分组。 仅支持释放**使用状态**为**未使用**的密码机分组。**使用状态**为**已使用**的密码机分组，不支持释放。如需减少分组中的实例数，可单击**操作**列的**修改**。

## 最佳实践

### CSP由天基迁移PAAS后残留资源清理

**方案**

本文介绍CSP由天基平台迁移到PAAS平台后，天基平台侧残留资源如何清理。

**警告**

资源删除后无法回滚，删除前请确认PAAS侧密码服务实例已全部重建完成。

**注意事项**

只需要清理残留的ECS实例即可，其他资源如VPC、SLB、VSW、安全组资源不需要清理。

**步骤一：查询ECS资产**

1. 登录数据库（cspcrypto_data），查询ECS实例数据。

```
select * from instance_tbl where status!='Deleted';
```

请记录instance_id字段，待后续释放使用。

**步骤二：清理ECS实例**

1. ECS资产查询。
使用kms-csp-resource账户执行aliyun查询命令，获取当前资源账户下的所有ECS。 查询结果包含TASS管控和业务正常创建出来的密码服务实例所使用的ECS。该操作主要验证接口调用是否正常，要释放的资源是否包含在此账户下。 kms-csp-resource账户的AccessKey ID、Secret Access Key，可以在kms-csp集群的**资源详情**里查询。 endpoint使用ecs-internal的域名，可以在资源申请表中查询。

```
./aliyun --skip-secure-verify --region XXXX --endpoint XXXX --access-key-id XXXX -access-key-secret XXXX ecs DescribeInstances --RegionId XXXX --PageNumber 1 --PageS ize 50
```

2. 停止ECS实例。
停止运行ECS实例前，请确认当前ECS的ID是否为需要释放的实例ID。

```
./aliyun --skip-secure-verify --region XXXX --endpoint XXXX --access-key-id XXXX --ac cess-key-secret XXXX ecs StopInstance --InstanceId XXXX
```

3. 删除ECS实例。

```
./aliyun --skip-secure-verify --region XXXX --endpoint XXXX --access-key-id XXXX --ac cess-key-secret XXXX ecs DeleteInstance --InstanceId XXXX
```
