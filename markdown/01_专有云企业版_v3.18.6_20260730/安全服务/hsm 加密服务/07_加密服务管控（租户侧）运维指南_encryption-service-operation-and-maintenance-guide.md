## 运维概述

本文介绍阿里云专有云企业版加密服务的运维目的、要求、注意事项、学习路径以及寻求帮助的方式。

**目的**

本手册指导运维人员对加密服务进行预防性地维护，确保系统稳定运行。运维人员可以根据本手册的指导， 处理维护过程中发现的系统问题。如果根据本手册无法解决系统问题，请联系阿里云技术工程师的处理。

**要求**

1. 运维人员必须拥有IT行业技能，包括计算机网络知识、计算机操作知识、问题分析排查能力。
2. 运维人员必须经过阿里云系统岗前培训，学习必要的阿里云系统知识以及运维平台的使用，包括但不限于
飞天基础运维平台、ASO运维平台、ASCM管理平台。

**注意事项**

在维护操作过程中，运维人员务必遵守操作规章，确保系统安全。对用户数据严格保密，未经用户书面许可，禁止复制、传播用户数据。

**学习路径**

运维人员可根据产研交付的运维文档，初步了解客户对于加密服务产品的需求，以及加密服务的基本含义及运维方式。

**寻求帮助方式**

运维人员在系统维护过程中，如果需要相关帮助，请联系加密服务的技术支持。 加密服务

### 实例管理

通过实例管理，用户可以在加密服务对实例的运维操作，包括实例查询、配置VPC、释放、漂移、删除。本文介绍如何运维实例。

**运维模式说明**

加密服务支持两种运维模式：正常模式和维护模式。

| 模式 | 说明 |
|---|---|
| 正常模式 | 默认正常模式，在该模式下主要执行查看以及不影响vsm业务的相关操作，不支持的操作按钮置灰。 |
| 维护模式 | 该模式下可执行对实例或设备的修改、配置等操作，不支持的操作按钮置灰。例如，执行升级、 漂移、启停等操作，必须进入维护模式。 维护模式下，对于已开启保护的实例（即非HSM侧开通的密码实例）仍不能进行释放、配置和解绑，如需释放，请先关闭实例保护。 |

**重要**

从正常模式切换到维护模式后，用户侧将不能执行对实例的配置、释放等操作，做完运维变更后，请及时切换回正常模式。 此处的模式选择会影响Apsara Uni-manager运营控制台的相关操作，详细介绍，请参见**用户**
**指南**。
例如，此处您选择的是维护模式，登录Apsara Uni-manager运营控制台后，创建、配置、释放、创建集群等操作按钮将置灰，并提示**后台已进入维护模式，该操作不可执行。如需操作，请**

## 日志运维

当管理员需要对加密服务过往的操作进行回溯时，可以通过日志来分析回溯需求。包括安全审计日志、服务运行日志。

**说明**

1、安全审计是一项长期的安全管理活动，贯穿云服务使用的生命周期。安全审计功能收集系统安全相关数据，分析系统运行情况中的薄弱环节，并上报审计事件给管理员进行分析和改进，从而确保云服务的安全可靠。 2、加密服务的日志也会收集到SLS，可通过SLS的portal或API分析日志。如果SLS没有portal，则需要登录到部署加密服务机器，在机器中查看相关日志。因请求是随机分发到机器上的，所以要逐个机器进行查看。

### 服务运行日志

通过查看加密服务运行日志，可回溯加密服务过往操作，同时也可协助定位和排查服务在运行过程中出现的加密服务

**操作步骤**

1. 登录Apsara Uni-manager运维控制台。
2. 在顶部菜单栏，选择**平台运维** > **飞天基础运维平台** > **资源管理**。
3. 单击**产品集群运维**。
4. 在**产品**|**集群**搜索框输入 `hsm` ，单击 `hsm-hsmmastercluster-xxxx` 集群**操作**列的**集群详情**。
5. 在集群详情页面的**服务**搜索框，输入**hsm**后，单击目标服务**操作**列的**详情**。
6. 单击**实例列表**页签。定位到目标实例后，单击**操作**列的**Terminal**。
7. 在服务终端，输入如下命令，进入服务容器。

```bash
sudo docker ps -a | grep hsm sudo docker exec -it containerId bash
```
