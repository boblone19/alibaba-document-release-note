### 告警设置

告警设置支持设置告警联系人和告警规则。当监控数据满足报警规则时，系统自动发送告警信息给报警联系人，支持钉钉消息和邮件。本文介绍如何添加和管理告警联系人。

**设置告警联系人**

1. 登录Apsara Uni-manager运营控制台。
2. 在控制台右上方，单击**安全**，选择**全局平台安全** > **系统配置**。在**系统配置**授权页面，选择**地域**并单击角
**色授权访问**。
3. 在左侧导航栏，选择**告警设置** > **告警设置**页签。
4. 单击**添加联系人**。填写联系人姓名、钉钉机器人Token、邮箱、组织（支持多级组织维度）等，单击确
定。 添加后的联系人可以在联系人列表查看，支持**编辑**、**批量删除**。

**设置安骑士告警规则**

1. 登录Apsara Uni-manager运营控制台。
2. 在控制台右上方，单击**安全**，选择**全局平台安全** > **系统配置**。在**系统配置**授权页面，选择**地域**并单击角
**色授权访问**。
3. 在左侧导航栏，选择**告警设置** > **告警设置**。
4. 在**安骑士**页签，设置要发送的告警规则后，单击**保存**。

## 云产品管理

### 安骑士运维

#### 高风险管理

**操作步骤**

1. 登录云盾运维中心。
2. 在左侧导航栏，选择**云产品管理** > **安骑士运维** > **高风险管理**。
3. 管理安骑士高风险模块。
开启或关闭**物理机安骑士**/**漏洞管理**：此功能默认关闭，开启后会打开物理机安骑士漏洞管理功能。使用此功能会暴露物理机漏洞风险，开启需谨慎。 开启或关闭**物理机安骑士**/**基线检查**：此功能默认关闭，开启后会打开物理机安骑士基线检查功能，开启需谨慎。
**租户安骑士多级组织开关**：此功能默认关闭，开启后会使租户侧安骑士开启多级组织视角，所有数据的
权限都将关联到组织下的资源集维度，可能涉及大量数据更新，开启需要较长时间。此功能开启需要申请挑战码，且开启后将无法关闭或回退，请谨慎操作。
**ASCM-****云盾数据同步**：单击**同步信息**，可手动将云管平台ASCM的数据同步至云盾，包括组织信息、
资源集信息和资产信息，可能涉及大量数据更新，需要较长时间完成。使用此功能需要申请挑战码，请谨慎操作。
**平台安全风险巡检****(eScan)** ：此功能用于专有云TAM、安全服务人员，用于巡检云平台安全风险，包
括：网络隔离风险、配置不当风险、应用风险等。单击进入管理界面，可管理**平台安全风险巡检**
**(eScan)**。更多信息，请参见什么是云平台安全风险巡检。
**安骑士告警归档周期**：您可以设置告警归档周期的时间，对超过时间设置的告警将在安骑士告警页面做
清除处理，并压缩归档至OSS存储。可通过拥有一级组织权限的用户登录安骑士>安全告警>归档数据下载查看。

#### 灰度策略管理

**操作步骤**

该操作会在所有租户、整个平台生效。请用户在进行灰度策略管理时，联系您的技术支持人员。
1. 登录云盾运维中心。

## 升级中心

### 升级中心概述

升级中心通过自动和手动方式，对专有云云盾的特征库和版本进行升级等操作，确保专有云及时获取最新的安全保障。 升级时，用户可以按照如下步骤，进行升级：
1. 配置升级包导入方式。
升级中心支持**在线自动导入**、**离线手动导入**。 专有云环境和公网互通，可以选择**在线自动导入**升级包方式。 专有云环境和公网不通，可以选择**离线手动导入**升级包方式。选择该种方式时，需要下载升级包。
2. 升级特征库、版本。具体操作，请参见升级特征库或版本。

### 升级特征库或版本

升级中心支持通过离线手动导入、在线自动导入升级包的方式，升级特征库或版本。本文介绍如何进行升级操作。

**操作步骤**

1. 登录云盾运维中心。
2. 在左侧导航栏，单击**升级中心**。
3. 在**升级配置**页签，配置升级包导入方式。

**离线手动导入**

如果专有云环境无法与公网连通，可以通过离线手动导入升级包的方式更新特征库和版本。 a. 选择升级包导入方式为**离线手动导入**，单击**生成升级标识符**，下载升级包。 b. 单击上传导入升级包，将已下载的升级包拖动到上传虚拟框内，或单击图标，上传升级包。

**说明**

上传升级包前，请先单击**手动导入离线升级包**对话框的网站链接，并信任此证书。 升级包导入成功后，用户可在特征库和版本升级页面查看升级包，执行升级操作。

**在线自动导入**

如果专有云环境无法与公网连通，可以通过在线自动导入升级包的方式更新特征库和版本。

**说明**

导入提示： 1、需要云盾产品服务能够访问互联网。 2、申请或使用已有阿里云公有云账号（不建议使用个人账号），该账号将作为在线自动获取升级包的用户标识。 3、配置完成后，将自动获取云盾及相关规则库的最新升级包并自动导入，导入成功后，即可在特征库和版本更新页面查看升级包，执行升级操作。 云盾 a. 选择升级包导入方式为**在线自动导入**，完成如下配置。

| 配置项 | 说明 |
|---|---|
| 阿里云账号ID | 输入阿里云账号ID。 |
| Access Key | 输入Access Key。 |
| Access Secret | 输入Access Secret。 |
| 自动升级时间段 | 选择自动升级的时间段。支持选择： 0~6时 0~8时 0~24时 22~6时 |
| SLB IP | 可以连接公网的SLB的IP地址。 |

b. 单击**连通性测试**。 c. 无问题后，用户可以选择开启**自动更新**开关。 启用**自动更新**后，系统能定期下载升级包。

## 安全审计

### 概述

云盾的安全审计能够收集系统安全相关的数据，分析系统运行情况中的薄弱环节，上报审计事件，并将审计事件分为高、中、低三种风险等级。通过安全审计，安全管理员可以回溯系统过往的操作，并且还可以关注、分析审计事件，从而持续改进系统。 安全审计是一项长期的安全管理活动，贯穿云服务使用的生命周期。

本文介绍如何设置安全审计的告警接收人。

**背景信息**

设置告警接收人后，在发生审计事件时，系统会将事件上报至所设置的告警接收人的邮箱中。

**操作步骤**

1. 登录Apsara Uni-manager运维控制台。
2. 在控制台右上方，单击**安全管理**，选择**安全审计** > **云盾安全审计**。
3. 在**安全审计**页面，单击**策略设置**。
4. 在**策略设置**页签，单击**告警设置**。
5. 新增告警接收人。
i. 单击**新增**。 ii. 在**新增报警接收人**对话框，配置告警接收人信息。

| 参数 | 说明 |
|---|---|
| 邮箱 | 设置报警接收人的邮箱。 |
| 姓名 | 设置报警接收人的姓名。 |
| 审计类型 | 设置审计类型。包含主机、网络设备、ECS、云产品、租户数据库、平台数据库。 |
| 审计对象 | 根据设置的审计类型，选择审计对象。 |
| 风险等级 | 设置操作的风险级别。包含全局风险、紧急、高危、中危、低危。 |

iii. 单击**确定**。
6. 管理告警接收人。
查询告警接收人选择**审计类型**、**审计对象**、**风险等级**，输入邮箱关键字，单击**查询**，查看当前已设置的告警接收人。 删除告警接收人云盾邮箱列表中，在对应邮箱的操作栏下，单击**删除**，可删除告警接收人。

#### 查询事件日志存档

本文介绍如何查询和下载审计事件和原始日志的存档。

**背景信息**

管理员可以下载事件和日志的存档信息到本地，进一步分析审计事件问题，保障专有云环境的安全。

**操作步骤**

1. 登录Apsara Uni-manager运维控制台。
2. 在控制台右上方，单击**安全管理**，选择**安全审计** > **云盾安全审计**。
3. 在**安全审计**页面，单击**策略设置**。
4. 在**策略设置**页签下，单击**存档管理**。
5. 查询事件日志归档信息。
系统默认自动存储185天的日志。 i. 设置**审计类型**、**归档类型**。 ii. 设置查询的时间段。
6. 下载审计事件或原始日志的存档文件。
单个下载：在目标存档文件的**操作**栏，单击**下载**，可将存档文件保存到本地。 批量下载：选中多个目标存档文件，在文件列表下方单击**批量下载**，可在**导出管理**中下载保存至本地， 列表页默认显示20条存档文件信息，如果您需要单次查看或下载更多存档文件，您可以在右下角调整每页可显示的存档文件数。

#### 修改系统配置

本文介绍如何设置安全审计的系统参数。

**背景信息**

通过设置安全审计的系统参数，可以配置系统单日最大报警次数及各类型原始日志的单日最大审计量。

**操作步骤**

1. 登录Apsara Uni-manager运维控制台。
2. 在控制台右上方，单击**安全管理**，选择**安全审计** > **云盾安全审计**。
3. 在**安全审计**页面，单击**策略设置**。
4. 在**策略设置**页面，单击**系统设置**。
5. 在设置项的**操作**栏，单击**编辑**。
6. 填写对应的参数值，单击**确认**。
其中-1表示无限制。

**重要**

每天审计原始日志总量、平台数据库、租户数据库原始日志量超过所配置的阈值上限后，原始日志和审计事件将不在进行归档存储，但仍将继续审计原始日志和审计事件。
