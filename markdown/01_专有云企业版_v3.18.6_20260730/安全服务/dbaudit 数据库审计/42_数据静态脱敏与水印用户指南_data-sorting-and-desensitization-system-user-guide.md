**前提条件**

确认您所使用的账号已具备相应部门的云资源权限，例如具备部门管理员角色权限。

数据静态脱敏与水印系统通过镜像方式部署在专有云的服务器中。数据静态脱敏与水印系统能够检测发现环境中的数据库，并提供数据脱敏和水印功能。

**操作步骤**

3. 在左侧导航栏，单击**数据静态脱敏与水印**。
4. 单击**创建实例**，在**创建实例**页面，创建云盾数据静态脱敏与水印系统。

### 脱敏基本操作流程

#### 脱敏流程介绍

本文介绍数据脱敏的流程。

**脱敏流程**

1. 创建数据源或文件源。
如果目标为与源不同的数据库，需要额外创建一个数据源作为脱敏目的库。
2. 创建并执行发现任务，对源数据的敏感数据进行发现。
3. 敏感数据梳理。
对系统发现的敏感列进行人工复核与标记，确保识别结果的准确性。
4. 创建并执行脱敏。
基于梳理结果制定脱敏规则，创建并运行脱敏任务，将处理后的安全数据写入目标库或生成新文件。

**脱敏效果**

### 基本概念

| 名词 | 说明 |
|---|---|
| 数据库脱敏 | 对存在于数据库中的数据进行脱敏，可以脱敏到数据库或脱敏成文件。 |
| 文件脱敏 | 对某些特定文件进行脱敏，可以脱敏到数据库或脱敏成文件。 |
| 数据库源 | 即一个确定的数据库，可作为数据库脱敏的数据来源或脱敏后数据的目的库。 |
| 文件源 | 文件源相当于数据库的概念，是一组文件的集合可以通过Web页面直接上传文件到本地。文件源下存放的文件是具有一定数据特征的结构化文件，例如：标准CSV和TXT格式的文件、EXCEL文件、DMP文件。文件源可作为文件脱敏的数据来源。 |
| 发现规则 | 识别敏感数据的规则，通过发现规则从众多数据项中识别出潜在的敏感数据。 |
| 脱敏算法 | 对敏感数据进行脱敏的算法，例如遮蔽、替换等。 |
| 发现任务 | 按照一定发现规则发现数据库表或文件中敏感数据的任务。 |
| 敏感字段核实 | 即敏感字段梳理，是指数据库源的发现任务执行后，人工核实表字段的敏感数据类型。 |
| 敏感文件核实 | 即敏感文件梳理，是指文件源的发现任务执行后，人工核实文件列的敏感数据类型。 |
| 数据子集 | 配置需脱敏表的集合，文件源脱敏无数据子集这个概念（DMP文件脱敏除外）。完成敏感字段核实后，可以手动创建数据子集，也可以直接创建脱敏任务，在脱敏任务中选择需脱敏表的范围，跳过配置数据子集这一步。 |
| 脱敏方案 | 对选定需脱敏的敏感字段或文件列，配置其采用何种脱敏算法，例如遮蔽、替换等。数据库脱敏在创建完数据子集后，可以手动创建脱敏方案，也可以直接创建脱敏任务，在脱敏任务中配置需脱敏表的范围和敏感字段的脱敏算法，跳过配置数据子集和脱敏方案步骤；文件源脱敏在完成敏感文件核实后，可以手动创建脱敏方案，也可以直接创建脱敏任务，在脱敏任务中配置敏感列的脱敏算法，跳过配置脱敏方案步骤。 |

| 分组字典 | 即数据字典指定分组列，分组字典结合脱敏方案的分组列配置使用，可以实现分组不变组内数据替换脱敏的效果。 例如一班有张三、李四、王五，二班有赵六、郑七，分组字典可以实现班级列数据（一班、二班）保持不变，人名列在班级内脱敏，即班级列为一班，人名列只会脱敏成一班下的人，班级列为二班，人名列只会脱敏成二班下的人。 |
| 字段字典 | 即字段名的集合，配合自定义字段字典发现规则使用，用于敏感数据发现，当字段名存在于字段字典中， 该字段被当做敏感数据。 |
| 脱敏方案模板 | 指定某种敏感数据类型使用何种脱敏算法和脱敏参数。 |
| 文件模板 | 指定文件是否带表头、字符集、字段分隔符、字段包围符等信息，用于发现任务和文件源脱敏的文件解析。 |

| 伪列水印 | 在关系型数据中通过对数据库表增加的非真实数据列，即增加的列数据是伪造出来的并与原始数据有相关性的数据。在增加的数据列中嵌入可提取的水印规则信息。 |
| 水印方案 | 针对不同使用场景，制定数据抽取和生成水印的方案。 |
| 水印任务 | 根据不同的水印方案，执行数据抽取、生成水印、输出数据的行为。 |
| 数据溯源 | 对泄漏数据进行水印信息的提取，并根据提取的水印标识查询到数据的分发源、分发对象等相关信息。 |

### 列加密

#### 设置列加密

列加密功能是一项数据安全技术，通过对数据库中的特定列进行加密存储，实现对数据库敏感列数据的加密访问，防止非授权人员通过云平台软件或数据库连接工具直接获取敏感数据明文，从而有效抵御内外部安全

**概述**

列加密功能包含**加密设置**以及**数据库账号权限**两部分，前者用于定义加密算法、方式及范围，后者则用于控制可访问加密数据的数据库账号及其权限。 列加密功能采用行业标准的加密算法，加密方式为使用本地密钥。

**重要**

PolarDB-X 2.0类型数据库还支持KMS密钥加密，其他数据库类型不支持。 南

被认为是敏感数据。 南在此方式下配置**确认比例**（抽样数据被认为是敏感数据的百分比达到确认比例后，该列被认为是此发现规则类型的敏感数据）、预判断设置、发现逻辑设置和推荐脱敏算法。
**预判断设置**是可选配置，可以配置自定义的字符数量或字符位置规则，在匹配正则前先进行数据校验，
如果数据不满足预判断规则，直接认为该数据非敏感而不会走到正则匹配流程。您可以在**预判断设置**页签下，选择规则类型（字符数量规则或字符位置规则），单击添加图标进行配置。
**发现方式**为**按复合方式发现**：当同一列以定长或指定分隔符方式存储多种敏感数据时（定长数据
如“01200501013015001234567“，前面12位固定为学号，后面11位固定为手机号，数据长度固定 23位；指定分隔符数据如“张三|15001234567“中文姓名和手机号码用|分隔），可以使用复合发现规则，按照数据格式配置发现规则，对同时存多种敏感数据的列进行敏感数据发现，需配合复合脱敏算法使用。 在此方式下配置**确认比例**，在**数据拆分**页签下配置数据拆分类型（定长按位拆分或按分隔符拆分）， 在**推荐脱敏算法**页签下选择推荐脱敏算法（一般是自定义复合脱敏算法）。
**数据拆分**配置说明：
南选择**拆分类型**为**按位拆分**，输入数据样本数据，单击**拆分**，可以获取数据位数拆分图（可以看出敏感数据从第几位到第几位），然后单击**添加区间**，添加敏感数据区间，指定敏感数据的开始结束位数以及敏感数据发现规则，可重复添加区间。 选择**拆分类型**为**按分隔符拆分**，输入分隔符后单击右侧添加图标（多分隔符可重复多次），输入全部隔符后，输入样本数据，单击拆分，然后为分隔符分隔的多个分段选择敏感数据发现规则。
5. 在测试样本区域，输入用于测试的数据值，单击**测试**。
6. 测试通过后，单击右上角的保存
图标。

#### 脱敏算法

**添加自定义算法**

1. 登录数据静态脱敏与水印系统。

图标。
4. 在右侧设置算法名称和算法类型。
**算法类型**配置说明：
**复合脱敏算法**：适用于分段复合的敏感数据，按照各段对应的基础脱敏算法进行脱敏。针对同一行同一
列以定长或分隔符方式存储多种敏感数据的数据进行脱敏，与复合发现规则配合使用。发现规则的具体内容，请参见**发现规则**章节。 如果无对应复合发现规则，无法创建复合脱敏算法。
**混合脱敏算法**：适用于一列数据中多种敏感数据混合的数据，根据多种发现规则匹配情况，按照发现规
则对应的基础脱敏算法进行脱敏。针对同一列不同行存储多种敏感数据的数据进行脱敏。 在**脱敏参数**中，单击**添加基本算法**，为某种发现规则添加脱敏算法及参数，可重复添加不同的发现规则。 混合脱敏算法作用是，需脱敏的数据按照排序第一的发现规则去发现，如果匹配则按照排序第一发现规则对应的脱敏算法脱敏，如不匹配则按照排序第二的发现规则去发现，以此类推。
**自定义函数算法**：使用自定义JS函数进行脱敏，输入为需脱敏数据，返回值为脱敏后数据。适用于处理
自定义业务逻辑的脱敏任务。 在**脱敏参数**的**自定义脱敏算法函数**输入框中，输入自定义JS函数的脱敏算法函数。 南在**脱敏参数**中，单击**添加基本算法**，为某种发现规则添加脱敏算法及参数，可重复添加不同的发现规则。
