# 专有云DNS 域名解析DNS（跨云）用户指南

专有云DNS

## 什么是域名解析DNS（跨云）

域名解析DNS（跨云）是运行在阿里云专有云环境的一套DNS域名解析产品，为多个专有云环境提供跨云共享域名解析服务。 域名解析DNS（跨云）通过设置域名与IP地址的对应规则和策略，可以将来自客户端的域名访问请求重定向到云平台中的云资源、企业内网的业务系统、互联网服务提供商的服务资源等。 专有云DNS 明

## 跨云共享域名

### 概述

适用于多云融合场景，配置信息在多朵云间全局同步，为多云融合后的所有应用提供全局域名解析。

### 添加和管理域名

**添加域名**

1. 登录DNS控制台。
2. 在左侧导航栏，选择**跨云域名服务** > **跨云共享域名**。
3. 在**跨云全局域名**页面，单击**添加域名**。
4. 在**创建调度域**弹出框中，输入**调度域名称**，单击**确定**。

**说明**

i. 一个域名最长不能超过220个字符（包括结尾的"."）。 ii. 域名可以分为域名段，中间用"."连接，每个域名段不能超过63个字符，并且不能为空（即不能出现连续的多个"."）。 iii. 域名只能使用大小写字母（a-zA-Z）、数字（0-9）、连字符"-"、下划线"_"，出现其他字符均为非法。 iv. 域名不区分大小写。 v. 域名必须以“.”结尾。

**后续操作**

**查看域名**

在**跨云全局域名**页面，可以通过列表查看已添加的域名，包括**域名名称****/ID**、**解析记录集总数**、**备注**、**创建**
**时间**、**最后修改时间**等。
支持通过输入域名名称进行搜索。 单击列表右上角图标，支持自定义显示/隐藏列表项，以及拖拽调整列表项顺序。

**备注域名**

备注域名主要用于标记域名，例如主机名、内部系统信息等。
1. 在**跨云全局域名**页面，找到目标域名，单击**操作**列中的**备注**。
2. 在**备注调度域**弹出框中，输入**备注**，单击**确定**。

**删除域名**

**说明**

调度域被删除后，该调度域下的所有调度实例都将被删除，请谨慎操作！
1. （方式一）在**跨云全局域名**页面，找到目标域名，单击**操作**列中的**删除**。
专有云DNS （方式二）在**跨云全局域名**页面，勾选待删除的一个或者多个域名，单击左下角**批量删除**。
2. 在弹出框中，单击**确定**。
