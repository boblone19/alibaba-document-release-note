# 专有云DNS 域名解析DNS（云内）用户指南

## 什么是专有云DNS

专有云DNS是运行在阿里云专有云环境的一套DNS域名解析产品，为专有云环境提供域名解析服务。专有云 DNS通过设置域名与IP地址的对应规则和策略，可以将来自客户端的域名访问请求重定向到云平台中的云资源、企业内网的业务系统、互联网服务提供商的服务资源等。 专有云DNS为VPC网络环境提供基础DNS解析调度服务。通过专有云域名解析DNS，您在自己的VPC内可以进行如下操作： 访问VPC内的其他ECS主机。 访问云平台提供的云服务实例资源。 访问客户自定义的企业级业务系统。 访问互联网上的业务和服务。 通过企业专线，与企业自建DNS实现互通。 明

## 云内域名服务

### 云内全局域名

云内全局域名管理用户在专有云中创建的全局内网域名、全局转发配置以及全局递归开关配置。

#### 概述

适用于多云融合场景，配置信息在多朵云间全局同步，为多云融合后的所有应用提供全局域名解析。

**添加解析记录**

|---|---|
| AAAA-将域名指向一个IPv6地址 | 一行请输入一个IPv6地址（允许输入多行，最多支持100条记录值， 不允许重复输入）。 格式要求：IPv6地址标准书写格式。 示例如下： 2400:3200::6666 2400:3200::6688 2400:3200::8888 |

| MX-将域名指向邮件服务器地址 | 一行请输入一条邮件服务器信息（允许输入多行，最多支持100条记录值，不允许重复输入）。 格式要求： [优先级][空格][邮件服务器主机名] 优先级：要求为 0 - 999 的整数，数值越小优先级越高。 邮件服务器主机名：要求为含有结尾.的全限定域名，长度限制254 个ASCII字符。 示例如下： 10 mailserver1.example.com. 20 mailserver2.example.com. |

| SRV-记录提供特定的服务的服务器 | 一行请输入一条应用服务信息（允许输入多行，最多支持100条记录值，不允许重复输入）。 格式要求： [优先级][空格][权重][空格][端口号][空格][应用服务器主机名] 优先级：要求为 0 - 999 的整数，数值越小优先级越高。 权重： 要求为 0 - 999 的整数，数值越大权重占比越大。 端口号：要求为 0 - 65535 的整数，表示TCP或者UDP的端口号。 应用服务器主机名：要求为含有结尾.的全限定域名，长度限制254 个ASCII字符。 示例如下： 1 10 8080 www1.example.com. 2 20 8081 www2.example.com. |

| CAA-为域名设置证书分发机构授权信息 | 一行请输入一条CAA记录（允许输入多行，最多支持100条记录值， 不允许重复输入）。 格式要求： [认证机构限制标志][空格][证书属性标签][空格][授权信息] 认证机构限制标志：要求为 0 - 255 的整数。 证书属性标签：支持3个可选值，issue、issuewild 和 iodef。 授权信息：取值不可以为空，长度限制254个ASCII字符，需要使用半角双引号括起来。 示例如下： 0 issue "caa.example.com" 0 issuewild ";" 0 iodef "mailto:example@example.com" |

#### 全局转发配置

##### 概述

该功能所有操作需要系统管理员权限。 域名解析DNS提供域名级别的转发操作，将特定域名的解析操作转发到其他DNS服务器上进行解析。 转发域名功能提供两种转发操作模式，强制转发模式和优先转发模式。 在强制转发模式下，设置只使用转发目的DNS服务器做域名解析，如果解析不到（解析超时）则返回DNS 客户端提示查询失败。 在优先转发模式下，设置优先使用转发目的DNS服务器做域名解析，如果查询不到再使用本地DNS服务器做域名解析。

| 记录类型 | 记录值格式要求 |

| A-将域名指向一个IPv4地址 | 一行请输入一个IPv4地址（允许输入多行，最多支持100条记录值， 不允许重复输入）。 格式要求：IPv4地址标准书写格式。 示例如下： 192.168.1.1 192.168.1.2 192.168.1.3 |
|---|---|
| AAAA-将域名指向一个IPv6地址 | 一行请输入一个IPv6地址（允许输入多行，最多支持100条记录值， 不允许重复输入）。 格式要求：IPv6地址标准书写格式。 示例如下： 2400:3200::6666 2400:3200::6688 2400:3200::8888 |

| MX-将域名指向邮件服务器地址 | 一行请输入一条邮件服务器信息（允许输入多行，最多支持100条记录值，不允许重复输入）。 格式要求： [优先级][空格][邮件服务器主机名] 优先级：要求为 0 - 999 的整数，数值越小优先级越高。 邮件服务器主机名：要求为含有结尾.的全限定域名，长度限制254 个ASCII字符。 示例如下： 10 mailserver1.example.com. 20 mailserver2.example.com. |

|---|---|
| SRV-记录提供特定的服务的服务器 | 一行请输入一条应用服务信息（允许输入多行，最多支持100条记录值，不允许重复输入）。 格式要求： [优先级][空格][权重][空格][端口号][空格][应用服务器主机名] 优先级：要求为 0 - 999 的整数，数值越小优先级越高。 权重： 要求为 0 - 999 的整数，数值越大权重占比越大。 端口号：要求为 0 - 65535 的整数，表示TCP或者UDP的端口号。 应用服务器主机名：要求为含有结尾.的全限定域名，长度限制254 个ASCII字符。 示例如下： 1 10 8080 www1.example.com. 2 20 8081 www2.example.com. |

| CAA-为域名设置证书分发机构授权信息 | 一行请输入一条CAA记录（允许输入多行，最多支持100条记录值， 不允许重复输入）。 格式要求： [认证机构限制标志][空格][证书属性标签][空格][授权信息] 认证机构限制标志：要求为 0 - 255 的整数。 证书属性标签：支持3个可选值，issue、issuewild 和 iodef。 授权信息：取值不可以为空，长度限制254个ASCII字符，需要使用半角双引号括起来。 示例如下： 0 issue "caa.example.com" 0 issuewild ";" 0 iodef "mailto:example@example.com" |
|---|---|
| NS-将子域名指向指定的DNS服务器解析 | 一行请输入一个DNS服务器地址（允许输入多行，最多支持100条记录值，不允许重复输入）。 格式要求：含有结尾.的全限定域名，长度限制254个ASCII字符，不允许出现泛域名。 示例如下： ns1.example.com. ns2.example.com. |

地址池发生修改后，如果已经开启了健康检查，那么所有地址值的健康检查结果会全部重置为正常；已关联访问策略并且设置了自动切换模式的情况下，有可能触发主备切换，请谨慎操作！
1. 在**地址池**页面，找到目标地址池，单击**操作**列**修改**。
2. 在**修改地址池**页面，修改**地址池名称**、**地址列表**，单击**确定**。
具体参数说明，请参考创建地址池。

**删除地址池**

**重要**

待删除的地址池需要与所有调度实例解除关联，方可删除！！！
1. （方式一）在**地址池**页面，找到目标地址池，单击**操作**列**删除**。
（方式二）在**地址池**页面，勾选待删除的一个或者多个地址池，单击左下角**批量删除**。
2. 在弹出的对话框中，单击**确定**。
在**地址池**页面，单击**操作**列**操作日志**，可以查看目标地址池的操作日志。具体请参见查看操作日志。

#### 健康检查

只有健康检查状态正常的地址值才会被返回。本文介绍如何对地址池内的地址值进行健康检查。

**创建健康检查**

1. 登录DNS控制台。
2.
3. 在**地址池**页面，找到目标地址池，单击**操作**列**健康检查**。
4. 在**健康检查**页面，单击**创建健康检查**。
5. 在**创建健康检查**页面，根据以下内容配置健康检查，单击**确定**。

| 配置参数 | 说明 |
|---|---|
| 探测开关 | 选择开启或关闭探测开关。 |
| 探测协议 | 选择探测协议。 HTTPS HTTP TCP UDP ICMP |
| 端口 | 输入对目标地址进行健康检查使用的网络端口号。 默认值：80。取值范围是 1~65535 的整数，参数不能为空。 说明当探测协议选择HTTPS/HTTP/TCP/UDP时，该参数需要设置。 |

| Host设置 | 输入用于健康检查探测的HOST配置。示例：www.example.com 缺省不填时自动设置为主域名。 说明当探测协议选择HTTPS/HTTP时，该参数需要设置。 |
|---|---|
| URL路径 | 用于确认目标地址的HTTP/HTTPS服务是否正常，即该路径返回的HTTP状态码为 2xx 或者 3xx 即为正常。 路径可以为空，系统会自动添加前导 /，默认值为 /。总长度不超过255。 说明当探测协议选择HTTPS/HTTP时，该参数需要设置。 |
| 返回码大于 | 设定健康检查判定为异常时，HTTP返回码数值应该大于的值。 默认值：400。 说明当探测协议选择HTTPS/HTTP时，该参数需要设置。 |
| 检查间隔(s) | 输入对目标地址进行健康检查探测的时间间隔。默认值：15。 |
| 超时时间(s) | 输入对目标地址进行健康检查探测，异常发生时等待的超时时间。默认值：3。 |
| 重试次数 | 输入对目标地址进行健康检查探测出现异常时的重试次数。默认值：1。 |
| 探测节点 | 选择VPC网络节点。要求至少选择两个。 |

## 管理标签

云解析DNS支持标签功能，您可以通过标签功能对租户内网域名、租户转发域名列表、租户默认转发配置和私有线路等实例进行标记和分类，便于资源的搜索和聚合。本文为您介绍如何管理及使用标签功能。

**标签概述**

随着实例数量的增多，会使实例的管理难度增加，可通过标签将实例进行分组管理，有助于搜索和筛选实例。 标签是为实例分配的标记，每个标签都由一对键值对（Key-Value）组成。标签的使用说明如下： 单个实例上单条标签的标签键（Key）必须唯一。 标签的键与值可以修改，也可以随时删除。如果实例被删除，该实例绑定的所有标签也都会被删除，该操作不会影响其他实例的标签绑定功能。 一个实例最多可以绑定20个标签，暂不支持提升配额。

**绑定标签**

1. 登录DNS控制台。
2. 通过导航栏，选择具体实例类型。
3. 根据以下信息为实例绑定标签。
为单个实例添加标签 a. 在对应实例类型页面，找到目标实例，鼠标悬停在**标签**列的图标上，单击气泡框中的**编辑**。 b. 在**编辑标签**对话框中，根据以下信息配置标签，单击**添加**可绑定多个标签，然后单击**确定**。

| 配置 | 说明 |
|---|---|
| 标签键 | 标签的标签键，支持选择已有标签键或输入新的标签键。 标签键最多支持64个字符，不能以 aliyun 或 acs: 开头，不能包含 http:// 和 https:// 。 |
| 标签值 | 标签的标签值，支持选择已有标签值或输入新的标签值。 标签值最多支持128个字符，不能以 aliyun 或 acs: 开头，不能包含 http:// 和 https:// 。 |

c. 在**标签编辑成功**对话框中，确认标签编辑结果，单击**关闭**。 为多个实例添加标签 a. 在对应实例类型页面，勾选列表左侧复选框选中所有需要绑定标签的目标实例，单击左下方**批量绑定**
**标签**。
b. 在**批量绑定标签**对话框，添加**标签键**和**标签值**，然后单击**确定**。 c. 在**标签编辑成功**对话框中，确认标签编辑结果，单击**关闭**。

**解绑标签**

1. 登录DNS控制台。
2. 通过导航栏，选择具体实例类型。
3. 根据以下信息为实例解绑标签。
单个实例解绑标签 a. 在对应实例类型页面，找到目标实例，鼠标悬停在**标签**列的图标上，然后单击气泡框中的**编辑**。 b. 在**编辑标签**对话框，单击目标标签右侧的图标可删除当前行的标签，然后单击**确定**。 c. 在**标签编辑成功**对话框中，确认标签编辑结果，单击**关闭**。 批量解绑标签 a. 在对应实例类型页面，勾选列表左侧复选框选中所有需要解绑标签的目标实例，单击左下方**批量解绑**
**标签**。
b. 在**批量解绑标签**对话框，在**需要解绑的标签**下选中所有需要解绑的标签，然后单击**确定**。 c. 在**标签编辑成功**对话框中，确认标签编辑结果，单击**关闭**。

**使用标签搜索实例**

为实例绑定标签后，您可以通过标签快速筛选出目标实例。
1. 登录DNS控制台。
2. 通过导航栏，选择具体实例类型。
3. 在对应实例类型页面，选择**高级筛选** > **标签筛选**。
4. 在弹出的选项框中，勾选**标签键**和**标签值**，然后单击**搜索**。系统将根据选择的标签键和标签值筛选出目标
实例。

## 查看操作日志

您可以查看云解析DNS相关实例的操作日志，通过查看操作日志，可以了解实例运行的状态、操作来源、操作时间、API调用详情等信息，便于对历史操作进行分析和回溯。

**操作步骤**

1. 登录DNS控制台。
2. 通过导航栏，选择具体实例类型。
3. 在对应实例列表页面，找到目标实例，单击**操作**列的**操作日志**。
4. 在**操作日志**页面，查看目标实例的操作日志。

**说明**

当前操作日志保存时长为30天，如需调整，需管理员在配置-日志转存配置中操作配置。 若通过转存设置延长保存时长，日志数据不会做前序时间数据补充。
5. **可选：**可以按**操作名称**、**操作人**等过滤条件进一步筛查出所需关注的操作记录，支持的过滤条件如下表所
示。

| 过滤条件 | 说明 |
|---|---|
| 操作人 | 输入执行变更操作的操作者。 |
| 操作名称 | 选择目标实例的变更操作名称，即API名称。 |
| 执行状态 | 选择执行状态为成功或失败。 |
| 操作源IP | 输入操作源IP。 |
| 操作时间 | 选择需要查看的时间范围。 |

6. **可选：**单击目标操作事件**操作**列的**操作详情**，在弹出面板，可以查看**操作详情信息**，包括**基本信息**和**API**
**调用详情**。
