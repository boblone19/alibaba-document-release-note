## 登录Apsara Uni-manager运维

**控制台**

本文介绍运维工程师等相关用户如何登录到Apsara Uni-manager运维控制台。

**前提条件**

已从部署人员或管理员处获取Apsara Uni-manager运维控制台的访问地址、用户名和密码。 Apsara Uni-manager运维控制台访问地址格式为region-id.ops.console.intranet-domain-id。 推荐使用Chrome浏览器。

**操作步骤**

1. 打开浏览器。
2. 在地址栏中，输入Apsara Uni-manager运维控制台的访问地址，按回车键。

**说明**

您可以单击右上角的当前语言切换其它语言。当前支持简体中文、英文、繁体中文三种语言切换。
3. 输入正确的用户名及密码。
专有网络VPC

**说明**

登录Apsara Uni-manager运维控制台的用户名和密码请从部署人员或管理员处获取。 若连续输入密码错误三次，系统将启动图片验证码登录功能；若连续输入错误五次，账户将被锁定，请联系管理员进行激活。 首次登录Apsara Uni-manager运维控制台时，需要修改登录用户名的密码，请按照提示完成密码修改。 为提高安全性，密码必须满足以下要求： 必须包含英文大小写字母。 必须包含阿拉伯数字（0~9）。 必须包含特殊符号，包括感叹号（!）、at（@）、井号（#）、美元符号（$）、百分号（%）等。 密码长度为10~20个字符。
4. 单击**账号登录**。

### 网络拓扑

专有网络VPC 通过此功能可以查看物理网络的拓扑关系。

**前提条件**

产品BaseServiceAll的NetworkBaseServiceCluster集群已部署且已到终态。

**操作步骤**

1. 登录Apsara Uni-manager运维控制台。
2. 在顶部菜单栏，选择**产品运维** > **网络运维** > **网络运维控制台**。
3. 在左侧导航栏，选择**网络大盘** > **网络拓扑**。
4. 在**网络拓扑**页面，选择**机房**，查看目标物理机房的物理网络拓扑结构图。
网络设备的颜色代表设备的状态。 蓝色：表示对象正常。 橙色：表示对象异常。 单击**基准拓扑**或**动态拓扑**可以查看对应类型的网络拓扑图。 当选择**基准拓扑**时，在页面右上角可以开启或关闭**实时告警刷新**功能。**动态拓扑**不支持**实时告警刷新**功能。

**说明**

关闭实时告警刷新功能后，如果后续产生新的告警，拓扑图上的设备或链路状态将不再更新。 单击**更新拓扑**可以更新拓扑的偏移量。
5. 通过网络拓扑图，可以查看网络设备信息和互联链路状态。
专有网络VPC 单击目标网络设备图标，在弹出框中查看对应设备的**网络设备信息**，包括**设备基本信息**和**告警列表**。 鼠标悬浮在目标告警**告警详情**列的**详情**上，可以查看对应告警的详细信息。 单击目标网络设备间的链路，在弹出框中查看对应设备间的**互联链路状态**，包括**链路信息列表**和**告警列** 表。 鼠标悬浮在目标告警**告警详情**列的**详情**上，可以查看对应告警的详细信息。

**采集协议设置**

## 附录

### VPC修改私网Cidr方案

1. .** **概述**
专有云环境，VPC的私网地址受key_value_config_info中的private_cidr控制，绑定EIP后ECS会根据管控从该表下发的私网配置进行路由判断，以决定数据的转发路径，在一些场景下，客户需要将一些公网或者伪公网（公网私用）地址当做私网地址处理，因此需要将这些公网地址以私网网段的形式下发给AVS，调整方式为直接修改key_value_config_info中的vpc_default_private_cidr，或者调整vpc的User_cidr表，使用客户自定义的私网配置。

| 类别 | 内容 | 说明 |
|---|---|---|
| 是否可被监控发现？ | 否 | N/A |
| 临时或固化方案？ | 固化 | N/A |
| 是否涉及数据修订？ | 是 | N/A |

**风险说明**

| 评估类别 | 评估内容 |
|---|---|
| 是否影响客户业务 | 是 |
| 执行方案操作的风险描述 | 调整私网CIDR可能会导致已绑定EIP的ECS路由判断发生问题，一定要谨慎处理。 |

2. .** **解决方案**

**2.1 环境检查**

**2.1.1 检查key表，User_cidr的当前配置**

登录vpcregiondb，执行如下命令，获取当前环境vpc默认私网段配置。 如何登录vpcregiondb，请参见登录数据库中的相关内容。

```
select config_value from key_value_config_info where config_key='vpc_default_private_cidr'; select * from vpc_user_cidr where vpc_id = "涉及到变更的VPC";
```

**重要**

专有网络VPC 下发给AVS的私网段为以上两个sql输出的合集，一定要确保当前配置的网段总数量<10，如果水位已经较高（接近10），不建议再做类似变更，否则可能导致环境数据异常。（v3.6.2以上版本不受限制，变更前请确认）。

**2.1.2 获取virtualmaster地址**

登录vpcregiondb，执行如下命令:

```
select master_id from master_lock;
```

**2.2 实施步骤**

**2.2.1 修改VPC_User_Cidr配置值（按需）**

登录ecs-ag，执行如下命令：

```bash
curl "http://$master_ip:9627? method=modifyVpcAttribute&vpcId=$vpc_id&userCidr=$cidr1,cidr2,cidr3"
```

**说明**

$master_ip 在2.1.2 获取virtualmaster地址章节中获取。 $vpc_id 为本次变更涉及到的VPC。 $cidr1/2/3 根据2.1.1 检查key表，User_cidr的当前配置章节中的vpc_user_cidr表内获取的数据填写，如果这个表里面已经有三个IP或者网段，那么没法再继续调整，如果<3个，则可以补充增加到3个段。 如果客户只想调整单个VPC的路由逻辑，那么可以选择只编辑该VPC的vpc_user_cidr表；如果客户想调整所有存量以及新建VPC的路由逻辑，则可以选择更新vpc_default_private_cidr。

**2.2.2 修改vpc_default_private_cidr配置值(按需)**

1. 登录ecs-ag，执行如下命令，使用delete方式，删除不再需要的cidr，如8.8.8.8/32，或者暂时移除，
准备聚合成大段（按需）。


**问题描述**
