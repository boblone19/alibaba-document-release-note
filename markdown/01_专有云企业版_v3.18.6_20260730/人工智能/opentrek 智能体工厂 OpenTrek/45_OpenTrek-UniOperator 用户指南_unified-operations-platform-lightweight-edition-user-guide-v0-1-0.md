## 快速入门（部署LicenseMgr）

快速入门包括从导入到上线的完整实践。

### 案例背景

LicenseMgr是 OpenTrek-UniOperator 的许可证管理服务，为平台或相关应用提供软件许可证的发放、 验证、管理和审计能力，本章节以部署LicenseMgr，介绍 OpenTrek-UniOperator 产品部署能力。
1. 将该系统**导入**到平台的产品列表中。
2. 完成系统**部署**，生成可运行的产品实例。
3. 当服务商发布 v1.1.0 新版本时，将已部署的实例**升级**。
4. 当业务不再需要该系统时，将实例**卸载**并释放资源。

### 前提条件

在开始操作前，请确认以下条件已满足： OpenTrek-UniOperator 平台已正常运行并且已获取平台的登录账号和密码。 当前账号具备平台运维的访问权限。 licenseMgr 制品包（ `.tar.gz` ）已上传至部署机。

### 导入产品

获取了产品配置包后，需要将产品导入到平台的产品列表中。

**操作步骤**

1. 在左侧导航栏中，单击**产品列表**。
2. 单击页面左上方的**导入产品**按钮，打开导入对话框。
智能体工厂 OpenTrek i. 填写部署机中 CICD 制品目录的绝对路径，例如： `/data/cicd/package-dir` 。 可单击**查看填写说明**，查看CICD制品目录说明。 同时兼容支持填写旧版product-*.tar.gz 制品路径，例如： `/data/packages/product-`

```
licenseMgr.tar.gz
```

ii. 可选：单击**指定解包临时目录**自定义解压路径。 iii. 单击**生成命令**，系统生成导入脚本。 智能体工厂 OpenTrek iv. 复制该命令并在服务器终端中执行，最终提示success表示导入成功。 系统生成的命令格式如下：

```bash
curl -k -s -X POST \
  -H "ahm access key: <access_key>" \
  -H "Content-Type: application/json" \
  -d '{"filepath": "/data/packages/product-licenseMgr.tar.gz"}' \
  "http://<platform_ip>:30007/ahm/api/internal/product/importScript" | sh
```

**说明**

`tar` 解压过程中出现的 `Ignoring unknown extended header keyword` 警告可安全忽略， 不影响导入结果。 在部署机终端执行该命令，正常输出如下：

```

[OK] Registry is ready [INFO] Detected standard AHM product package Step [1] Unpacking Product Package ... [OK] Product package unpacked successfully ... success
```

v. 最后单击**完成**。
3. 导入完成后，在**产品列表**页面可以看到新导入的**licenseMgr**产品，列表显示产品名称、版本号和产品

OpenTrek-UniOperator 是面向专有云和智能运维场景的一体化产品管理与运维平台。通过产品管理，管理员可以集中管理各类 AI 及智能软件产品的发现、部署、升级和卸载操作。

## 常见问题

**Q：导入命令无响应**

可能是平台服务未就绪或网络不通，请检查平台 IP 和端口是否可达。

**Q：导入失败提示包格式错误**

可能是制品包不完整，重新打包并上传制品。

**Q：依赖检查不通过**

可能是镜像未推送到 Registry，请确认镜像已正确推送。

**Q：应用启动失败，提示连接 MySQL 失败**

可能是数据库服务不可达或密码错误，请检查 `license-mgr-mysql-svc` 服务是否存在；确认数据库名拼写为 `licence` 。

**Q：部署任务长时间处于运行中**

可能是Components Stack Check 超时，查看 Pod 事件日志： `kubectl describe pod -n ahm-`


**Q：导入产品时提示"文件路径格式不正确"，如何处理？**

使用一键导入方式时，文件路径必须以 / 开头。例如 `/data/packages/product.zip` 是正确的格式， `data/packages/product.zip` 则不正确。

**Q：部署时版本下拉列表中某些版本不可选，显示"制品未导入"或"License未授权"，如何处理？**

请联系服务商获取产品制品文件并完成导入，同时确认 License 授权信息已正确配置。您也可以在版本下拉列表顶部单击**一键导入**来快速导入制品。

**Q：升级时提示"升级版本不能低于当前版本"，如何处理？**

请确认选择的目标版本号高于当前实例版本。系统限制目标版本号第一位须与当前版本号第一位相等或 +1，不支持跨大版本升级。

**Q：下线操作是否可以撤销？**

下线操作将彻底移除实例及相关资源，操作不可撤销。如需重新使用该产品，请通过**产品管理**重新部署。

**Q：实例详情页的组件状态各颜色代表什么？**

| 颜色 | 含义 |
|---|---|
| 绿色（running/complete） | 组件运行正常或部署完成。 |
| 橙色（pending） | 组件正在启动或等待调度。 |
| 红色（failed） | 组件运行失败。 |
