# 智能体工厂 OpenTrek OpenTrek-Ops用户指南

智能体工厂 OpenTrek

## 概述

本文介绍OpenTrek-Ops平台的功能和使用方法。 OpenTrek-Ops 是基于 xClaw 范式的多智能体运维与治理平台，提供企业级 AI 智能体的全生命周期管理能力。平台围绕 Agent 的创建、部署、监控、协作和治理，为运维团队提供一站式解决方案。

**产品架构**

OpenTrek-Ops 将运维管理分为三个层次，即智能体运维、技能资产运维以及基础设施运维。通过对三个层次运维经验的积累和数据的收集，平台将运维数据汇聚到统一的治理中心中，由 OpenTrek-Ops 平台对数据进行整合分析和综合处理。 OpenTrek-Ops 平台为用户提供统一的运维 Portal，通过统一的运维入口，为用户提供一致化的运维体验。平台支持与多种基础设施服务的对接，包括 LLM Service、Redis、OSS、PostgreSQL 等，可以将运维系统中的数据通过 API 的形式提供给第三方系统。

**适用场景**

OpenTrek-Ops 适用于以下场景：
**智能运维自动化**：通过 Agent 实现运维任务的自动化执行，降低人工操作成本。
**多智能体协作**：构建 Agent 项目实现复杂运维场景的多角色协同。
**技能资产管理**：统一管理、审核和分发 Agent 技能，实现能力复用。
**运维治理**：对 Agent 运行状态、Token 消耗、错误率等进行全方位监控。

**前提条件**

已从管理员处获取 OpenTrek-Ops 平台的访问地址、用户名和密码。 推荐使用 Chrome 浏览器。

## 登录OpenTrek-Ops平台

**登录与退出**

介绍用户如何登录和退出 OpenTrek-Ops 平台。

**使用场景**

登录与退出是使用 OpenTrek-Ops 平台的基础操作，适用于以下场景： 运维人员日常访问平台进行运维操作。 管理员进行系统配置和管理。 用户完成操作后安全退出系统。

**前提条件**

已从管理员处获取 OpenTrek-Ops 平台的访问地址、用户名和密码。 OpenTrek-Ops 平台访问地址由管理员提供。 推荐使用 Chrome 浏览器。

**操作步骤**

1. 打开浏览器。
2. 在地址栏中，输入 OpenTrek-Ops 平台的访问地址，按回车键。
3. 输入正确的用户名及密码。

**说明**

若连续输入密码错误多次，系统将启动验证码登录功能；若连续输入错误达到上限，账户将被锁定，请联系管理员进行激活。 首次登录 OpenTrek-Ops 平台时，可能需要修改初始密码，请按照提示完成密码修改。为提高安全性，密码必须满足以下要求： 必须包含英文大小写字母。 必须包含阿拉伯数字（0~9）。 必须包含特殊符号。 密码长度为 10~20 个字符。
4. 单击**登录**。

**退出系统**

1. 在页面左下角单击当前登录用户右侧的
。
2. 在弹框中单击**退出登录**。

A：请确认技能已启用，且 Agent 已安装该技能。
