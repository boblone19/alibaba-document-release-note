## 产品详情

AgentRuntime 智能体运行服务是面向企业级 Agent 应用的一站式基础设施平台，提供从调试、部署到监控、升级的全生命周期管理能力。平台内置统一执行环境，支持 Python、Node.js、Java 等多语言运行时，集成安全沙箱（Code Interpreter、Browser Use）、模型接入与治理、工具调用、凭证管理及可观测能力。本文主要介绍AgentRuntime的工作原理和核心功能等。

**工作原理**

AgentRuntime采用分层架构设计，由 Agent 运行时、Sandbox 沙箱平台、模型管理中心、工具管理中心、凭证管理中心和可观测模块组成。

**核心运行层**

Agent 运行时为各类 Agent 应用提供标准化执行环境，支持零代码和高代码两种开发模式，并实现版本管理、灰度发布与弹性实例调度。

**安全执行层**

Sandbox 沙箱平台基于容器服务runD沙盒提供隔离执行环境，其中 Code Interpreter 支持 Python/Node.js/Java 代码的安全执行与文件会话管理，Browser Use 基于 VNC+Playwright 提供网页自动化能力。

**模型管理层**

支持注册管理模型服务，通过AI网关代理实现。

**工具管理层**

工具管理中心支持 MCP 协议，提供预置工具与自定义工具接入能力。

**凭证管理层**

凭证管理中心统一管理 API Key凭证，并在运行时安全注入。

**可观测层**

可观测模块基于 OpenTelemetry 实现从请求入口到模型、工具、外部依赖的全链路 Trace，并通过 Metrics 支持实时监控 Agent 执行耗时与状态。

**部署**

各模块通过标准 HTTP API（兼容 OpenAI Chat Completions 协议）与多语言 SDK（Python/Node.js）对外提供能力，支持与 LangChain、AgentScope 等主流框架集成。

**核心功能**

**统一执行环境**：为 Agent 应用提供标准化、稳定、高效的运行环境，与公共云功能对齐，确保一致的开
发和运行体验。
**全生命周期管理**：支持 Agent 应用从调试、部署到监控、升级的完整流程管理。
**多语言运行时**：内置 Python 3.0+、Node.js、Java 运行时，支持企业利用现有技术栈构建 Agent。
**安全沙箱能力**：提供 Code Interpreter（代码执行与会话管理）和 Browser Use（网页浏览、数据抓
取、表单填写）两类沙箱能力，基于 MicroVM 实现多级隔离。
**模型接入**：支持第三方模型、开源托管模型及向量模型接入，集成AI网关提供模型代理、负载均衡、超时
控制、内容安全与 Token 限流能力。
**工具管理**：支持 MCP 协议，提供工具市场，支持预置工具接入与自定义工具发布。
**凭证管理**：统一管理 Agent、Sandbox、LLM 及工具调用所需的 API Key凭证类型。
**可观测能力**：支持 Trace 链路调用可视化与 Metrics 实时监控，展示执行耗时、状态及错误信息。
**多模式开发**：支持零代码（面向业务人员）和高代码（Python/Node.js/Java 编码）两种开发方式。
AgentRuntime提供统一执行环境、全生命周期管理、多语言运行时、安全沙箱、模型管理、工具管理、凭证管理及可观测能力，支持企业基于自有技术栈开展 Agent 应用运维。 智能体工厂 OpenTrek

## 应用场景

AgentRuntime 智能体运行服务提供统一执行环境、全生命周期管理、安全沙箱及多语言运行时支持，满足企业级Agent应用在部署与运维阶段的基础需求。本文主要介绍AgentRuntime的应用场景。

**场景1：企业级AI应用全生命周期管理**

AgentRuntime平台支持从调试、部署到监控、升级的完整Agent应用生命周期管理。企业可使用 Python、Node.js、Java等语言编写的Agent应用，并通过平台进行统一管理。平台集成可观测性能力，支持调用链路追踪、日志关联和LLM调用Token消耗度量。该场景适用于企业内部AI应用团队，需要标准化部署流程、简化运维复杂度并提高开发效率的场景。

**场景2：MCP工具托管与运行环境优化**

AgentRuntime平台为MCP（Model Control Protocol）工具提供标准化的托管运行环境。在百炼平台等场景中，传统方案将多个MCP集中部署在单一ECS虚拟机上，存在环境依赖冲突、安全隔离不足、资源弹性缺失和稳定性差等问题。AgentRuntime通过容器化部署解决环境依赖问题，每个MCP打包为独立容器镜像，包含所需全部环境和依赖；通过多级隔离机制（容器隔离和沙箱隔离）提升安全性；通过按需弹性伸缩实现资源高效利用，无请求时实例可缩减至零；通过故障隔离确保单个MCP故障不影响其他服务。该场景适用于需要托管多个第三方或开源工具的企业平台，特别是对安全性和稳定性有较高要求的场景。

**场景3：安全敏感型Agent应用部署**

针对执行不可信代码的安全风险，AgentRuntime提供多维度安全隔离机制。平台支持物理或集群隔离、节点隔离、内核级隔离（强沙箱）（即将上线）和请求或会话级隔离等多种模式。管理员可预先定义不同安全等级对应的资源和策略，开发者只需选择相应安全等级即可自动应用对应隔离措施。平台整合ACK提供的 runD等强安全沙箱能力（即将上线），确保高风险任务在硬件虚拟化环境中运行，防止容器逃逸。该场景适用于金融、政务等对数据安全有严格要求的行业，需要处理敏感数据或执行外部代码的Agent应用。

**场景4：自动化任务与数据处理**

AgentRuntime支持代码执行和数据处理能力，提供安全隔离的Code Interpreter环境用于执行动态生成的代码，支持文件I/O和会话管理。同时支持浏览器自动化，通过VNC+Playwright实现网页浏览、数据抓取、表单填写等任务。平台还支持桌面应用自动化，通过GUI方式操作本地应用程序。该场景适用于需要自动化数据采集、处理和分析的企业应用，如舆情监控、市场调研、业务流程自动化等场景。

**场景5：跨部门协作的模型与工具共享**

AgentRuntime支持跨部门、跨项目的模型与工具共享机制。凭证管理模块统一存储LLM访问密钥与工具 API凭证，按项目或角色分配使用权限。Tool Hub支持自定义工具发布与内部共享，便于沉淀企业级能力资产。多个Sandbox环境可独立配置依赖与镜像，满足不同团队的技术栈差异。开发模式支持从低代码快速验证到高代码工程化落地的平滑过渡。该场景适用于大型集团企业，总部统一建设Agent基础设施，各子公司或事业部基于同一平台开发专属Agent应用，实现能力复用与标准统一。 智能体工厂 OpenTrek

## 使用限制

您在使用AgentRuntime 智能体运行服务时注意不要超过相应的限制值，以免程序出现异常。

| 分类 | 受限说明 |
|---|---|
| 集群 | 管控集群和业务集群需分开部署（至少 2 个 K8s 集群），每个集群最低配置 16C32G。 管控台需要能访问业务集群的 K8s API Server。 业务集群 AI 网关需要有外部可访问的 IP（LoadBalancer 类型 Service）。 独占模式下大量并发会话会增加集群资源压力，需根据业务规模规划集群容量。 |
| 沙箱 | 沙箱首次启动受镜像拉取和 Pod 调度影响，启动时间可能较长，建议提前做镜像预热。 |
| 凭证 | 自签名证书环境下部分操作的使用体验可能受影响。 |
| 存储 | OSS Bucket 和镜像仓库需要提前准备并确保有足够的存储配额。OSS 非必需，但如需使用零代码 Agent、沙箱状态持久化或部署加速功能则必须配置。 |
