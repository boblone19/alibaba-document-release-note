# 智能体工厂 OpenTrek HiMarket用户指南

智能体工厂 OpenTrek

## 什么是HiMarket

HiMarket是面向企业开发者用于统一管理和分发AI能力的企业级AI开放平台。

**背景与挑战**

随着大语言模型、MCP（Model Context Protocol）服务等AI能力在企业内部的快速普及，各业务部门构建了数量众多、形态各异的AI资源。企业在AI资源运营过程中通常面临以下挑战：AI资源分散于不同团队和平台，缺乏统一视图与集中管理机制；底层AI能力未经过产品化包装，难以直接被业务方和第三方开发者调用；不同业务线需要独立的开发者门户与品牌形象，但共享底层基础设施；需要在调用侧完成鉴权、限流、 内容安全、Token计量等多重控制；难以对AI调用进行全链路追踪、用量统计与成本核算。这些挑战导致企业AI能力难以规模化复用，开发者接入成本高，运营管理效率低下。

**产品概述**

HiMarket是基于Higress AI网关构建的企业级AI开放平台，帮助企业构建私有化的AI能力市场，统一管理和分发LLM、MCP Server、Skill等AI资源。平台采用前台、管理控制台、基础设施三层分离的架构设计， 将分散的AI能力封装为标准化的API产品，支持多版本管理和灰度发布。平台内置AI体验中心（HiChat）， 提供AI对话的自助体验入口；内置模型市场、Skill市场、MCP市场等多类市场，支持AI能力的统一供给与消费；同时具备安全管控、可观测分析、计量计费等企业级运营能力。HiMarket基于HiMarket开源项目构建，在开源框架基础上深度定制了AI体验中心、MCP市场等企业级能力，并提供商业化支持与私有化交付保障。

**核心功能**

**AI****资源市场**：将分散的AI能力沉淀为标准化的API产品，统一管理模型市场、MCP市场、技能市场等多类
资源。
**AI****体验中心**：内置HiChat对话体验入口，支持多模态对话、多模型对比、MCP工具调用和安全沙箱代码
执行。
**企业级运营管理**：提供产品全生命周期管理、多维度观测分析、统一计量计费、版本管理与灰度发布能
力。
**多租户门户定制**：支持为不同业务线和生态合作方构建独立的开发者门户，支持自定义域名、品牌样式、
身份认证与审批工作流。 智能体工厂 OpenTrek

## 快速入门

本文介绍 HiMarket 的快速入门流程，帮助管理员在最短时间内完成从网关接入到 API 产品发布的全流程， 并指引开发者完成注册、订阅与首次 API 调用。

**背景信息**

HiMarket 分为两类使用者：
**管理员**：通过 HiMarket 管理后台完成网关实例导入、门户创建、API 产品封装与发布。
**开发者**：通过开发者门户完成登录、产品浏览、创建 Consumer 消费者、获取凭证并发起调用，或在
HiChat中进行在线体验。 本快速入门以“管理员发布一个 Model API 产品，开发者完成订阅并通过 HiChat 与模型对话”作为典型示例。

**使用流程**

**管理员流程**

1. 登录 HiMarket 管理控制台，完成管理员注册与登录。
2. 导入集群，用于托管Portal部署。
3. 导入网关实例，作为 AI 资源的底层网关。
4. 创建 Portal，面向开发者提供独立的访问站点。
5. 创建Model API，并配置基础信息。
6. 发布资源，让开发者在门户中可以浏览和订阅。

**开发者流程**

1. 访问开发者门户，完成登录。
2. 浏览产品，在模型/MCP/智能体等页面发现产品。
3. 完成产品订阅和 Consumer 凭证申请。
4. 在 HiChat 中体验已订阅的模型产品。

**使用须知**

HiMarket 依赖 Higress 网关和 MySQL 数据库，请先完成基础设施部署后再进行后续操作。 每个门户通过域名识别，管理员需配置默认域名或自定义域名的 DNS/Hosts 解析指向 himarketfrontend 服务。 门户默认采用账号密码登录，如需对接企业身份系统，可在门户**Security**页面启用**OIDC** **登录**。 开发者注册和产品订阅默认支持两种审批模式（自动通过 / 手动审批），请根据业务合规诉求在门户
**Security**中合理配置。
管理员账号和开发者账号相互独立，分属不同的登录入口。 智能体工厂 OpenTrek

#### 创建 Portal

**背景信息**
