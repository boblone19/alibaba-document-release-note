# 智能体工厂 OpenTrek OpenTrek-UniOperator 产品简介

智能体工厂 OpenTrek

## 产品详情

## 产品详情

OpenTrek-UniOperator 是一款面向企业级 Kubernetes 环境的轻量级云管理平台，提供多集群纳管、应用市场、产品部署编排、实例生命周期管理、用户权限管控等一站式运维能力。平台采用 Helm Chart 标准化部署方式，支持在专有云 Kubernetes 环境中快速交付，助力企业在私有化环境中实现高效、统一的产品运维管理。 智能体工厂 OpenTrek

## 产品价值

## 产品价值

OpenTrek-UniOperator 具有轻量交付、统一管理、标准化部署、安全可控等核心优势。

**轻量交付**

基于 Helm Chart 标准化打包，支持在已有 Kubernetes 集群上一键部署，无需额外基础设施依赖。后端基于 Go 语言构建，单二进制运行，资源占用低；支持 SQLite、MySQL、PostgreSQL 三种数据库，适应开发测试到生产环境的多种部署形态。安装器提供 Web UI、TUI、CLI 三种交互模式，满足不同交付场景需求。

**统一管理**

支持多 Kubernetes 集群统一纳管，通过 KubeConfig 导入外部集群，In-cluster 集群自动注册。在一个控制台中集中管理集群资源、产品部署、用户权限和镜像仓库，消除多集群环境下的运维孤岛，降低运维复杂度。

**标准化部署**

通过 OpenTrek-UniOperator 实现产品的标准化管理与部署。产品以 Helm Chart 为交付单元，经过预检、组件部署、堆栈检查、后处理四阶段编排流程完成安装，确保每次部署过程可复现、可追溯。部署任务支持全程进度追踪与状态查看，降低人工操作风险。

**安全可控**

基于 JWT 无状态认证与 RBAC 三级角色权限体系（管理员、编辑者、查看者），实现精细化的访问控制。 智能体工厂 OpenTrek

## 应用场景

## 应用场景

OpenTrek-UniOperator 面向专有云环境下的产品运维管理场景，帮助企业实现多集群环境下产品从导入、部署到运维的全流程管理。

**多集群环境下的产品运维管理**

**核心能力**

在多 Kubernetes 集群环境下，通过统一运维平台实现产品的集中管理。将产品以 Helm Chart 形式导入应用市场，选择目标集群进行一键部署，平台自动完成预检、组件安装、堆栈校验等全流程编排。部署完成后可在控制台中统一查看所有产品实例的运行状态，并进行版本升级和实例下线等生命周期操作。

## 应用场景

企业在多个专有云集群中部署和运维同类产品的场景。需要将第三方产品快速导入并标准化部署到目标集群的场景。多集群环境下需要统一查看产品实例状态和版本信息的场景。

**客户价值**

以产品市场为入口，打通产品导入、部署、运维全流程，降低多集群环境下的运维复杂度，实现产品交付标准化和运维可视化。

**私有化环境下的平台交付与运维**

**核心能力**

面向无法直连互联网的专有云环境，OpenTrek-UniOperator 提供离线交付能力。安装器支持 Web UI 图形化引导和 CLI 命令行两种部署模式，数据库可选 SQLite（轻量测试）或 MySQL/PostgreSQL（生产环境），支持 linux/amd64 和 linux/arm64 双架构。部署完成后平台自动注册 In-cluster 集群，并通过健康检查接口支持外部监控系统集成。

## 应用场景

金融、政务等强安全要求下的私有化环境产品交付场景。离线或网络受限环境下需要快速部署运维管理平台的场景。需要在 ARM 架构服务器上部署运维管理工具的场景。

**客户价值**

轻量级交付、低资源占用、多架构支持，让企业在各种受限环境下都能快速获得统一的运维管理能力，缩短平台上线周期。 智能体工厂 OpenTrek

## 基本概念

## 基本概念

| 概念 | 说明 |
|---|---|
| In-cluster | 指 OpenTrek-UniOperator 自身所运行的 Kubernetes 集群。该集群在平台部署后自动注册，无需手动导入 KubeConfig，且不可删除。 |
| 应用市场（AHM） | Application Hub Management，OpenTrek-UniOperator 中的产品管理模块。产品以 Helm Chart 为交付单元，通过应用市场进行导入、浏览、部署和管理。 |
| 产品实例 | 指通过应用市场成功部署到目标集群中的产品运行实体。每个产品实例包含产品名称、版本号、供应商等关键属性，支持查看详情、升级和下线操作。 |
| 部署任务 | 指一次产品部署或升级操作的执行记录。部署任务包含预检、组件部署、堆栈检查、后处理四个阶段，每个阶段有独立的执行状态和进度追踪。 |
| KubeConfig | Kubernetes 集群的访问凭证文件，包含 API Server 地址、认证信息等配置。统一运维平台通过 KubeConfig 文件导入外部集群进行纳管。 |
| Helm Chart | Kubernetes 应用的包管理格式，用于定义、安装和升级 Kubernetes 应用。统一运维平台以 Helm Chart 作为产品标准化交付载体。 |
| RBAC | Role-Based Access Control，基于角色的访问控制。统一运维平台支持管理员、编辑者、查看者三级角色，控制用户对平台功能的访问权限。 |
| uo-bootstrap | 统一运维平台的安装器组件，提供 Web UI、TUI、CLI 三种部署交互模式，负责在目标环境中完成平台的初始化部署。 |
