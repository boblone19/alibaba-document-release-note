## 什么是AgentRuntime 智能体运

**行服务**

**AgentRuntime Platform**是一个专为企业级 AI Agent 应用设计的、部署在企业自有云环境下
的 PaaS (Platform-as-a-Service) 平台。它专注于解决 Agent 在生产环境中从代码调试、部署到运维全生命周期的核心挑战，提供统一的**Agent** **运行时管理、工具（****Tool/MCP****）生命周期管理、底层异构资源**
**的精细化弹性调度，以及多级安全隔离能力**。

**运行时管理**

| 功能点 | 详细说明 |
|---|---|
| 统一执行环境 | 提供标准化的执行环境，支持各类 Agent 应用运行。 |
| 全生命周期管理 | 支持 Agent 应用调试、部署、监控、升级。 |
| Python/Node.js/Java 运行时 | 支持 Python、Node.js 和 Java 运行时。 |

**沙箱能力**

| 功能点 | 详细说明 |
|---|---|
| Code Interpreter | 提供安全隔离环境，支持动态生成代码的执行，支持文件 I/O 和会话管理。 |
| Browser Use | 支持通过自动化浏览器执行网页浏览、数据抓取、表单填写等任务。 |
| All-in-One 沙箱 | 将代码执行、浏览器、文件系统等能力集成于一个沙箱实例中。 |
| 文件系统 | 为沙箱提供隔离的、可读写的虚拟文件系统，支持创建、 读取、修改和删除文件。 |
| 操作能力（Computer/Mobile Use） | 支持模拟桌面或移动设备图形界面（GUI）操作。 |
