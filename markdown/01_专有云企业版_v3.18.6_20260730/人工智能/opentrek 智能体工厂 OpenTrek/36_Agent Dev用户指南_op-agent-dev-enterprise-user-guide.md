# 智能体工厂 OpenTrek Agent Dev用户指南

智能体工厂 OpenTrek 品简介

## 产品简介

OpenTrek Agent Dev产品定义、产品优势、产品架构说明。

**产品定义**

OpenTrek Agent Dev作为企业级大模型应用开发管理平台和行业知识加工平台，提供了大模型应用开发、调试、评测、观测、运维、优化全生命周期管理工具链，并提供知识加工检索、工具和MCP服务注册管理、上下文工程和提示词工程等能力支持。

**产品优势**

**多模态知识高效处理**

客户价值高效构建高质量企业知识库，快速搭建RAG问答等AI应用。 能力优势提供了端到端知识解析能力：支持文档/图像/音视频/数据表等全模态数据管理，内置20+深度解析加工模板，覆盖财报/论文/政策/教材等10+类型，可实现文档版面解析、复杂表格解析、公式解析、图片理解， 可帮助客户基于私有化数据知识，快速构建多模态知识库。

**全场景智能体搭建支持**

客户价值场景覆盖全面，支持知识问答Agent、工作流Agent、自主规划Agent等类型智能体搭建。 能力优势深度整合RAG知识增强、Workflow自定义编排、ReAct单智能体推理决策多重机制，开发者可根据场景需求灵活切换工作模式，满足从基础问答到群体智能的多层次开发需求。

**MCP与工具生态开放**

客户价值支持客户高效集成多样化工具，提升开发灵活性和安全性，简化接入流程，降低集成成本，加速业务创新与响应。 能力优势支持API工具的异步调用和鉴权信息动态传入，适配多场景类型工具接入；支持SSE/STDIO双模式注册 MCP服务，支持安全沙箱独立运行，灵活支持不同接入方式，保障安全性和稳定响应；API一键封装 MCP，实现跨协议兼容，降低集成成本。

**精细化记忆管理机制**

客户价值基于短期记忆管理能力有效解决智能体任务长上下文管理问题，基于长期记忆管理能力实现智能体任务的个性化处理，使智能体越用越好用。 能力优势短期记忆管理支持历史对话轮数设置、长上下文压缩、重要实体抽取、自定义记忆读写。长期记忆支持重点问答、用户画像、任务地图，同时支持自定义记忆生成策略、整理策略、召回策略。

**产品架构**

随着大模型成熟和产业落地加速，大模型应用开发正成为驱动千行百业智能化转型的新质生产力。然而在应用落地过程中，开发者面临全生命周期管理复杂、工具链割裂、评测体系缺失等核心痛点——从上下文工程的设计优化、知识系统的动态更新，到多工具协同的工作流编排、复杂场景的持续观测运维，每个环节都存在技术门槛高、试错成本大的挑战。传统开发模式更面临多模态数据处理能力不足等掣肘，严重制约大模型应用的规模化落地。 智能体工厂 OpenTrek 品简介为了应对这一趋势，我们围绕大模型应用在企业级场景中的全生命周期管理和基础能力支持，构建了 OpenTrek Agent Dev大模型应用开发平台和数据知识加工平台，旨在为企业提供从数据加工到应用开发的一体化解决方案，助力AI技术真正实现产业落地。 平台作为企业级大模型应用生产平台，提供了专业领域的知识加工、智能体搭建、评测、观测、运维等一站式服务工具链。 智能体工厂 OpenTrek 速入门

### 功能概述

本章节介绍智能体中心下的所有功能说明和类型。

**功能说明**

### 智能体

智能体是OpenTrek Agent Dev平台的核心应用形态，基于大模型能力构建对话式AI应用。平台支持多种智能体类型，满足不同业务场景的需求，并提供从创建、配置到调试、评测的完整开发流程。 智能体模板：使用平台预置的智能体模板快速搭建应用，支持 AutoBI、AutoVideo、AutoDoc 等场景模板。

### 知识库

知识库为智能体提供结构化的知识支撑，支持对文档、数据表、图文等多种类型的知识进行统一管理。通过知识库，智能体可以在对话中引用相关知识，提升回答的准确性和专业性。

### 工具箱

工具箱为智能体提供外部能力调用入口，支持管理平台工具、共享工具和我的工具。通过工具箱，您可以为智能体配置 API、代码执行、知识检索等能力，扩展智能体的功能边界。 我的工具：管理当前登录用户的工具，支持创建、编辑和删除自定义工具。 平台工具：查看平台预置的工具，这些工具由平台管理员统一维护，可直接在智能体中使用。 共享工具：查看和使用其他空间共享过来的工具，实现跨空间的能力复用。

### 提示词

提示词模块提供提示词模板管理和提示词优化能力，帮助您设计高质量的提示词，提升智能体的对话效果。 通过提示词模板，您可以快速复用经过验证的提示词方案；通过提示词优化任务，您可以系统地改进提示词质量。

**智能体类型**

**知识问答**：大模型直接回答或参考辅助知识实现对话应用。可选择基于 AutoBI、AutoVideo、AutoDoc

**功能说明**

### 数据管理

数据管理为平台提供统一的数据集管理能力，支持文档、图像、音频、视频、数据表、文本等多种数据类型的存储和管理。通过数据集管理，您可以高效组织训练数据、微调数据和知识库构建数据，为模型训练、智能体开发和知识加工提供数据支撑。 数据集详情：查看数据集介绍、数据视图和数据文件，支持数据加工和数据标注的快捷入口。

### 数据加工

数据加工提供端到端的数据解析、增强和清洗能力，覆盖富文本解析、大语言数据合成、多模态解析、数据清洗、数据配平等多个功能类别。通过数据加工，您可以将原始数据转换为高质量的训练数据和知识片段， 为模型训练和知识库构建提供数据支撑。 能力广场：提供丰富的数据加工模板和自定义算子，支持端到端的数据处理流程。

### 数据标注

数据标注提供对文本、图片数据进行标注及验收的全流程管理能力，支持多人协作标注和任务拆分。通过数据标注，您可以为模型训练、微调和 RAG 知识库构建准备高质量的标注数据，同时支持智能标注模型辅助生成标注结果，提升标注效率。 任务管理：导入数据并创建标注任务，支持查看详情、分配标注人和验收人、导出至数据集等操作。 标注任务：执行数据标注操作，支持文本和图片多种标注类型，可结合智能标注模型辅助生成。 验收任务：对已标注数据进行检查和批阅，对不合格的子任务进行驳回重标，确保标注质量。

## 系统管理

### 功能概述

本章节介绍系统管理下所有功能说明。

**功能说明**

全局资源管理用于添加和管理平台所需的各类数据资源，包括对象存储、数据库等底层基础设施资源。通过全局资源管理，您可以为智能体服务、数据中心和知识库提供统一的资源存储和管理能力，仅组织管理员/资源集管理员角色通过管理员角色访问时可进行配置。
**对象存储**：注册 OSS 或 S3 类型的存储资源，用于数据文件的存储和管理。
**PolarDB PG**：注册 PostgreSQL 数据库资源。
**缓存数据库**：注册 Redis 缓存数据库资源。
**向量数据库**：注册向量存储和检索资源，用于知识库向量索引。
**全文检索** **ES**：注册 Elasticsearch 全文检索资源。
全局服务管理提供智能体服务和数据中心资源的创建、配置和运维管理能力。通过全局服务管理，您可以为智能体应用配置网关服务、存储资源和数据库资源，并实现服务的空间分配，保障智能体服务的稳定运行和数据中心的正常服务。
**数据中心资源**：创建、配置和停用数据中心资源，支持数据库检索增强和数据中心两种模式。

### 系统设置

系统设置提供场景默认服务、系统参数、请求流量控制和虚机管理等配置能力。通过系统设置，您可以为智能体开发流程配置默认模型服务，调整系统运行参数，控制智能体版本的请求流量，并管理用于 STDIO 模式 MCP 服务注册的虚机资源。
**场景默认服务**：为工作流、记忆体、知识库等场景配置默认模型服务，减少手动选择操作。
**请求流量控制**：控制智能体的切流方式，支持按并行处理任务数或同时发起请求数两种模式。
**虚机管理**：注册和管理虚机资源，用于STDIO模式MCP服务的部署和运行。

### 模型接入

接入并管理平台内部署的模型服务，完成调试和启用后供智能体调用。 接入平台内部署的模型，需选择组织、资源集、地域、提供方模型服务和模型类型，填写 API_KEY， 配置生效空间。 将三方模型API接入平台使用，支持自定义服务类型、协议类型和API服务地址。 接入三方模型API，需配置模型服务名称、展示名称、code、服务类型、协议类型、API 服务地址、请求头和开放参数配置。

### 空间管理

智能体工厂 OpenTrek 统管理空间管理提供多组织环境下的空间创建、成员管理和权限配置能力。通过空间管理，平台管理员可以为各个组织部门分别创建独立的空间，实现智能体应用的隔离管理，确保不同组织或业务部门之间的数据和应用互不干扰。
**创建空间**：新建空间并指定所属资源集，为各组织部门提供独立的应用管理环境。
**空间成员管理**：为空间添加成员，配置空间管理员和空间成员角色。

**说明**

平台支持以下空间角色：
**空间管理员**：可管理空间成员，进行成员的添加、修改角色和移除操作。
**空间成员**：拥有对应空间的数据权限，可查看和使用空间内的智能体、知识库等资源。
**空间查找与切换**：通过资源集和空间名称查找空间，具有多空间权限的账号可快速切换空间。

### 工作流函数说明

通过自定义工作流画布编排搭建智能体时，入参提供了多种工作流函数，可根据搭建场景进行选用。

**调用函数操作指引**

1. 在工作流设计阶段，单击**添加节点**，选择具体节点。
2. 配置输入参数时，来源选择函数。
3. 将鼠标放至函数输入框中，搜索相应函数。
4. 选中函数后，需要配置函数。
5. 单击配置项的**请选择**区域，触发配置功能，可配置函数对应属性的值。不同的函数会有1个到多个配置
项，每个配置项独立配置。

**说明**

函数配置规则： 函数属性的值可支持“引用”、“函数”、“常量”3种获取方式。 引用：可引用前置所有节点的任意出参。 常量：输入固定值。 函数：嵌套其他函数。 如函数有多个配置项属性待配置，需要每个都完成配置。
6. 完成配置后，单击
。
7. 将鼠标悬停至已配置的函数区域，可查看函数全文。

**常用函数说明**

**get(object,key)**

此函数用于解析object类型的数据，选择指定的object中某一个key的值。 此函数需要配置“object”和“key”两个配置项属性： object配置项，配置需要被此函数解析的数据（支持引用、常量、函数）。此处输入或引用的数据必须保证为object类型，否则解析会报错。 key配置项，配置上一条配置的object数据中，需要被解析出来的key。 例如，object={"name":"张三","id"="123"}，key="id"，则此函数解析出来的值为“123”。

**get(list,index)**

此函数用于解析List类型的数据，指定List中具体某一条数据为输入参数。 此函数支持“list”和“index”两个配置项属性。 list配置项，配置需要被此函数解析的数据（支持引用、常量、函数）。此处输入或引用的数据必须保证为list类型，否则解析会报错。 index配置项，配置上一条配置的list数据中，需要被解析出的数据位次。
