# 对象存储 用户指南

## 产品概述

### 什么是对象存储OSS

阿里云对象存储OSS（Object Storage Service ）是阿里云提供的安全、低成本、高可靠的云存储服务。 相比传统自建服务器存储，OSS在可靠性、安全性、成本和数据处理能力方面都有着突出的优势。使用 OSS，您可以通过网络随时存储和调用包括文本、图片、音频和视频等在内的各种非结构化数据文件。 OSS将数据文件以对象（Object）的形式上传到存储空间（Bucket）中，提供键值对（Key-Value）形式的对象存储服务。您可以根据Object的名称（Key）获取该Object的内容。 您可以进行以下OSS相关的操作： 获取已上传文件的地址，进行文件的分享和下载。 修改存储空间或文件的属性或元信息，为其设置相应的权限。 在对象存储OSS控制台进行基础和高级OSS操作。 通过开发工具包SDK或直接在应用程序中调用RESTful API，进行基础和高级OSS操作。

### 使用须知

本文介绍在使用对象存储OSS前，您需要了解的内容。 如果需要让其他用户使用OSS产品部分或全部功能，您需要先创建RAM用户，并为该用户授予相关的RAM 权限，从而让该用户具备与其RAM策略相匹配的操作权限，实现对OSS的访问或操作。 使用OSS前，还需要了解以下限制：

| 限制项 | 说明 |
|---|---|
| 存储空间 | 同一用户创建的存储空间总数不能超过100个。 存储空间一旦创建成功，名称和区域不能修改。 |
| 上传文件 | 通过控制台上传、简单上传、表单上传、追加上传的文件大小不能超过5 GiB，要上传大小超过5 GiB的文件必须使用分片上传 （Multipart Upload）方式。分片上传方式上传的文件大小不能超过 48.8 TiB。 OSS 支持上传同名文件，但会覆盖已有文件。 |
| 删除文件 | 文件删除后无法恢复。 控制台批量删除文件的上限为100个，更大批量的删除必须通过API或 SDK实现。 |
| 生命周期 | 每个存储空间的生命周期配置最多可容纳1000条规则。 |

**操作步骤**

1. 登录对象存储控制台。
2. 单击**Bucket****列表**，之后单击**创建****Bucket**。
3. 在**创建****Bucket**面板，配置相应的参数。

| 域名 | 集群的域名。 |

### 修改读写权限

OSS提供ACL（Access Control List）权限控制方法。存储空间（Bucket）创建后ACL默认为私有权限， 您可以在存储空间创建之后修改ACL。

**背景信息**

OSS存储空间目前有三种访问权限： 私有：只有该存储空间的拥有者或者授权对象可以对该存储空间内的文件进行读写操作，其他人在未经授权的情况下无法访问该存储空间内的文件。 公共读：只有该存储空间的拥有者或者授权对象可以对该存储空间内的文件进行写操作，任何人（包括匿名访问）可以对该存储空间中的文件进行读操作。 公共读写：任何人（包括匿名访问）都可以对该存储空间中的文件进行读写操作，请慎用该权限。

**警告**

如果将访问权限设置为公共读或公共读写，其他用户可以不通过身份验证直接读取存储空间中的数据， 安全风险较高。为保障您的数据安全，建议您将存储空间的访问权限设置为私有。

**操作步骤**

1. 登录对象存储控制台。
2. 单击**Bucket****列表**，之后单击目标Bucket名称。
3. 单击**基础设置**页签，在**读写权限**区域单击**设置**。
4. 选择该存储空间的读写权限。
5. 单击**提交**。

### 设置服务端加密

对象存储OSS支持服务端加密功能。上传文件（Object）时，OSS对收到的文件进行加密，再将得到的加密文件持久化保存；下载文件时，OSS自动将加密文件解密后返回给用户，并在返回的HTTP请求Header 中，声明该文件进行了服务端加密。

**背景信息**

OSS支持以下两种数据加密方式： 使用KMS托管密钥进行加解密（SSE-KMS） 使用KMS托管的默认CMK（Customer Master Key）或指定CMK ID加密OSS Object。加密密钥由 KMS托管，您无需花费大量成本来保障密钥的保密性、完整性和可用性。 使用OSS完全托管加密（SSE-OSS） 使用OSS托管的密钥加密每个Object，作为额外的保护，OSS会使用定期轮转的主密钥对加密密钥本身进行加密。 您可以通过以下两种方式在OSS控制台上开启服务端加密功能： 方式一：创建Bucket时开启服务端加密功能方式二：在基础设置页签开启服务端加密功能

**操作步骤**

**方式一：创建Bucket时开启服务端加密功能**

1. 登录对象存储控制台。
2. 单击**Bucket****列表**，之后单击**创建****Bucket**。
3. 在**创建****OSS bucket**页面中填写各项参数。

| 参数 | 说明 |
|---|---|
| 服务端加密 | 设置服务端加密参数。 无：不加密数据。 OSS完全托管：使用OSS完全托管的密钥加密每个Object。 KMS：使用KMS平台托管的密钥加密Object。 |
| 加密算法 | 根据需要选择加密算法。当服务端加密选择OSS完全托管或KMS时可配置。取值范围如下： AES256：使用AES256加密每个Object，并为每个Object使用不同的密钥进行加密， 作为额外的保护，它将使用定期轮转的主密钥对加密密钥本身进行加密。 SM4：使用SM4加密每个Object，并为每个Object使用不同的密钥进行加密，作为额外的保护，它将使用定期轮转的主密钥对加密密钥本身进行加密。 |

| 密钥ID | 当服务端加密选择KMS时可配置。选择指定密钥ID后，OSS将使用指定的KMS密钥加密 Object。 说明选择密钥ID前，您需要在KMS控制台创建加密密钥。 |
|---|---|

4. 单击**提交**。

**方式二：在基础设置页签开启服务端加密功能**

**重要**

开启或修改Bucket默认加密方式不会影响Bucket中已有文件的加密配置。
1. 登录对象存储控制台。
2. 单击**Bucket****列表**，之后单击目标Bucket名称。
3. 单击**基础设置**页签，在**服务器端加密**区域单击**设置**。
4. 配置服务端加密参数。

| 参数 | 说明 |
|---|---|
| 服务端加密方式 | 设置服务端加密参数。 无：不加密数据。 OSS完全托管：使用OSS托管的密钥加密您的数据。 KMS：使用KMS平台托管的密钥加密Object。 |
| 加密算法 | 根据需要选择加密算法。当服务端加密方式选择OSS完全托管或KMS时可配置。取值范围如下： AES256：使用AES256加密每个Object，并为每个Object使用不同的密钥进行加密， 作为额外的保护，它将使用定期轮转的主密钥对加密密钥本身进行加密。 SM4：使用SM4加密每个Object，并为每个Object使用不同的密钥进行加密，作为额外的保护，它将使用定期轮转的主密钥对加密密钥本身进行加密。 |
| 加密密钥 | 当服务端加密方式选择KMS时可配置。选择指定密钥ID后，OSS将使用指定的KMS密钥加密Object。 说明选择加密密钥前，您需要在KMS控制台创建加密密钥。 |

5. 单击**提交**。

### 设置防盗链

**背景信息**

当浏览器向OSS请求文件时，HTTP请求的Referer标头会标识发起请求的源页面URL。OSS通过校验 Referer值来判断请求来源的合法性，基于预设规则允许或拒绝访问。 Referer白名单：仅允许指定的域名访问OSS资源。 Referer黑名单：不允许指定的域名访问OSS资源。 是否允许空Referer：如果不允许空Referer，则只有HTTP或HTTPS header中包含Referer字段的请求才能访问OSS资源。 仅当通过签名URL或者匿名访问Object时，进行防盗链验证；当请求的Header中包含Authorization字段，不进行防盗链验证。

**操作步骤**

1. 登录对象存储控制台。
2. 单击**Bucket****列表**，之后单击目标Bucket名称。
3. 单击**基础设置**页签，在**防盗链**区域单击**设置**。
4. 根据下表说明设置参数。

| 参数 | 说明 |
|---|---|

| Referer | 设置Referer白名单。单击添加Referer并填写域名或IP地址。支持通配符星号 （*）和问号（?）。如需添加多个Referer，请多次单击添加Referer进行配置。示例如下： 配置为www.example.com，可匹配如www.example.com/123、www.example.com.cn等以www.example.com为前缀的地址。 配置为*www.example.com/，可匹配http://www.example.com/和https://www.example.com/的地址。 通配符星号（*）表示使用星号代替0个或多个字符。例如配置为 *.example.com，可匹配如help.example.com、www.example.com等地址。 通配符问号（?）表示使用问号代替一个字符。例如配置为example?.com，可匹配如examplea.com、exampleb.com等地址。 支持带端口的域名或IP地址，例如www.example.com:8080、10.10.10.10:8080等地址。 |
|---|---|
| 黑名单Referer | 设置Referer黑名单。单击添加黑名单Referer并填写域名或IP地址。支持通配符星号（*）和问号（?）。如需添加多个黑名单Referer，请多次单击添加黑名单 Referer进行配置。示例如下： 配置为www.example.com，可匹配如www.example.com/123、www.example.com.cn等以www.example.com为前缀的地址。 配置为*www.example.com/，可匹配http://www.example.com/和https://www.example.com/的地址。 通配符星号（*）表示使用星号代替0个或多个字符。例如配置为 *.example.com，可匹配如help.example.com、www.example.com等地址。 通配符问号（?）表示使用问号代替一个字符。例如配置为example?.com，可匹配如examplea.com、exampleb.com等地址。 支持带端口的域名或IP地址，例如www.example.com:8080、10.10.10.10:8080等地址。 |
| 空 Referer | 选择是否允许Referer为空。 空Referer表示HTTP或HTTPS请求中，不带Referer字段或Referer字段为空。 如果不允许空Referer，则只有HTTP或HTTPS header中包含Referer字段的请求才能访问OSS资源。 |

**说明**

当使用OSS的Bucket域名预览MP4文件时，由于浏览器默认会同时发出两个请求，其中一个为带 Referer的请求，另一个为空Referer的请求，因此设置防盗链时必须同时满足在Referer中添加 Bucket域名，且允许空Referer的条件。当使用OSS的Bucket域名预览非MP4文件时，则仅需允许空Referer。

### 设置跨域资源共享

**背景信息**

OSS提供HTML5协议中的跨域资源共享CORS设置，帮助您实现跨域访问。当OSS收到一个跨域请求（或者OPTIONS请求），会读取存储空间对应的CORS规则，然后进行相应的权限检查。OSS会依次检查每一条规则，使用第一条匹配的规则来允许请求并返回对应的Header。如果所有规则都匹配失败，则不附加任何 CORS相关的Header。

**注意事项**

4. 单击**创建规则**，在**创建规则**面板上根据下表说明设置相应参数。

| 参数 | 是否必选 | 说明 |
|---|---|---|
| 来源 | 是 | 指定允许的跨域请求的来源。配置规则如下： 允许多条匹配规则，多条规则需换行填写。 域名需包含协议名，例如HTTP、HTTPS。 支持通配符星号（*），每条匹配规则允许使用最多一个星号（*）。 若域名使用的是非默认端口，还需要携带端口号。例如 https://www.example.com:8080 。 域名配置示例如下： 匹配指定域名时，填写完整域名。例如 https://www.example.com 。 匹配泛二级域名时，可使用通配符星号（*）。例如 https://*.example.com 。 匹配所有域名，可直接填写通配符星号（*）。 |
| 允许Methods | 是 | 指定允许的跨域请求方法，支持同时选中多个请求方法。取值： GET：获取文件。 POST：表单上传。 PUT：简单上传。 DELETE：删除文件。 HEAD：获取文件元信息。 |

| 允许Headers | 否 | 指定允许跨域请求的响应头。配置规则如下： 格式为 key:value ，例如 content-type:text/plain ，大小写不敏感。 允许多条匹配规则，多条规则需换行填写。 每条匹配规则最多使用一个星号（*）通配符。建议没有特殊需求的情况下设置为星号（*）。 |
|---|---|---|
| 暴露Headers | 否 | 指定允许用户从应用程序中访问的响应头。例如一个JavaScript的 XMLHttpRequest对象。不允许使用星号（*）通配符。 |
| 缓存时间（秒） | 否 | 指定浏览器对特定资源的预取（OPTIONS）请求返回结果的缓存时间。单位为秒。 |

### 使用自定义域名访问OSS

文件（Object）上传至存储空间（Bucket）后，OSS会自动生成文件URL，您可以直接通过文件URL访问该文件。如果您希望通过自定义域名（自有域名）访问这些文件，需要将自定义域名绑定至文件所在的 Bucket。

**重要**

绑定自定义域名前，请确保已拥有一个可用域名。如果Bucket位于中国内地且需为公网用户提供服务，绑定的域名必须完成ICP备案。

**背景信息**

自定义域名绑定至OSS Bucket的实现机制基于DNS的CNAME（Canonical Name）记录。通过将域名指向OSS为Bucket提供的访问地址，当用户访问自定义域名时，DNS系统将其解析到对应的OSS Bucket域名，从而实现对OSS资源的直接访问。

**注意事项**

单个Bucket支持绑定多个自定义域名。单个域名仅能绑定到一个Bucket。

**步骤一：绑定自定义域名**

1. 登录对象存储控制台。
2. 单击**Bucket****列表**，之后单击目标Bucket名称。
3. 单击**基础设置**页签，在**域名管理**区域单击**设置**。
4. 在**域名管理**页面，单击**绑定域名**。
5. 在**绑定域名**面板，输入域名，并单击**确定**。

**说明**

如需解绑自定义域名，请单击域名**操作**列的**解绑**并确认即可。

**步骤二：将自定义域名解析到OSS域名**

将域名绑定至Bucket后，自定义域名尚未生效，需要配置CNAME解析记录将自定义域名指向OSS访问域名，使自定义域名生效。

**重要**

在配置自定义域名CNAME指向OSS访问域名前，请务必在控制台将该自定义域名与OSS Bucket 进行绑定，否则会导致以自定义域名访问OSS时无法正确识别出Bucket ，进而返回非预期内容的情况。同时在后续解除绑定关系后，也请务必及时删除自定义域名CNAME到OSS的指向。
1. 获取OSS Bucket访问域名。
ii. 单击**Bucket****列表**，之后单击目标Bucket名称。 iii. 在Bucket**概览**页面的**访问域名**区域，复制相应Bucket域名。 如果访问仅来自公网，请复制**外网访问**对应的**Bucket****域名**；如果访问仅来自内网，请复制**内网访问**对应的**Bucket****域名**。

**说明**

如果访问来源同时包含公网和内网，涉及复杂的网络路由与域名解析场景，建议联系阿里云技术支持协助评估架构方案并提供专业配置指导。

### 设置TLS版本

客户端应用程序与OSS之间的通信使用传输层安全TLS（Transport Layer Security）进行加密。 TLS是一种标准的加密协议，可确保通过互联网进行通信的客户端与服务端之间的隐私和数据完整性。通过OSS服务端设置TLS版本后，客户端仅支持使用指定的TLS版本与OSS进行数据的发送和接收，以满足通信链路的安全性要求。

目前TLS包括1.0、1.1、1.2和1.3四个版本。OSS仅支持TLS1.1、1.2和1.3版本。具体版本使用场景以及支持的主流浏览器说明如下：

| 协议 | 说明 | 适用场景 | 支持的主流浏览器 |
|---|---|---|---|
| TLS 1.1 | 主要改进了对安全性的支持，去除了部分已知的漏洞，增加了对更强大加密算法的支持，例如AES、RSA、SHA-256等。 | 需要相对较高安全级别的场景， 但不需求最新的TLS特性的环境。 | IE11+ Chrome 22+ Firefox 24+ Safri 7+ |
| TLS 1.2 | 进一步加强了对安全性的支持，并增加了一些新特性例如服务器名称指示 （SNI）、扩展握手协议等。支持的加密算法包括AES-GCM、AES-CBC、 ECDHE等。 | 大多数常见的安全通信场景，包括Web应用程序、电子商务网站、电子邮件、虚拟专用网络 （VPN）等。 | IE11+ Chrome 30+ Firefox 27+ Safri 7+ |

| TLS 1.3 | 在安全性、性能和隐私方面进行了重大改进。删除了一些不安全的加密算法，增加了更强大的密钥交换算法和加密算法，减少了握手过程的延迟，还提供了更好的前向保密和身份验证机制。 | 对安全性要求较高、希望获得更好性能和隐私保护的场景，如金融机构、大型互联网公司、政府机构等。 | Chrome 70+ Firefox 63+ |
|---|---|---|---|

### 设置回源规则

当您的用户向您的对象存储OSS请求的数据不存在时，本应返回404错误。若您设置了回源规则，填写了数据的正确地址，用户可以通过回源规则从OSS获取到正确的数据。

**背景信息**

回源类型分为镜像和重定向两种方式，可以满足您对于数据热迁移、特定请求的重定向等需求。 镜像回源配置了镜像回源后，当对OSS中一个不存在的文件进行GET操作时，OSS会向回源规则指定的地址请求这个文件，在获取到目标文件后返回给您，并将该文件写入OSS。镜像回源主要用于无缝迁移数据到OSS， 即服务已在自己建立的源站或者在其他云产品上运行，需要迁移到OSS上，但是又不能停止服务，此时可利用镜像回写功能实现。 重定向配置了重定向后，当对OSS中一个不存在的文件进行GET操作时，OSS会将您的请求重定向至回源规则指定的地址去获取目标文件。您可以利用这种跳转的功能对文件做重定向以及在此基础之上的各种业务。

**注意事项**

单个存储空间最多支持配置20条回源规则，系统将按规则顺序依次执行。 源站Bucket必须设置为公共读权限，私有权限的Bucket不支持回源。 开启原图保护的Object不支持回源。

### 设置保留策略

OSS保留策略具有WORM（Write Once Read Many）特性，满足用户以不可删除、不可篡改方式保存和使用数据。如果您希望指定时间内任何用户（包括资源拥有者）均不能修改和删除OSS某个Bucket中的 Object，您可以选择为Bucket配置保留策略。在保留策略指定的Object保留时间到期之前，仅支持在 Bucket中上传和读取Object。Object保留时间到期后，才可以修改、覆盖或删除Object。

**操作步骤**

1. 登录对象存储控制台。
2. 在左侧的存储空间列表中，单击目标存储空间名称。
3. 创建保留策略。
i. 在存储空间的详情页面，单击**基础设置**页签，在**保留策略**区域单击**设置**。 ii. 在**保留策略**页面，单击**创建策略**。 iii. 在**创建策略**对话框，设置**保留周期**，然后单击**确定**。 保留周期取值范围为1~25550天。

**说明**

如果已创建的锁定保留策略不符合使用需求，可单击其**操作**列的**删除**，在弹出的确认对话框中单击**确定**，即可完成删除。
4. 锁定保留策略。

**重要**

当保留策略创建24小时后未提交锁定，则该策略自动失效。 保留策略被锁定后，您将无法缩短保留周期或者删除保留策略，且在保留周期内无法修改、覆盖或删除Bucket中的数据。 i. 单击保留策略**操作**列的**锁定**。 ii. 在弹出的对话框中，单击**确定**。
5. （可选）锁定保留策略后，可按需延长保留周期。
i. 单击保留策略**操作**列的**编辑**。 ii. 在**编辑**面板，设置**保留周期**，然后单击**确定**。

**重要**

新设置的保留周期不能小于原有的保留周期。保留策略锁定后，无法缩短保留周期。

**OSS Action分类**

### 日志管理

#### 设置日志管理

用户在访问OSS资源时，会产生大量的访问日志。您可以使用日志存储功能，将OSS的访问日志存放到您指定的存储空间中。

**注意事项**

要转存日志到目标Bucket时，请根据Bucket的加密方式进行相应授权。 当Bucket使用KMS加密方式时，OSS服务需要具有操作相应Object以及使用KMS密钥进行加解密的权限，请通过创建自定义角色进行授权。 当Bucket未使用KMS加密方式时，OSS服务需要具有操作相应Object的权限，请通过创建自定义角色进行授权，且自定义角色的名称必须为AliyunOSSLoggingDefaultRole。 未使用KMS加密方式包括Bucket未开启服务端加密和使用了OSS完全托管的加密方式两种。 权限策略示例请参见日志管理场景转存日志权限策略示例。

**操作步骤**

4. 打开**开启日志存储**开关，并设置日志相关参数。

| 参数 | 说明 |
|---|---|
| 日志存储位置 | 下拉选择存储日志记录的存储空间名称，只能选择当前组织下同一资源集内的存储空间。 |
| 日志前缀 | 填写生成日志的目录和前缀，日志将被记录到指定的目录下。例如 log/<TargetPrefix> ，日志将被记录在log/目录下。 |
| 授权角色 | 授予OSS服务的角色。该角色的权限请根据Bucket的加密方式进行配置。 配置RAM角色授权并创建角色后，通过如下任一方式配置授权角色。 选择默认日志转存授权。此时角色名称必须固定为 AliyunOSSLoggingDefaultRole。 选择自定义授权并选择创建的RAM角色进行授权。此时角色名称可自定义。 |

## 对象（文件）

### 上传文件

存储空间创建完成后，即可向存储空间内上传文件（Object）。

**背景信息**

您可以将任意类型的文件上传至存储空间中。通过OSS控制台您可以上传小于5 GiB 的文件。如果您要上传的文件大于5 GiB，您可以通过SDK或API进行上传。

**操作步骤**

1. 登录对象存储控制台。
2. 单击**Bucket****列表**，之后单击目标Bucket名称。
3. 在**文件管理**页签，单击**上传文件**。
4. 在**上传文件**面板，设置上传文件的参数。

| 参数 | 说明 |
|---|---|
| 上传到 | 设置文件上传到OSS后的存储路径。 当前目录：将文件上传到当前目录。 指定目录：将文件上传到指定目录，您需要输入目录名称。若输入的目录不存在，OSS将自动创建对应的文件目录并将文件上传到该目录中。 目录命名应满足以下要求： 不允许使用表情符号，请使用符合要求的UTF-8字符。 / 用于分割路径，可快速创建子目录，但不要以 / 或 \ 开头，不要出现连续的 / 。 不允许出现名为 .. 的子目录。 总长度控制在1~254个字符。 |
| 文件ACL | 选择文件的读写权限，默认为继承Bucket。 继承Bucket：文件的读写权限按Bucket的读写权限为准。 私有：对文件的所有访问操作需要进行身份验证。 公共读：可以对文件进行匿名读，对文件写操作需要进行身份验证。 公共读写：所有人都可以对文件进行读写操作。 |

| 上传文件 | 将需要上传的一个或多个文件拖拽到此区域，或单击图标，选择一个或多个要上传的文件。 重要如果上传的文件与存储空间中已有的文件重名，则会覆盖已有文件。 如果上传的是文件夹，上传时仅会保留文件，文件夹不会保留，所有文件都会存放在同一目录。 添加的文件大小不能超过5 GiB，大小超过5 GiB的文件，请使用命令行工具ossutil、OSS SDK或OSS API等方式，通过分片上传的方式进行上传文件操作。 不同浏览器可能会对上传文件的文件名中某些字符进行转义或替换，请您确认上传文件的文件名是否准确。 上传文件的命名需要符合以下规范： 使用UTF-8编码。 区分大小写。 长度必须在1~1023字节之间。 不能以正斜线（/）或反斜线（\）开头。 |
|---|---|

5. 在**上传文件**面板等待任务完成。

**重要**

文件上传过程中，请勿刷新或关闭**上传任务**面板，否则上传任务会被中断。 在**上传文件**面板，按需执行相应操作。

**取消上传中的任务**

在文件上传过程中，单击**取消全部**，取消所有上传中的任务；单击文件**操作**列的**取消**，取消单个文件的上传。

**移除已完成的任务**

文件上传成功后，单击**移除已完成**，移除所有已完成的上传任务；单击文件**操作**列的**移除**，移除单个上传任务。

**说明**

此操作不会移除上传失败的任务。如需移除上传失败的任务，请先单击文件**操作**列的**移除**，取消上传任务，再次单击**移除**完成操作。

### 新建目录

对象存储OSS通过模拟文件目录的形式在控制台实现类似于Windows文件夹的基本功能，本文介绍如何在 OSS控制台创建文件目录。

**背景信息**

OSS内部使用扁平结构存储数据，不使用传统文件系统中的层级结构，所有数据均以对象（Object）的形式保存在存储空间（Bucket）中。为方便您对Object进行分组并简化管理，OSS管理控制台默认将以正斜线 （/）结尾的对象作为文件目录的形式展现。该对象同样可以上传及下载，您可以在OSS控制台中使用类似于Windows文件夹的操作方式来使用OSS文件目录。

**说明**

对于任何一个以正斜线（/）结尾的对象，不论该对象是否存有数据，在控制台中都以文件目录的方式显示，您只能通过API或SDK的方式来下载该对象。

**操作步骤**

1. 登录对象存储控制台。
2. 单击**Bucket****列表**，之后单击目标Bucket名称。
3. 在**文件管理**页签，单击**新建目录**。
4. 在**新建目录**面板，输入目录的名称。
目录名称需要符合以下规范： 不允许使用表情符号，请使用符合要求的UTF-8字符。 正斜线（/）用于分割路径，可用于快速创建子目录。目录名称中不允许以正斜线（/）或反斜线（\）开头，不得出现连续的正斜线（/）。例如，创建名为example/test/的目录时，会自动创建主目录example/和子目录test/。 不允许出现 `..` 。 总长度为1~254个字符。
5. 单击**确定**。
创建目录后，可以单击该目录对应的**彻底删除并确认**，删除目录以及目录下的内容。

### 设置软链接

软链接功能用于便捷访问Bucket内的常用Object。设置软链接后，您可以使用类似于Windows的快捷方式，通过软链接文件打开Object。

**操作步骤**

1. 登录对象存储控制台。
2. 单击**Bucket****列表**，之后单击目标Bucket名称。
3. 在**文件管理**页签，单击目标文件**操作**列的**设置软链接**。
4. 在**设置软链接**面板中，填写**软链接文件目录**，然后单击**确定**。
文件目录需要符合以下规范： 举例：filename 或 aaa/bbb/filename。 不允许使用表情符号，请使用符合要求的 UTF-8 字符。 正斜线（/）用于分割路径，可用于快速创建子目录，但是不能以正斜线（/）或反斜线（\）开头，不得出现连续的正斜线（/）。 不允许出现名为 `..` 的子目录。 总长度控制在 1~254 个字符。

**重要**

如果设置的软链接文件名未包含文件扩展名，例如文件myphoto.jpg的软链接文件名为myphoto， 通过控制台或URL访问该软链接文件时可正常预览。通过工具或控制台下载该软链接文件时，因文件无文件扩展名，下载后是一个未知文件，无法直接打开。如需打开文件，请添加正确的文件扩展名。

您可以在搜索框中输入Bucket名称，快速查找所需Bucket。
3. 在**文件管理**页签，选择目标文件**操作**列的**⋯ >** **选取内容**。
4. 在**选取内容**面板中，根据下表说明配置各项参数。

| 参数 | 说明 |
|---|---|
| 文件类型 | 显示文件类型，支持CSV或JSON格式的文件。 |
| 分隔符 | 当文件类型选择CSV时，需设置该项。 可选择半角逗号（,）或自定义填写分隔符。 |
| 文件有标题行 | 当文件类型选择CSV时，需设置该项。 文件第一行包含列标题时，选中此项后提取的数据将去除第一行的内容。 |
| JSON 格式符 | 当文件类型选择JSON时，需设置该项。 JSON LINES _ JSON DOCUMENT _ |
| 压缩格式 | 选择文件的压缩格式。 NONE GZIP |

5. 配置好参数后，单击**显示文件预览**，预览文件内容。
6. 单击**下一步**，在**SQL** **编辑器**中输入SQL语句提取所需的文件内容。
7. 单击**执行**，在**执行结果**中可查看提取的文件内容。

**说明**

单击**执行结果**区域下方的**下载**，可将提取的文件内容下载至本地。

## 我的访问路径

OSS支持添加访问路径，您可以通过访问路径快速访问目标资源。

**前提条件**

1. 登录对象存储控制台。
2. 单击**我的访问路径**后的加号（+）。
3. 在**添加已授权的访问路径**面板添加路径。
参数说明如下：
**地域**：选择目标Bucket所在地域。
**文件路径**：添加目标资源路径，格式为 `bucket/object-prefix` 。例如，访问的目标资源是名
`example`；访问目标资源为example根目录下test目录，则填写为example的Bucket根目录，则填写

```
example/test/。
```

4. 单击**确定**。

## 创建Single Tunnel

创建一条OSS和VPC之间的Single Tunnel，可以通过VPC来访问OSS资源。

**前提条件**

已创建VPC和交换机。具体操作，请参见**《专有网络****VPC****用户指南》**中的“创建专有网络”和“创建和管理交换机”章节。

**说明**

即使OSS是同城容灾部署形态，Single Tunnel访问方式也没有容灾能力，不支持容灾切换。

**操作步骤**

1. 登录对象存储控制台。
2. 单击**singleTunnel****列表**。
3. 在**SingleTunnel****列表**页面，单击**创建**。
4. 在**创建****Single Tunnel**页面，设置Single Tunnel参数。

| 参数 | 是否必选 | 说明 |
|---|---|---|
| 组织 | 是 | 选择目标VPC所在的组织。 |
| 资源集 | 是 | 选择组织后，会根据组织自动选择资源集。 |
| 地域 | 是 | 选择组织后，会根据组织自动选择地域。 |
| 集群 | 是 | 选择Single Tunnel生效的集群，创建的SingleTunnel只能访问此处指定集群的Bucket。 |
| 共享范围 | 是 | 选择要共享的范围。取值范围为本资源集（默认值）、本组织及下级组织和本组织。 |
| 描述 | 否 | 输入Single Tunnel的描述信息。 长度为2～20个字符，必须以大小写英文字母或汉字开头，且只能包含字母、数字、下划线（ ）和短划线（-）。 _ |
| 协议版本 | 是 | 选择IP协议版本，当前默认选中IPv4协议。 |
| VPC | 是 | 选择已创建的VPC网络。可单击创建VPC新建一个VPC网络。 |
| VSwitch | 是 | 选择已创建的交换机。可单击创建VSwitch新建一个交换机。 |

5. 单击**提交**。
6. 单击**确定**。
Single Tunnel创建成功后，可在**SingleTunnel****列表**页面查看创建的Single Tunnel信息。 如果不再使用某个Single Tunnel，请单击Single Tunnel**操作**列的**删除**并确认，删除该Single Tunnel。
