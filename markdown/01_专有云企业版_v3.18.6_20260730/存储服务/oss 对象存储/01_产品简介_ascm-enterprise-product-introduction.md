# 对象存储 产品简介

对象存储 OSS

## 对象存储

阿里云对象存储OSS（Object Storage Service ）是阿里云提供的安全、低成本、高可靠的云存储服务。 相比传统自建服务器存储，OSS在可靠性、安全性、成本和数据处理能力方面都有着突出的优势。使用 OSS，用户可以通过网络随时存储和调用包括文本、图片、音频和视频等在内的各种非结构化数据文件。

### 产品详情

OSS将数据文件以对象（Object）的形式上传到存储空间（Bucket）中，提供键值对（Key-Value）形式的对象存储服务。用户可以根据Object的名称（Key）获取该Object的内容。

**Bucket管理**

Bucket是用于存储对象Object的容器，所有的Object都必须隶属于某个Bucket。用户可以根据实际需求，创建不同类型的Bucket来存储不同的数据，并通过配置读写权限ACL、生命周期等属性来管理 Bucket。

**Object管理**

Object是OSS存储数据的基本单元，也被称为OSS的文件。OSS提供多种上传和下载文件的方式，用户可以根据文件大小以及网络环境，选择适当的上传和下载文件，并通过配置读写权限ACL、对象标签等属性来管理Object。

**数据安全**

### 应用场景

OSS适用于图片和音视频等应用的海量存储、数据多地容灾以及离线数据归档存储。

**图片和音视频等应用的海量存储**

OSS可用于图片、音视频、日志等海量文件的存储。各种终端设备、Web网站程序、移动应用可以直接向 OSS写入或读取数据。OSS支持流式写入和文件写入两种方式。

**离线数据归档存储**

根据OSS低成本和高可用的特性，可以将企业内部长期需要离线归档的数据转存至OSS。

**数据多地容灾**

用户存储的数据可以通过跨区域复制或跨云复制等能力实现两个集群或两个云系统之间的数据异步（近实时）复制，帮助用户实现两地三中心的技术架构、多地数据容灾备份，使用户可以在极端灾难中保证业务流畅。 对象存储 OSS

对象存储 OSS

| 加密 |  |  |
|---|---|---|
|  | 客户端加密 | 使用客户端加密时，会为每个Object生成一个随机数据加密密钥， 用该随机数据加密密钥明文对Object的数据进行对称加密。主密钥用于生成随机的数据加密密钥，加密后的内容会作为Object的 meta信息保存在服务端。解密时先用主密钥将加密后的随机密钥解密出来，再用解密出来的随机数据加密密钥明文解密Object的数据。主密钥只参与客户端本地计算，不会在网络上进行传输或保存在服务端，以保证主密钥的数据安全。 警告使用客户端加密功能时，您需要对主密钥的完整性和正确性负责。因您维护不当导致主密钥用错或丢失， 从而导致加密数据无法解密所引起的一切损失和后果均由您自行承担。 在对加密数据进行复制或者迁移时，您需要对加密元信息的完整性和正确性负责。因您维护不当导致加密元信息出错或丢失，从而导致加密数据无法解密所引起的一切损失和后果均由您自行承担。 |
|  | 传输层加密TLS | 客户端应用程序与OSS之间的通信使用传输层安全 TLS（Transport Layer Security）进行加密。 TLS是一种标准的加密协议，可确保通过互联网进行通信的客户端与服务端之间的隐私和数据完整性。通过OSS服务端设置TLS版本后，客户端仅支持使用指定的TLS版本与OSS进行数据的发送和接收，以满足通信链路的安全性要求。 |
| 版本控制 | 版本控制是针对Bucket级别的数据保护功能。开启版本控制后，针对数据的覆盖和删除操作将会以历史版本的形式保存下来。在错误覆盖或者删除对象（Object）后，能够将Bucket中存储的Object恢复至任意时刻的历史版本。 |  |
