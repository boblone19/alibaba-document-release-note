# 文件存储NAS 运维指南

文件存储NAS

## 产品架构

阿里云文件存储（File Storage NAS，简称NAS）是面向阿里云ECS实例、容器服务的文件存储服务，提供标准的文件访问协议。 NAS文件系统后端基于阿里云盘古分布式存储，3个数据副本分布存储于多台盘古节点上。前端访问节点接受NFS客户端的连接请求和提供Cache功能，自身是无状态和分布式部署，保证前端的高可用。单TB数据恢复时间小于30分钟（单集群6节点规模），随着集群规模越大，恢复速度越快。详细信息可参考《**NAS**技
**术白皮书》**。

### 停写设置

文件存储NAS 通过设置停写设置，可以控制写入存储的总容量。当写入容量过高时，将禁止写入；容量降低后将恢复写入。

**配置**

配置停写步骤如下：
1. 登录Apsara Uni-manager运维控制台。
2. 在顶部导航栏，选择**平台运维** > **飞天基础运维平台** > **资源管理**。
3. 在左侧导航栏，选择**产品集群运维**，并在**产品**|**集群**搜索框中输入**nas**。
4. 在目标集群的操作列，单击**集群详情**，进入该集群的详情页面。
5. 选择**终态配置**页签，然后在文件列表框中选择**services > nas-nfs > user > nfs_supervisor**，配
置nfs_supervisor.json文件。

```json
{
    "nas_disk_usage_limit":90
}
```

**nas_disk_usage_limit**参数值为百分数，表示写入存储量达到总容量的多少就停止写入。建议设置
为**90**。 如果该集群未创建nfs_supervisor.json文件，请执行以下操作： i. 单击**services > nas-nfs > user**文件夹右侧的
**图标** > **新增文件**。创建nfs_supervisor文件
夹。 ii. 在**新增文件**对话框中，配置**新增类型**为**文件夹**、**文件**/**文件夹名称**为nfs_supervisor.json，然后单击确定。 iii. 单击刚创建的nfs_supervisor文件夹右侧的
**图标** > **新增文件**，创建nfs_supervisor.json文件。
iv. 在**新增文件**对话框中，配置**新增类型**为**文件**、**文件**/**文件夹名称**为nfs_supervisor.json。 文件存储NAS v. 配置nfs_supervisor.json文件。

```json
{
    "nas_disk_usage_limit":90
}
```

**nas_disk_usage_limit**参数值为百分数，表示写入存储量达到总容量的多少就停止写入。建议设置
为**90**。
6. 配置更改后，集群重新rolling，配置生效。

**说明**

禁写后，重写方法如下： 删除文件系统或文件内容，系统的回收周期为7天左右，7天后可以进行重写操作。 更改limit值，也可以进行重写操作。

**验证**

验证过程如下：
1. 创建文件系统，并进行正确挂载。
2. 向文件系统写入并达到limit标准。此时将禁止写入，不影响其他命令的使用，例如ACL等。
文件存储NAS
3. 查看日志。
