# 混合云存储CDS CPFS产品简介

## 产品详情

文件存储CPFS (Cloud Parallel File Storage)是阿里云专有云高性能的并行文件系统，支持POSIX协议， 提供对数据亚毫秒级的访问和数十GB/s的读写吞吐能力，推荐用于AIGC、自动驾驶、EDA仿真、CG渲染等业务场景。

## 产品价值

**超高性能**

CPFS集群和单文件系统均可支持TB级的吞吐能力。 企业级NVMe SSD介质，数据访问链路采用RDMA高速网络。 全并行I/O访问模型，计算节点与CPFS存储集群内的所有存储服务器可以并行建立连接，同时读取数据。 分布式元数据，元数据根据目录树结构切分至多台服务节点，同时提供服务。

**弹性扩展**

存储容量在线扩容，性能随容量弹性扩展。 支持存储节点的在线扩展，并对应用透明。在不停止服务的情况下，支持后端存储服务系统的在线热升级，支持动态加入和移除磁盘。 分布式元数据，单文件系统承载百亿文件。 数据和元数据全对称架构，POSIX客户端可并行访问所有服务节点，吞吐和IOPS随着容量同步线性增长，最高可达TB级吞吐和百万级IOPS，满足人工智能、HPC、机器学习大文件以及海量小文件的高性能访问需求。

**经济高效**

数据采用EC纠删码方式进行存储，支持4D+2P的规格。

## 应用场景

CPFS是阿里云推出的一款超高性能的文件存储服务，支持端到端RDMA网络，应用于AIGC、自动驾驶等智算场景。

**AIGC**

CPFS结合对象存储OSS、文件存储NAS等产品组成完整的解决方案，可以提供持久化存储，满足训练模型需要百万级图片素材、创作者的AI绘画文件需求。此外，CPFS提供高达百Gbps的吞吐能力，加速训练环节的数据读写性能，提供更快的模型训练及推理速度，加快新业务上线，降低用户侧AI绘画等待时间。

**自动驾驶**

自动驾驶场景中，超高性能CPFS存储可以提高GPU计算资源的利用率，云上CPFS弹性扩展能力和即开即用，减少运维管理成本数据流动，实现云上云下无缝对接，打通数据上传、计算、分发、归档全流程，降低数据存储成本。CPFS混合云线下+云上同时部署，支持与OSS数据流动，同时满足计算弹性和数据存储成本优化需求。

**基因计算高性能存储**

CPFS对接容器服务ACK、Serverless容器服务ASK和基因计算AGS，搭建极速、低成本、高精度的基因计算容器环境，满足基因测序计算和数据共享需求。CPFS用于基因数据分析中的共享存储，保存下机数据和组装后的数据，以及过程数据，满足基因行业用户的低时延、高IOPS的存储需求，减少数据拷贝/传输。同时，CPFS计算结果数据会同步到对象存储OSS，CPFS集成OSS提供海量存储空间，同时通过生命周期管理，将冷数据归档存储，降低存储成本。

## 功能特性

本文介绍CPFS文件系统的功能特性。

**基本功能**

| 功能 | 说明 |
|---|---|
| 文件系统管理 | 支持通过控制台创建、查看、删除文件系统。并提供标准Open API。 |
| 多租户 | 支持以多级组织、资源集的方式管理文件系统、挂载点。 |
| 配额管理 | 支持基于组织和资源集进行配额管理，管理组织和资源集下的容量使用。 |
| 计量 | 支持对CPFS文件系统已使用容量进行统计，在控制台可查看物理容量使用量、物理容量使用趋势、逻辑容量使用量等容量信息。 |
| 协议支持 | 网络协议：支持RoCE协议、100G以太网等。 存储协议：支持POSIX标准协议，用户的数据和应用软件无需修改即可运行在分布式文件系统上。 |
| 硬件兼容性 | 兼容业界主流服务器主机，兼容主流硬盘类型、RAID卡。 |
| 客户端挂载 | 支持客户端的批量挂载、自动挂载。 |

**可靠性及可用性**

| 功能 | 说明 |
|---|---|
| 数据EC | 将原始数据分成多个数据块，并通过计算生成一定数量的校验块。这些数据块和校验块共同组成一个EC组，分布在不同的存储节点上。当部分数据块或校验块丢失时，可以通过其他块恢复丢失的数据。EC包含数据块（n）和校验块（m）这两个概念： 数据块（n）：数据分成n个数据切片。 校验块（m）：通过n个数据块计算而得的m个校验块。数据块（n）+校验块 （m）组成一个EC组，它们分别位于不同的服务器上，当丢失任意小于等于m个块时，都能通过EC算法恢复丢失的块。 CPFS文件系统支持4+2的配置。 |
| 系统冗余设计 | 全套系统关键部件采用全冗余设计，系统各部分配置均不存在任何单一故障失效点。单个存储节点失效不会导致数据丢失；单节点故障对应用透明，不影响应用的正常读取。 |
| 故障稳定性 | 支持硬盘或节点故障后数据自动重构和均衡。数据重构恢复对系统性能影响小于10%。 |

| 在线升级 | 在不停止服务的情况下，文件系统可支持存储系统在线升级，支持动态加入和移除磁盘。 |
|---|---|
