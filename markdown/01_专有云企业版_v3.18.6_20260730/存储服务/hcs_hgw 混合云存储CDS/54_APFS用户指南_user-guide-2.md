# 混合云存储CDS APFS用户指南

## 什么是APFS文件系统

**产品概述**

高性能并行文件存储APFS（ApsaraStack Parallel File System）是以云定义的分布式并行文件系统，具备智算场景下大规模并行训练所需的高性能，以及智能化数据管理、可靠的安全保障、灵活的部署形态、资源弹性扩展等特点。适配海光DCU、Ascend GPU加海光存储集群的场景。

### 数据流动

阿里云APFS文件系统支持与对象存储OSS之间的高效数据流动，提供备份归档与数据导入两大核心能力， 帮助用户实现数据生命周期管理、成本优化及高性能计算场景下的数据快速导入。 数据备份：通过配置备份计划，可以将APFS文件系统中的数据定期自动备份至OSS对象存储中，适用于以下场景： 数据备份与容灾：将APFS中的数据副本同步至OSS，构建跨存储介质的备份策略，提升数据安全性。 存储成本优化：识别并迁移低频访问的数据至OSS，从而降低整体存储成本，实现数据分层管理。 数据导入：通过创建导入作业，将OSS中的数据高效回流至APFS文件系统，适用于以下场景： 线下数据上云：利用OSS支持多种方式导入数据的优势，可通过OSS将线下或其他系统中的数据导入 APFS中，提升数据传输效率。 AI/大数据训练加速：对于企业长期积累在OSS中的海量历史数据，可批量导入至高性能的APFS文件系统中，为AI模型训练、高性能计算（HPC）等对I/O要求极高的场景提供低延迟、高吞吐的数据访问能力。

#### 备份计划

通过创建备份计划，可将 APFS 文件系统中的数据复制到 OSS 对象存储中。

**创建备份计划**

### 使用限制

同一用户、同一地域下，一个文件系统仅可创建一个备份计划。 同一用户、同一地域下，备份计划名称不可重复。 最小备份时间间隔为 24 小时。 当源文件系统处于删除中、已删除、停止中、已停止等异常状态时，备份计划将被自动暂停。

**前提条件**

已创建对象存储OSS Bucket。

**操作步骤**

1. 登录APFS文件存储控制台。
2. 在左侧导航栏单击**数据流动**。
3. 在**备份计划**页签，单击**创建备份计划**，配置以下参数。

| 配置项 | 参数 | 说明 |
|---|---|---|
| 基本信息 | 计划名称 | 输入备份计划的名称。 |
|  | 描述 | 输入备份计划的描述信息。 |
| 数据源配置 | 源文件系统 | 下拉选择需要备份的APFS文件系统。 |
|  | 源路径 | 输入需要备份的文件路径，示例值：/source/path。 |
|  | OSS存储桶 | 下拉选择需要复制的目标OSS存储桶（Bucket）。 |
|  | 目标存储位置 | 输入Bucket下的目标复制路径，示例值：oss-bucket-name/oss- path。 |
| 调度配置 | 定时表达式 | 输入定时表达式，定义备份任务的执行时间。示例值：0 0 12 * * ?，表示每天中午12:00触发。 重要调度间隔不得小于1天。 |
|  | 迁移速度 | 高速：不限制。 中速：最高速率不超过 200 MB/s。 低速：APFS每个节点的迁移带宽不超过总带宽的 50%。 |

| 高级配置 | 排除路径 | 输入源文件系统中不需要复制的文件路径。该路径下的所有文件将不会被复制到对象存储OSS中。多个路径间用英文逗号（,）隔开， 示例值：/tmp,/logs,/cache。 |
|---|---|---|
|  | 文件名匹配模式 | 输入需要备份的文件名，只有命中的文件会被备份。多个文件间用英文逗号（,）隔开，示例值：*.log,*.tmp,*.bak。 |
|  | 文件大小阈值 | 输入需要备份的文件大小阈值。 格式：整数 + 单位，支持单个值或范围（英文逗号分隔的两个值）。 支持单位：B（字节）、K（KiB）、M（MiB）、G（GiB）、 T（TiB），不区分大小写。 单个值：表示只备份大于等于该大小的文件。示例值：1G，表示只备份文件大小 ≥ 1GiB 的文件。 范围：最小值,最大值，最小值必须严格小于最大值。示例值：1G,2G，表示备份 1GiB ≤ 文件大小 ≤ 2GiB 的文件。 |
|  | 文件操作时间阈值 | 输入文件修改时间阈值。 格式：整数 + 单位，支持单个值或范围（逗号分隔的两个值）。 支持单位：ms 表示毫秒，s 表示秒，m（小写）表示分钟，h 表示小时，d 表示天，w 表示周，M（大写，按 30 天计算）表示月，y（365 天）表示年。需特别注意 m（分钟）和 M（月）大小写敏感。 单个值：表示只备份文件操作时间（如 mtime）距今超过该时长的文件。例如3d 表示只备份最后修改时间在 3 天前及更早的文件（即文件修改时间 ≥ 3 天）。 范围：最小值,最大值，最小值必须严格小于最大值。如1d,5d表示仅备份操作时间在 1 天 ~ 5 天之间的文件。 重要 m（分钟）和 M（月）大小写敏感。 范围模式下只能有 2 个值。 范围模式下最小值必须严格小于最大值。 不支持输入小数。 |
|  | 最大容量限制（GiB） | 备份计划创建的所有副本占用的OSS容量限制（GiB），默认为 1024。 说明当副本容量达到最大容量限制时，将停止备份。 |

#### 副本管理

通过副本管理可对备份任务进行取消、删除等操作，并可手动创建备份任务。

### 使用限制

单用户同时运行的备份副本数上限为 2 个。 全局同时运行的备份副本数上限为 5 个。 同一备份计划下不可同时存在多个正在同步的副本。 备份计划有容量上限（默认 1024 GiB），所有健康状态副本的总容量不可超过该上限。 仅对状态为“同步中”的任务可执行取消任务操作。 备份计划必须处于启用状态才能创建新的备份副本。 连续失败一定次数，备份计划进入“暂停”状态（SUSPENDED），需要人工介入。

**管理副本**

1. 登录APFS文件存储控制台。
2. 在左侧导航栏单击**数据流动**。
3. 单击**副本管理**页签，可对副本任务进行管理。

| 删除副本 | 删除副本任务。 说明 OSS对象存储桶中已备份的文件不会被删除。 单击目标副本任务操作列的删除副本，在二次弹窗中确认无误后，单击确定。 |

#### 导入作业

通过导入作业可将对象存储 OSS 中的数据导入到 APFS 文件系统中。

### 使用限制

单用户同时运行的导入作业数上限为 1 个。 全局同时运行的导入作业数上限为 3 个。 文件系统必须处于可用状态。

**创建导入作业**

**前提条件**

已创建对象存储OSS Bucket。

**操作步骤**

1. 登录APFS文件存储控制台。
2. 在左侧导航栏单击**数据流动**。
3. 单击**导入作业**页签。
4. 单击**创建导入作业**，并配置如下参数。

| 配置项 | 参数 | 说明 |
|---|---|---|
| 基本信息 | 导入名称 | 输入导入任务的名称。 |
|  | 描述 | 输入对该任务的描述信息。 |
|  | 目标文件系统 | 下拉选择目标APFS文件系统。 |
|  | OSS存储桶 | 下拉选择数据源所在的OSS存储桶（Bucket）。 |
|  | 文件系统路径 | 输入APFS文件系统路径，格式示例：/target/path。 |
|  | OSS对象路径 | 输入数据源所在的OSS对象路径，格式示例：oss-bucket-name/oss- path。 |

| 高级配置 | 带宽限制 | 输入导入文件的传输带宽限制。 指定限制：输入“数值+单位”字符串。支持单位： K (KB/s)、 M (MB/s)、 G (GB/s)。填写示例： 50M ，表示限制为 50 MB/s。 不限制：输入字符串 off 。 默认值：若不填写该参数，默认为 200M ，即默认限速为 200 MB/s。 |
|---|---|---|
|  | 排除路径 | 输入OSS存储桶中不需要导入的文件路径。该路径下的所有文件将不会被导入到 APFS文件系统中。多个路径间用英文逗号（,）隔开，示例值：/tmp,/logs,/cache。 |
|  | 文件名匹配模式 | 输入需要备份的文件名，只有命中的文件会被备份。多个文件间用英文逗号（,）隔开，示例值：*.log,*.tmp,*.bak。 |

**管理导入作业**

1. 登录APFS文件存储控制台。
2. 在左侧导航栏单击**数据流动**。
3. 单击**导入作业**页签，可对导入任务进行管理。

| 操作 | 说明 |
|---|---|
| 查看作业 | 单击作业名称可查看作业的详细信息。 基础信息：可查看作业ID、作业名称、文件系统ID、进度（%）、副本大小、文件数等信息。 进度信息：可查看同步进度（%）、传输速度、已传输文件数量、大小（字节）信息。 存储信息：可查看文件系统路径、OSS存储桶、OSS路径、总大小（字节）信息。 |
| 取消任务 | 可操作取消状态为“同步中”的导入作业。 单击目标任务操作列的取消任务，在二次弹窗中确认无误后，单击确定。 |
| 删除作业 | 如无需保留导入作业，可操作删除。 说明已导入文件系统中的文件不会被删除。 单击目标任务操作列的删除任务，在二次弹窗中确认无误后，单击确定。 |
