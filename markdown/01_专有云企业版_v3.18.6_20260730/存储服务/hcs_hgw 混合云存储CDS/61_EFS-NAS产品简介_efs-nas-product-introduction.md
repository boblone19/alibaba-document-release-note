# 混合云存储CDS EFS-NAS产品简介

阿里云弹性文件存储 EFS-NAS 产品

## 产品详情

阿里云弹性文件存储 EFS-NAS（File Storage NAS）是面向阿里云ECS实例、E-HPC、容器服务等计算节点的文件存储服务，是一种可共享访问、弹性扩展、高可靠以及高性能的分布式文件系统。

**产品类型**

EFS-NAS支持容量型和性能型两种实例类型，以满足不同的业务场景。 容量型实例基于SSD + HDD混合闪存服务器。 提供大容量、成本优化的共享文件存储方案。 适合档案管理、数据归档、视频监控回放等成本敏感场景。 性能型实例基于SSD全闪存服务器。 提供高吞吐、低延迟的文件访问能力。 适合高性能计算、媒体剪辑、数据库文件存储等性能敏感场景。

**核心功能**

文件系统挂载：支持多客户端挂载文件系统。 弹性扩容：可对文件系统进行在线扩容，随业务增长动态调整容量。 挂载点：支持通过NFS/SMB协议共享生成挂载点。 配额管理：支持按照组织设置容量配额，实现资源的合理分配、成本控制和性能优化。 单一命名空间容量：最大支持 5 PiB容量，实现海量数据统一管理。 单集群最大规模：支持最多 2000 块磁盘，按需横向扩展。 3 台起步部署：满足小规模业务起步与平滑扩容的需求。 存储池灵活部署：支持文件存储集群底层的资源独占与灵活规划，降低初期设备投入数量。

**产品特性**

**协议支持与多协议互通**

支持NFS v3.0 / NFS v4.0 / NFS v4.1协议。 支持SMB 2.1 / SMB 3.0协议。 支持多协议互通：同一目录/文件可通过NFS与SMB多种协议访问，满足跨操作系统与多种应用场景下的文件共享需求。 支持IPv4/IPv6双栈网络，客户端可通过IPv4或IPv6地址访问文件系统。

**数据安全与权限管理**

三副本保护：数据多副本冗余，确保存储高可用与数据安全。 EC（Erasure Coding）纠删码保护：支持多种数据保护策略，包括2+1、4+2、8+3、4+2:1、 8+2:1 模式，提升存储效率与可靠性。 ACL 权限控制：支持 Windows ACL 和 Linux POSIX ACL 文件访问控制。 安全组控制：可基于客户端 IP 设置读写访问权限策略。

**审计与合规**

支持通过操作审计查询操作日志，满足企业审计、合规要求。 阿里云弹性文件存储 EFS-NAS 产品

**产品优势**

性能与容量兼具：既能满足高性能低延迟需求，也可支撑海量低成本存储。 多协议互通与混访能力：同一数据源可被不同系统直接访问，提升多平台协作效率。 灵活弹性部署：在线扩容与资源池化管理，适配不同业务生命周期。 高可用与数据安全：三副本与EC纠删码结合，既保证高可靠性，又可优化存储利用率。 细粒度安全与审计：多级ACL权限、安全组策略与访问审计，满足企业安全、合规、政企与金融等行业监管要求。 阿里云弹性文件存储 EFS-NAS 产品

## 产品价值

**高可用与数据可靠性**

通过多副本、EC纠删码数据冗余机制，确保在硬件故障时业务持续可用，并保障数据安全不丢失。

**共享一致性与高并发性能**

多计算实例可同时访问同一数据源，借助文件锁与事务机制保证强一致性；底层优化的I/O调度和分布式架构可在高并发访问下保持稳定的吞吐与低延迟。

**协议与生态互通**

支持标准的NFS v3、NFS v4.0、SMB 2.1 和 SMB 3.0 协议，兼容主流Linux与Windows系统，方便与现有业务系统无缝集成，降低迁移成本。

**多样化访问方式**

既可通过VPC在云内安全接入，也可通过专线、VPN等将本地IDC与云端打通，实现跨地域低延迟访问，满足混合云和多数据中心部署需求。

**安全合规**

提供细粒度权限控制、传输与存储加密、访问审计等功能，确保数据在访问全链路中的安全性，符合行业及监管要求。

**便捷运维与可视化管理**

管理控制台与API支持实时监控容量、性能、健康状态，并可自动告警与扩容，提升运维效率和可控性。 阿里云弹性文件存储 EFS-NAS 产品

## 应用场景

在政企、金融和制造等行业，NAS（网络附加存储）因其文件共享便捷、扩展灵活及安全可控等特性，在多个业务场景中得到广泛应用，核心价值体现在集中管理、灵活扩容、快速检索、安全防护及跨地域协作等方面，能有效解决传统存储在容量、性能、可管理性和合规性上的不足。

**政企行业**

电子政务与业务档案管理：集中存储和管理部门公文、审批文件、影像材料，实现跨部门、跨地域的高效文件共享与协作。 公共安全与执法取证：存储高清视频监控、执法记录仪数据及审计日志，支持快速检索与长期归档，满足等级保护和监管要求。 司法机关电子检务：与业务系统联动，确保案卷、证据文件在多节点实时同步，提升案件办理效率与可追溯性。

**金融行业**

文件与影像归档管理：用于集中存储客户影像资料、合同扫描件、柜面单据等，便于快速调阅与灾备保存，满足合规要求。 业务报表与文件共享：为分支机构提供统一的文件访问平台，提高内部数据分发与协作效率。 双活/高可用业务支撑：依托NAS文件系统的高可用和复制能力，支撑电子影像系统、合规留痕系统的双中心运行，保障业务连续性。

**制造行业**

工业设计与研发数据管理：集中管理CAD图纸、工艺文件、测试视频等大文件，支持元数据标签和全文搜索，加快设计迭代。 生产过程与质量追溯：存储产线采集的工艺参数、设备日志、检测影像，实现按批次、时间等条件快速查询，支撑质量管理。 跨厂区协同与供应链共享：支持多工厂、供应商间安全共享生产资料和订单文件，实现实时协作与版本统一。 阿里云弹性文件存储 EFS-NAS 产品

## 功能特性

本文介绍EFS-NAS产品的功能特性。

**基本功能**

| 功能 | 说明 |
|---|---|
| 文件系统类型 | 容量型：基于SSD+HDD的混闪服务器提供容量型实例，适用于数据库备份、 日志存储、Windows用户目录、Linux home目录等成本敏感型且对时延响应要求不高的文件共享业务。 性能型：基于SSD 的全闪服务器提供性能型实例，适用于Linux/Windows企业应用、容器PersistentVolume(PV)、Web内容管理、基因计算等时延敏感型且对时延响应要求较高的文件共享业务。 |
| 文件系统容量 | 单个文件系统支持最大容量为5 PiB。 |
| 协议互通 | 支持NFS v3.0/NFS v4.0/NFS v4.1、SMB 2.1/SMB 3.0协议，可根据应用场景自由选择挂载文件系统的协议版本。 同一目录/文件可通过NFS与SMB多种协议访问，满足跨操作系统与多种应用场景下的文件共享需求。 |
| 配额管理 | 支持按照组织设置容量配额，实现资源的合理分配、成本控制和性能优化。 支持对指定目录设置目录配额、用户配额和用户组配额，每种配额均支持容量配额和文件数配额两种维度，并通过硬配额、软配额和建议配额三个层级精细化管控存储资源。 |
| 挂载点 | 支持通过NFS/SMB协议共享生成挂载点。 |
| IPv4/IPv6双栈 | 支持IPv4和IPv6双栈网络访问，创建NFS/SMB共享时可选择IPv4或IPv6协议版本，客户端可通过IPv4和IPv6地址挂载和访问文件系统。同一文件系统支持同时创建IPv4和IPv6挂载点。 |
| 挂载 | 支持通过挂载点将文件系统挂载至多个客户端。通过控制台可将NFS共享批量挂载或卸载至多个ECS实例，系统通过ECS云助手自动执行挂载命令。 |
| 弹性扩容 | 可在线扩容，随业务增长动态调整容量。 |

**可靠性及数据安全**

| 功能 | 说明 |
|---|---|
| 三副本 | 将每个数据块（Chunk）复制成三个相同的副本，并将这些副本按照一定的策略存放在集群中的不同节点上，这样可以确保即使某个节点发生故障，数据仍然可以从其他节点恢复。提供高数据可靠性，保护用户数据安全。 |

阿里云弹性文件存储 EFS-NAS 产品

| EC（Erasure Coding）纠删码 | 纠删码技术将数据分为n个数据块和m个校验块，组成n+m的EC组，它们分别位于不同的服务器上，当丢失任意小于等于m个块时，都能通过EC算法恢复丢失的块。支持2+1、4+2、8+3、4+2:1、8+2:1的EC模式。 |
|---|---|
| NFS权限控制 | NFS共享支持基于客户端IP/网段配置读写、只读等权限及root压缩/全部压缩等规则。 |
| 用户/用户组 | SMB协议共享，支持按照用户/用户组进行权限管理，可以为不同用户/用户组分配不同的权限级别（如“读写”、“只读”、“完全控制”等），保障数据的访问安全。 |
| 审计日志 | 支持通过操作审计查询操作日志，满足企业审计、合规要求。 |
| 快照 | 通过快照可以定期备份文件系统的业务数据，以应对误操作、攻击或病毒导致的数据丢失风险。快照分为普通快照和定时快照两种类型，适用于不同的数据保护需求。 普通快照：由用户手动创建，适用于在系统升级、配置变更、数据迁移等关键操作前进行即时备份。 定时快照：由系统根据定时快照策略自动周期性生成，适用于生产环境中对重要目录进行日常备份，满足数据合规留存、防误删、自动化运维等长期防护需求。 还可为快照设置过期删除策略，支持自定义过期策略或永久保留。 单个文件系统最多创建 2048 个快照，推荐保留 128 个快照。 所有文件系统最多创建 8192 个快照。 |
| WORM | WORM（Write Once Read Many）功能是用于保护文件数据安全的一写多读特性。启用 WORM 策略后，文件在指定保护周期内将受到严格访问控制，确保“一旦写入，不可篡改”，有效防范误操作、恶意删除或勒索攻击。 |
| 回收站 | 为避免误删文件系统中的文件导致业务受阻或数据永久丢失，可开启回收站功能。开启后，被删除的文件或目录将暂存在回收站中。并支持设置保留策略，被回收的文件在规定的保留时间到期之后彻底删除。用户可以在保留期间恢复这些文件。 |
| Qos配置 | 为避免文件系统占用过多系统资源，运维人员可白屏化为文件系统配置QoS策略，限制文件系统读写的最大带宽和最大OPS。 |
| 批量冻结/解冻与删除 | 支持在控制台对多个文件系统执行批量冻结或批量解冻操作，批量管理文件系统生命周期。冻结状态的文件系统暂停所有读写访问，且不支持扩容和删除操作， 需先解冻后方可删除。支持单个删除和批量删除文件系统，冻结状态的文件系统不可被删除。 |
