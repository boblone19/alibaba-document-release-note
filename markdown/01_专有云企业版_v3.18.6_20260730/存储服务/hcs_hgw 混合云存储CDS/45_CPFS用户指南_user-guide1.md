## CPFS文件存储

文件存储CPFS（Cloud Parallel File Storage）是阿里云专有云高性能的并行文件系统。

**产品概述**

文件存储CPFS（Cloud Parallel File Storage）是阿里云专有云高性能的并行文件系统，满足高性能计算场景的需求。CPFS提供了统一的命名空间，支持POSIX协议，支持在多个计算节点中实现文件系统的共享访问，提供对数据亚毫秒级的访问和数十GB/s的读写吞吐能力。 CPFS文件系统应用于AI训练、自动驾驶、基因计算、影视渲染、石油勘探、气象分析、EDA仿真等场景， 适用于高吞吐、高IOPS、海量文件的IO密集型业务。

### 使用限制

仅支持性能型文件系统的创建，最大总容量限制为1.7 PiB。 仅支持通过裸金属算力平台BMCP控制台挂载至BMCP算力集群。 默认自动创建挂载点，不支持额外创建挂载点。 文件系统的扩容需要在非数据读写的状态下进行。 不支持集群缩容。

## CPFS列表

### 管理文件系统

本节介绍如何查看、删除CPFS文件系统，以及修改文件系统的描述信息。

**前提条件**

**查看文件系统**

1. 在CPFS列表页，单击在搜索框单击
图标或单击**高级筛选**按钮，可选择根据**文件系统****ID**、**文件系统名** 称或**标签筛选**进行筛选。
2. 在文件系统列表页中，单击目标文件系统的ID或操作列的**详情**。
3. 在跳转出的详情页面，可查看文件系统的基本信息和**挂载信息**。

**说明**

默认自动创建挂载点，不支持额外创建挂载点。
5. 在文件系统列表页，单击**监控**列的
图标，可查看该文件系统的容量、带宽、读写iops等指标数据。

**删除文件系统**

**前提条件**

删除文件系统前需要先取消文件系统挂载。 文件系统删除后不可恢复，删除前请确保已完成数据备份。 文件系统删除后不会立即释放资源，将于7天后释放磁盘占用空间。

**操作步骤**

1. 在文件系统列表页中选择目标文件系统，单击右侧操作列的**删除。**
2. 在弹出的对话框里单击**确定**。

**说明**

卸载文件系统可能影响业务运行，请谨慎操作！

**修改文件系统描述信息**

1. 在文件系统列表页中找到目标文件系统，将鼠标悬浮至**文件系统名称****/ID**列，单击
图标。
2. 在弹出的对话框中输入新的描述信息。
3. 单击**确定**。

**说明**

文件系统描述信息，长度限制为2-128个字符，以大小写字母开头，支持数字和"_"、"-"、":"特殊字符，不能以 `http://` 和 `https://` 开头。

**设置文件系统标签**

1. 在文件系统列表页中找到目标文件系统，将鼠标悬浮至**标签**列，单击
图标。
2. 在**编辑标签**对话框中，输入标签键和标签值，
3. 单击**确定**。

### 扩容文件系统

本节介绍如何扩容CPFS文件系统。

**前提条件**

文件处于非数据读写的状态。

**操作步骤**

1. 登录CPFS文件存储控制台。
2. 在文件系统列表页中选择目标文件系统，单击右侧操作列的**扩容**。
3. 在文件系统扩容详情页，选择**新的总容量（****TiB**）。

**说明**

新的总容量不能低于当前总容量，不能超过最大总容量，其中性能型最大总容量为1 PiB，扩容颗粒度为10 TiB。
5. 单击**提交**，完成文件系统的扩容。

### 数据流动

本文介绍如何设置CPFS与对象存储OSS之间的数据复制。

**应用场景**

CPFS数据复制到OSS： 将CPFS的数据复制到对象存储OSS可用于数据备份。 可将低频访问的数据转移存储至对象存储OSS中，优化存储成本。 OSS数据复制到CPFS： 利用OSS支持多种方式导入数据的优势，可通过OSS将线下或其他系统中的数据导入CPFS中，提高数据传输效率。 可将企业早期积累在OSS中的大量数据，通过复制存储至CPFS中，用于AI训练等场景。

**前提条件**

已完成组织的AliyunOSSPrivateCloudDrsSyncRoleRAM服务角色授权，具体操作，请参见《**Apsara**
**Uni-manager****运营控制台****用户指南**》手册中**配置中心****>RAM****服务角色**章节。

**操作步骤**

1. 登录CPFS文件存储控制台。
2. 进入APFS文件系统列表页，单击目标文件的系统ID/名称或**操作**列的**详情**，进入文件系统的详情页，单
击**数据流动**页签，进入数据流动任务页面。

**说明**

如果检测到当前组织未进行AliyunOSSPrivateCloudDrsSyncRoleRAM服务角色授权，进入数据流动任务页面时会自动弹出**云资源访问授权**对话框，可在对话框中选择目标组织完成授权。
3. 单击**创建数据流动任务**，在对话框中设置对应的参数。

| 参数项 | 说明 |
|---|---|
| 任务项 | CPFS > OSS：将CPFS中的数据复制到OSS中。 OSS > CPFS：将OSS中的数据复制到CPFS中。 |
| 数据源 | OSS作为数据源或目标路径的参数填写说明： 首先在单选框中下拉选择数据存放的Bucket。 填写Bucket的具体文件路径。例如：/source file/file01.txt _ CPFS作为数据源或目标路径的参数填写说明： 您需要填写的参数是目标文件或目录在默认挂载点下的相对路径。 说明默认挂载点为 /cpfs/xxxx（例如：文件系统 bmcpfs-0168c998 的默认挂载点为 /cpfs/0168c998）。 填写规则： 文件路径： 如果目标文件的完整路径是 /cpfs/xxxx/a.jpg，对应的需填写的路径参数应为 a.jpg 或 /a.jpg。 您只需提供从默认挂载点开始的路径部分，可以选择是否以斜杠 / 开头。 目录路径： 如果目标目录的完整路径是 /cpfs/xxxx/bigdir/dir1，对应的参数应为 bigdir/dir1 或 /bigdir/dir1。 同样，您可以选择是否以斜杠 / 开头。 示例： 文件 /cpfs/xxxx/images/photo.png 对应的参数为：images/photo.png 或 /images/photo.png。 目录 /cpfs/xxxx/data/files 对应的参数为：data/files 或 /data/files。 重要请确保填写的路径是相对于默认挂载点的路径，而不是完整的绝对路径。 如果路径中包含特殊字符（如空格、中文等），请正确转义或使用引号包裹路径。 |
| 目标路径 |  |
| 描述 | 填写本次复制任务的相关描述。 |

**说明**

单个数据流动任务量数据不超过100 TiB。
4. 单击**确定**提交数据复制任务。
5. 创建复制任务后，可在数据流动任务列表中查看任务状态、任务类型、任务结果、数据源、目标路径、描
