# 全栈云平台 License指南

## License简介

本文将为您简单的介绍License。 License即“软件授权”或“软件许可证”，是阿里云对客户购买的产品使用范围、功能、期限等进行授权的一种合约形式，客户通过License可获得阿里云所承诺的相应产品和服务。 在商业软件中，License管理是商业化的重要一环，是软件安全输出的必要因素。

## 基本概念

本文介绍License中的常用术语。

**软件**

软件是指阿里云自主开发的软件副本。软件不包括在线服务或服务交付物，但软件可以是在线服务的一部分。 License是指下载、安装、访问和使用某个软件产品的权利。许可数量的计算单位可按用户数、使用期限或其他阿里云规定的使用级别进行计量。

**产品授权形态**

产品授权形态是指云产品依照自身的部署和售卖方式，接入专有云产品版本后的授权形态，当前支持资源类授权、逻辑类授权、免费授权。

**授权计量方式**

授权计量方式是指产品授权如何进行计量，当前支持按CPU核数、GPU核数、TB存储、GB内存、单套 （台）、多套（台）进行计量。计量方式通常和产品售卖方式一致。

**授权计量范围**

授权计量范围是指产品授权计量的范围，当前支持按照本产品集群下物理服务器、虚拟服务器、天宫等资源进行授权计量，或按照指定Region、机房的产品集群进行计量。

**产品授权关联单位**

产品授权关联单位是指逻辑类授权产品提供的一套授权能力所包括的具体指标。这些能力指标可以通过购买产品扩容包进行累加。例如，ARMS应用监控专业版包含50个节点监控能力，每多购买一套扩容包就增加 10个节点监控能力。

## 申请License

本文将为您介绍License授权包与获取途径。 License授权包有以下两种版本： 临时License授权包。 基于朱雀配置和合同发放给用户，用于在初验前产品交付部署的授权包。临时License授权包自生成起90 天有效。 正式License授权包。 基于朱雀配置和合同发放给用户的授权包，包括新购云平台License、增量扩容License。正式License授权包发放主流程包括项目完成合同流程、系统申请、License生成、现场导入、License更新。 对于已完成商务合同流程或提前交付流程的商务项目，阿里云系统会自动生成商务项目的正式License授权包。在完成客户验收前，阿里云系统自动生成的授权包为临时License授权包，只有当完成客户验收并由商务确认Renew后，系统才会生成正式License授权包。 您也可以联系阿里云的CMB或SA来获取License授权包。 权包

## 导入并激活License授权包

获取授权包后，您需要将授权包进行导入和激活。 获取License授权包后，您需要确认现场是否已经部署专有云授权管控服务（本产品为免费产品）。如果服务未部署，需要联系交付人员先进行授权服务的增量部署。之后将授权包交由交付人员进行导入和激活，激活方式根据授权包版本不同分为以下两种： 临时License授权包不需要激活，默认从生成起90天内有效。 正式License授权包需要当前项目已经完成验收，并且确认了Renew起止时间，然后通过Apsara Unimanager运维控制台进行激活。

## 查看License的状态

本文介绍如何查看License的授权详情。

**操作步骤**

1. 登录Apsara Uni-manager运维控制台。
2. 在顶部菜单栏中单击**配置**。
3. 在左侧导航栏中选择**系统配置**>**授权信息**。
4. 单击**授权详情**页签即可查看当前License的状态。
授权状态有以下几种：

| 授权版本 | 状态 |

| 未授权 | 未授权 |
| 试用授权 | 试用授权即将过期 |
|  | 试用授权生效中 |
|  | 试用授权已过期 |
|  | 试用授权超量 |
| 正式授权 | 正式授权未激活 |
|  | 正式授权即将过期 |
|  | 正式授权生效中 |
|  | 正式授权已过期 |

## 常见问题

### 收到过期提醒该如何处理

本文为您介绍在运维支持服务临近过期时系统的提示内容和提示频率。 运维支持服务临近过期时系统将会出现如下提示：

| 级别 | 时限 | 行为 |
|---|---|---|
| 临近过期I级 | 临过期90天到45天 | 每周提醒一次 |
| 临近过期II级 | 临过期45天到15天 | 每三天提醒一次 |
| 临近过期III级 | 临过期15天 | 每天提醒一次 |
| 过期I级 | 过期7天内 | 每天提醒一次 |
| 过期II级 | 过期7天到15天 | 每天提醒一次 |
| 过期III级 | 过期15天以上 | 每天提醒一次 |

**说明**

由于买断了软件授权，所以现场提醒的是运维支持服务的过期时间，不影响实际软件使用。
