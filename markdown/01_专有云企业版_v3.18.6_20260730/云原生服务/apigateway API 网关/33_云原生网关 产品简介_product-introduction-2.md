# 网关 云原生网关 产品简介

关

## 什么是云原生网关

云原生网关是一款集成流量网关、微服务网关和安全网关的统一网关产品，基于开源 Istio 与 Envoy 构建，旨在为 Kubernetes 环境提供统一、高性能、易运维的入口网关解决方案。 作为云原生网关，具备以下核心特性： 三合一架构：实现了流量网关 + 微服务网关 + 安全网关三合一的高集成能力，简化架构、降低链路延迟与运维复杂度。 深度生态集成：原生支持 Dubbo、Nacos、Sentinel 等主流微服务组件，适用于复杂的云原生应用体系。 动态配置与可观测性：通过 Kubernetes CRD 实现声明式配置，支持热更新、实时监控与日志追踪，满足生产级稳定性要求。 高性能与可扩展：以 Envoy 为数据面，具备高并发、低延迟的处理能力，并可通过插件机制灵活扩展功能。

## 产品详情

云原生网关面向 K8s Ingress 和 Gateway API 提供流量代理能力，提供服务暴露及流量管控、应用流量入口与集成等能力，具有性能更强劲、稳定更可靠、多重安全防御、扩展性强等特性，是高性能、安全的 API 网关。

**核心概念**

云原生网关在核心使用上，主要提供 HTTP API。

**HTTP API**

基于HTTP协议的接口，以路由为中心。适用于K8s Ingress、微服务架构、AI（SSE）等场景，实现服务的对外快速暴露。 在Kubernetes集群中，Ingress对集群服务（Service）中外部可访问的资源进行管理，提供七层负载均衡能力。云原生网关Ingress是在API网关之上提供更为强大的Ingress流量管理方式，兼容Nginx Ingress以及50多个Nginx Ingress的注解，覆盖90%以上的Nginx Ingress业务场景，支持多服务版本同时灰度发布、灵活的服务治理能力以及全方位的安全防护保障，能够满足大规模云原生分布式应用的流量治理诉求。 业务系统间若不需要精细化的API粒度管理，可通过配置路由的方式，定义特定的请求应该由哪个后端服务来处理。路由路径相比API接口往往粒度较粗，如/user/*，这样可快速配置访问路径，实现系统间的交互。 HTTP API主要面向开发或运维团队，通过路由可以快速实现业务逻辑的拆分和服务的交互，有较高的灵活性，简化业务系统间的调用逻辑。

## 产品价值

云原生网关深度融合了容器服务、微服务等云产品，实现了云产品资源的快速对外服务，为用户打造安全、 高效的云原生流量网关，助力企业无缝过渡至数字化时代。

**低成本**

云原生网关将流量网关（K8s Ingress、Nginx）、微服务网关（Spring Cloud Gateway、Zuul网关等） 和安全网关功能合并，降低50%资源开销，同时缩短了请求时间，降低运维复杂度。

**高集成**

无缝集成容器和微服务体系，支持K8s、Nacos 等服务发现方式。 无缝集成日志和监控服务。 无缝集成证书体系，轻松管理证书。

**解放生产力**

托管式PaaS产品，围绕API生命周期的各个阶段提供生产力工具，大大提高API管理、运维效率，降低日常维护成本。

**高性能、高可用**

分布式部署，承载大规模访问，低延迟处理。 孵化于阿里巴巴内部产品，并且历经 2020 双 11 考验，每秒承载数十万笔请求，目前已经在支付宝、钉钉、淘宝、天猫、优酷、飞猪、口碑等阿里巴巴各业务系统中使用。

## 应用场景

本文介绍云原生网关的核心应用场景。

**AI 场景**

**大模型服务代理**

Higress 提供 `ai-proxy` 插件实现 AI 服务代理功能，支持 OpenAI、Azure OpenAI、Moonshot、通义千问等多种 LLM 提供商。支持协议转换、模型映射、上下文管理等核心功能。

**AI 负载均衡**

`ai-load-balancer` 插件提供针对 LLM 的专用负载均衡策略，包括全局最少请求、前缀缓存匹配等算法。

**安全防护场景**

**身份认证**

提供多种认证插件包括 `basic-auth` 、 `key-auth` 、 `jwt-auth` 、 `oidc` 等，支持不同场景的身份验证需求。

**流量防护**

支持 `request-block` 、 `key-rate-limit` 、 `ip-restriction` 等插件实现请求拦截、限流和 IP 访问控制。

**访问控制**

通过 `bot-detect` 、 `waf` 、 `cors` 等插件提供机器人检测、Web 应用防火墙、跨域资源共享等安全防护能力。

**流量管理场景**

**请求转换**

通过 `transformer` 、 `custom-response` 、 `geo-ip` 等插件实现请求响应数据转换、自定义响应生成和地理位置处理。

**路由控制**

提供 `rewrite` 、 `header-control` 等路由相关插件，支持 URL 重写和请求头控制功能。

**发布管理场景**

**前端灰度发布**

`frontend-gray` 插件实现前端用户灰度功能，支持业务 A/B 测试，通过灰度匹配、监控和回滚策略保证系统发布运维的稳定性。支持基于用户ID、用户标签等多维度的灰度规则配置。

**可观测性场景**

**监控集成**

支持与 Prometheus + Grafana 集成，提供网关指标监控和可视化仪表板。

**统计追踪**

通过统计和追踪相关插件提供全面的请求监控和链路追踪能力。
