# 统一云管平台 飞天助理 用户指南

## 飞天助理访问控制

飞天助理支持通过角色的权限点管理实现用户访问控制及功能点权限分配。

**操作步骤**

1. 管理员登录Apsara Uni-manager运营控制台。
2. 在顶部菜单栏，选择**企业**。
3. 在左侧导航栏，选择**权限管理** > **角色授权**。
4. 单击**创建自定义角色**。
5. 依次完成角色基础配置、管理权限、应用权限、菜单权限和自定义权限策略。
基础配置、管理权限、菜单权限和自定义权限策略的详细说明请参见《统一云管平台用户指南》中的“管理自定义角色”章节。 在**应用权限**中，找到飞天助理产品，根据业务需要，进行角色权限勾选。
6. 角色创建完成后，将角色授权给用户。

### 准确性评测

准确性评测支持对飞天助理进行准确性评估。通过评测用例、评测集和评测任务三级结构完成自动化评估流程，并支持导出详细评测报告。

#### 评测用例管理

##### 添加用例

本文介绍如何添加用例。

**前提条件**

操作用户默认为运营管理员用户。

**操作步骤**

1. 登录Apsara Uni-manager运营控制台。
2. 在顶部菜单栏选择**配置**。
3. 在左侧导航栏选择**飞天助理** > **准确性评测**。
4. 单击**评测用例管理**卡片。
5. 在**评测用例管理**页面，单击**添加用例**。
6. 设置评测用例，支持**单评测用例生成**、**自动生成评测用例**和**获取用户问答用例**。

**单评侧用例生成**

a. 在**单评测用例生成**页签，输入用例信息。

| 配置项 | 说明 |
|---|---|
| 用例类型 | 选择用例类型，当前版本仅支持rag类型。 |
| 产品 | 选择用例对应的产品，仅支持单选。 |
| 问题 | 输入用例的问题。 |
| 答案 | 输入用例问题对应的答案。 |

b. 单击**添加用例**。

**自动生成评测用例**

a. 在**自动生成评测用例**页签，设置用例对应的产品的数量。

| 配置项 | 说明 |
|---|---|
| 产品 | 选择用例对应的产品，支持多选。 |
| 用例数量 | 输入用例生成的数量。 |

b. 单击**生成用例**。

**获取用户问答用例**

a. 在**获取用户问答用例**页签，选择用户的起止时间。

| 配置项 | 说明 |
|---|---|
| 目标时间 | 选择获取用例的目标时间。 |
