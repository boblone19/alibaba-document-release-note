# 灾备管理平台 云平台备份用户指南

灾备管理中心

## 登录平台备份

**前提条件**

已从部署人员或管理员处获取Apsara Uni-manager运维控制台的访问地址、用户名和密码。 Apsara Uni-manager运维控制台访问地址格式为region-id.ops.console.intranet-domain-id。 推荐使用Chrome浏览器。

**操作步骤**

1. 打开浏览器。
2. 在地址栏中，输入Apsara Uni-manager运维控制台的访问地址 `region-id.aso.intranet-domain-`
`id.com` ，按回车键。

**说明**

您可以单击右上角的当前语言切换其它语言。当前支持简体中文、英文、繁体中文三种语言切换。 灾备管理中心
3. 输入正确的用户名及密码。

**说明**

登录Apsara Uni-manager运维控制台的用户名和密码请从部署人员或管理员处获取。 若连续输入密码错误三次，系统将启动图片验证码登录功能；若连续输入错误五次，账户将被锁定，请联系管理员进行激活。 首次登录Apsara Uni-manager运维控制台时，需要修改登录用户名的密码，请按照提示完成密码修改。 为提高安全性，密码必须满足以下要求： 必须包含英文大小写字母。 必须包含阿拉伯数字（0~9）。 必须包含特殊符号，包括感叹号（!）、at（@）、井号（#）、美元符号（$）、百分号（%）等。 密码长度为10~20个字符。
4. 单击**账号登录**。
5. 在顶部菜单栏中选择**系统配置**。
6. 在左侧导航栏中选择**平台备份管理**。

## 平台备份归档存储

### 新建平台备份归档存储

本章节介绍如何创建对应的云平台备份的目的端存储。

**操作步骤**

1. 登录平台备份，请参见登录平台备份。
2. 在左侧导航栏中选择**平台备份管理** > **平台备份归档存储**。
3. 单击**新建存储**。
4. 参考下表填写参数值。

| 参数名称 | 参数说明 |
|---|---|
| 存储名称 | 请自定义存储名称，例如：存储一。 |
| 协议类型 | 请根据实际情况进行选择。 OSS类型：阿里云提供的云对象存储服务。 S3类型：Amazon Web Services（AWS）提供的对象存储服务。 |
| 地址 | 如果协议类型是OSS类型时，请输入OSS的 Endpoint。 如果协议类型是S3类型时，请输入S3的Endpoint。 |
| AccessKey/用户名 | 如果协议类型是OSS类型时，请输入OSS的 AccessKey/用户名。 如果协议类型是S3类型时，请输入S3的 AccessKey/用户名。 |
| AccessKey/密码 | 如果协议类型是OSS类型时，请输入OSS的 AccessKey/密码。 如果协议类型是S3类型时，请输入S3的 AccessKey/密码。 |
| Bucket/存储路径 | 如果协议类型是OSS类型时，请输入OSS的存储路径。 如果协议类型是S3类型时，请输入S3的存储路径。 |
| 存储空间 | 请设置该存储的空间值，单位：GB。 |

灾备管理中心储

| 告警阈值 | 请设置上报告警的百分比，当实际存储空间 / 存储空间 * 100%大于所设置的告警阈值时，会上报告警。 |
|---|---|

5. 单击**确定**。

### 管理平台备份归档存储

本章节介绍如何查看详情、编辑、删除存储。

**前提条件**

**操作步骤**

1. 登录平台备份，请参见登录平台备份。
2. 在左侧导航栏中选择**平台备份管理** > **平台备份归档存储**。
3. 在归档存储页面支持查看详情，编辑存储、删除存储等操作。
查看详情：单击操作列详情，即可查看归档存储的详细信息。 编辑存储： 单击**操作**列**编辑**，可修改除**协议类型**外的其他参数值。 单击**确定**。 删除存储： 单击**操作**列**删除**。 在弹出的提示框上单击**确定**。 灾备管理中心档

## 配置平台备份归档

### 配置minirds备份

**前提条件**

已成功创建对应数据库实例。

**说明**

默认对dbaas_db、perf_db、dukang_db、bak_db、robot_db、 kmsdata/kmsdata_tiangong、idccrypto_data、os_meta、oss_chiji、ummak、account、 location、diamond、schedulerx、ram_slave_proxy、subaccount、ram_master、hsmidc 数据库实例进行备份。

**操作步骤**

1. 登录平台备份，请参见登录平台备份。
2. 在左侧导航栏中选择**平台备份管理** > **平台备份归档配置**。
3. 选择**minirds****备份**页签。
4. 参考下表配置备份策略。

**说明**

备份策略系统已预置，请设置存储策略即可。

| 参数名称 | 参数说明 |
|---|---|
| 归档存储 | 下拉选择提前创建的备份归档存储名称。 |
| 保存天数（天） | 表示备份归档后保留数据的天数，请输入正整数。 |

5. 单击**保存**。
6. 单击**添加备份实例**。
7. 勾选需要备份的数据库实例，单击**确定**。

## 查看平台备份归档记录

本章节介绍在备份归档后如何查看归档详情。

**前提条件**

已成功执行平台备份归档。

**操作步骤**

1. 登录平台备份，请参见登录平台备份。
2. 在左侧导航栏中选择**平台备份管理** > **平台备份归档记录**。
3. 在归档详情页面支持查看备份归档详情。

**说明**

数据在删除一周后将不再展示其归档详情。
