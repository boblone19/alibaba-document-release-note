# 运维编排 产品简介

运维编排

## 产品详情

用户可以通过模板来定义执行任务、执行顺序、执行输入和输出，然后通过执行模板来完成任务的自动化运行。OOS支持跨产品使用，使用OOS可管理ECS、RDS、SLB、VPC等云产品。

**模板**

OOS使用模板来定义所需要编排的运维操作，模板内容支持YAML和JSON两种格式，可分为公共模板和自定义模板两种类型。

**执行**

OOS支持多种运行模式，包括自动执行和单步执行，帮助用户完成多样化的运行任务。 自动执行：建议先在测试环境使用，以便完全了解模板所进行的运维操作，并且结果符合预期，然后才在生产环境进行。 单步执行：类似于调试（Debug）功能。需要详细地了解每一个任务的执行时，可使用单步执行模式。 运维编排

## 产品价值

本文介绍OOS的产品价值。

**规范化自动化运维**

OOS帮助企业以模板化方式定义运维操作，通过系统自动运行，显著提升运维效率、增强运维操作的安全性，并有效降低手工运维的错误。

**可视化的执行追踪**

提供完整的执行过程与结果可视化能力，用户可直观查看： 直观地看到各个任务的执行详情、输入参数和输出结果。 清晰地看到任务执行的流程、顺序和错误跳转路径，便于快速定位问题。

**全托管自动化**

提供全托管的自动化执行，即无服务器（Serverless）的自动化执行。执行过程无须消耗和使用业务侧的计算资源（如ECS实例），即可满足创业型公司、中小型企业以及大型企业客户的自动化运维需求。完全的自动化模式下无需人工守护，让用户更加专注于业务的高速增长。

**高效的批量任务管理**

传统场景下，执行批量任务相比执行单一任务的管理复杂度大幅增加，OOS可以提供实时的进度管理、运行状况统计和快速的错误定位，从而提高整体的运维效率。

**完备的鉴权和审计**

支持使用资源访问管理和用户权限管理系统（RAM）管理OOS，无论是运维编排自身的操作，还是通过运维编排执行的对其他云产品的操作，均支持鉴权和审计，无需担心操作的安全性。

**快速模板构建能力**

OOS提供高易用性的模板构建能力，用户无需从零开始构建。 OOS提供热门云产品的快速集成能力，帮助用户快速构建模板，降低模板编写的难度，提高整体运维的效率。 OOS为常见的运维场景提供了公共模板，只需选择一个类似的模板快速地复制和修改，即可满足运维需求。

**运维即代码（Operations as Code）**

将日常所需要的运维任务以模板的方式提供，并遵循代码（Code）的管理方式来管理模板。从创建到审核，再同步到生产账号中，后续的运维任务只从标准模板中选择运行，确保运维动作的安全，像源代码一样的规范，并以此完成运维即代码（Operations as Code）的最佳实践。 运维编排

## 应用场景

运维编排服务（OOS）支持多种典型运维场景，既能满足标准化操作需求，也允许用户根据实际业务灵活自定义模板。本文介绍OOS的常见应用场景。

**批量操作**

批量执行运维命令，即需要针对多个目标（如ECS实例）批量执行统一的运维命令，适用于需要规模化、标准化操作的场景，有助于保障业务连续性与系统健康。例如，批量检查ECS实例中的硬盘剩余空间：首先选择需要检查的实例列表（多种选择方式，如名字匹配、标签分组、资源组分组等），然后通过云助手命令执行硬盘检查，最终统一查看结果。

**更新镜像**

为确保 ECS 实例运行环境的安全性与合规性（如安装安全补丁、升级组件依赖等），可通过 OOS 自动化更新镜像。从一个源镜像开始逐步更新，最终生成一个新镜像，然后用于测试和生产。实现镜像版本可控、 可追溯，避免人工操作带来的环境漂移。

**审批型运维**

在高风险或敏感操作中，需引入人工审批机制，以确保操作的必要性与合规性。通过在模板中增加审批动作 （ACS::Approve），系统将在运维动作实际执行前进行人工审批，以确保运维动作的必要性，从而避免浪费和误操作。 适用场景包括： 生产环境变更（如数据库重启、配置修改）。 资源释放或删除操作。 权限敏感的批量命令执行。 OOS能够有效防止误操作，满足企业 IT 治理与审计的要求。

**定时任务**

将重复性运维操作自动化定时执行，减少人工干预，保障环境稳定性。例如，在某测试场景中，需要在每日凌晨自动清理测试账号下的OSS对象存储文件，以确保每次测试均在干净的环境中进行。因此，可以创建一个模板，该模板将在每日凌晨运行，从而保证测试环境始终保持全新状态，避免对下一次测试结果造成干扰。 运维编排

## 功能特性

本文介绍OOS的功能特性。

| 功能 | 说明 |
|---|---|
| 定时运维 | 定时执行所定义的运维动作。例如，在某测试场景中，需要清除某账号下因为测试所产生的对象存储OSS文件，则可以创建一个模板，每天凌晨运行，以确保测试环境是一个全新的环境，避免干扰下一次的测试结果。 |
| 公共模板 | 提供多种场景的模板供您选择，涵盖实例管理、执行命令、镜像管理、数据备份、安全审计、定时运行、弹性伸缩管理以及跨地域复制等相关操作的模板。 |
| 我的模板 | 支持自定义模板以编写您所需的运维操作。 |
| 执行管理 | 任务执行管理允许用户对通过模板创建的任务执行进行全生命周期的管理，包括查看执行状态、取消执行、删除执行以及获取详细的执行日志和输出信息。通过这一功能，用户可以确保任务执行的透明性和准确性，从而更好地满足自动化运维需求。 |
