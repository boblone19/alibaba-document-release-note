## 登录Apsara Uni-manager运维

**控制台**

本节介绍运维工程师等相关用户如何登录到Apsara Uni-manager运维控制台。

**前提条件**

已从部署人员或管理员处获取Apsara Uni-manager运维控制台的访问地址、用户名和密码。 Apsara Uni-manager运维控制台访问地址格式为 `region-id.ops.console.intranet-domain-`

```
id.com 。
```

推荐使用Chrome浏览器。

**操作步骤**

1. 打开浏览器。
2. 在地址栏中，输入Apsara Uni-manager运维控制台的访问地址 `region-id.aso.intranet-domain-`
`id.com` ，按回车键。 弹性伸缩 ESS

**说明**

您可以单击右上角的当前语言切换其它语言。当前支持简体中文、英文、繁体中文三种语言切换。
3. 输入正确的用户名及密码。

**说明**

登录Apsara Uni-manager运维控制台的用户名和密码请从部署人员或管理员处获取。 若连续输入密码错误三次，系统将启动图片验证码登录功能；若连续输入错误五次，账户将被锁定，请联系管理员进行激活。 首次登录Apsara Uni-manager运维控制台时，需要修改登录用户名的密码，请按照提示完成密码修改。 为提高安全性，密码必须满足以下要求： 必须包含英文大小写字母。 必须包含阿拉伯数字（0~9）。 必须包含特殊符号，包括感叹号（!）、at（@）、井号（#）、美元符号（$）、百分号（%）等。 密码长度为10~20个字符。
4. 单击**同意协议并登录**。

## 检查服务状态

本文介绍如何查看ess集群所涉及的服务状态。

**操作步骤**

1. 登录Apsara Uni-manager运维控制台。
2. 在顶部菜单栏，选择**平台运维** > **资源管理**。
默认进入**产品集群运维**页面。
3. 在**产品**|**集群**搜索框中，输入**ess**。
产品列表中将展示ess产品的集群、状态、实例状态、巡检报警和操作。
4. 单击**实例状态**列下的服务，可以查看ess集群所涉及的服务和组件。

| 服务 | 组件 | 说明 |
|---|---|---|
| ess- coordinator | EssCoordinat or | 对外提供服务的OpenAPI层，负责把请求持久化和任务下发。 |
|  | EssInit | 首先负责DB的初始化工作，完成之后会把弹性伸缩的所有API配置文件推送到POP配置中心，完成OpenAPI的初始化工作。 |
|  | EssTrigger | EssTrigger依赖于EssInit。 负责健康检查、最大最小检查、伸缩组删除清理等任务的执行。 负责定时任务、报警任务的触发工作。 |
| ess-worker | EssWorker | 负责所有弹性任务的执行工作，包含ECS实例的创建、SLB后端服务器的添加、RDS白名单的添加、云监控分组的同步等。 任务失败会自动重试并设置有效的回滚机制。 |
|  | ServiceTest | 负责整体应用运行状态的回归测试，包含60+回归用例，用于验证功能完备性。 |

5. 在目标集群**操作**列，单击**集群详情**，可进入集群详情页面查看对应服务**状态**是否终态。
如果未到终态，可以登录组件机器，通过相关命令（例如 `docker ps` 和 `docker logs` ）定位并查询组件容器日志，根据容器日志中的异常信息确认问题，解决问题后重启组件机器。 弹性伸缩 ESS

## 管理组件

本文介绍ESS组件的常用操作，包括查看组件监控信息，登录组件机器和重启组件机器。

**查看组件监控信息**

1. 登录Apsara Uni-manager运维控制台。
2. 在顶部菜单栏，选择**平台运维** > **资源管理**。
默认进入**产品集群运维**页面。
3. 在**产品**|**集群**搜索框中，输入**ess**。
产品列表中将展示ess产品的集群、状态、实例状态、巡检报警和操作。
4. 单击**操作**列的**集群详情**。
默认进入**服务列表**页签。
5. 单击要查看的服务**操作**列的**详情**。
6. 在组件详情页，根据需要，进行对应操作。
**查看组件监控信息**：在对应实例**操作**列，单击**组件信息** > **监控**，即可查看**组件监控**、**机器监控**和**系统**
**服务监控**。
**登录组件机器**：
a. 在对应实例**操作**列，单击**Terminal**。 b. 在页面左侧单击**vmXXX**，选择**账号类型**和**服务器账号**，然后单击**确定**。 c. 在Terminal Service页面中进行命令行操作。
**重启组件机器**：
a. 在对应实例**操作**列，单击**操作** > **重启**。 b. 在弹出的对话框中，输入**RESTART**，然后单击**确定**。
