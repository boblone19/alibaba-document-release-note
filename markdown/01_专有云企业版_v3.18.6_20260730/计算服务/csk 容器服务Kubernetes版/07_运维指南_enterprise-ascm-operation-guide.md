# 容器服务Kubernetes版 运维指南

容器服务Kubernetes版

## 使用前必读

容器服务Kubernetes版提供容器相关服务，对于运行在Kubernetes集群中的应用，不当操作可能导致业务故障。本文介绍容器服务的使用须知和高危操作，帮助用户更好地预估和避免相关的操作风险。

**使用须知**

**数据面组件相关**

数据面组件指运行在用户ECS服务器上的系统组件，例如CoreDNS、Ingress、kube-proxy、terway、 kubelet等。由于数据面组件运行在用户ECS服务器上，因此数据面组件运行的稳定性需要阿里云容器服务与用户共同维护。 在使用数据面组件时，请遵循以下建议： 使用数据面组件时，修改组件配置可能会导致组件功能异常，请谨慎修改组件配置。关于通过控制台管理组件的具体操作，请参见**《容器服务****Kubernetes**版**用户指南》**>**《组件》**>**《管理组件》**。 请勿直接使用IaaS层产品的OpenAPI来变更组件的运行环境，包括但不限定于使用ECS的OpenAPI更改 ECS运行状态、修改Worker节点的安全组配置、更改Worker节点的网络配置以及通过负载均衡的 OpenAPI修改SLB配置等，擅自改动IaaS层资源可能会导致数据面组件异常。 部分数据面组件受上游社区版组件影响，可能存在有Bug或漏洞，请注意及时升级组件，以避免开源组件 Bug或漏洞导致业务受损。

**集群升级相关**

请务必通过容器服务的集群升级功能升级集群的K8s版本，自行升级K8s版本可能导致Kubernetes集群的稳定性和兼容性问题。具体操作，请参见**《容器服务****Kubernetes**版**用户指南》**>《**Kubernetes**集
**群》**>**《集群》**>**《升级集群》**。
阿里云容器服务对集群升级提供以下支持： 提供集群K8s新版本的升级功能。 提供K8s新版本的版本说明文档，包括相较于前版本的变化。 提示升级到K8s新版本时因资源变化可能会发生的风险。 您在使用集群升级功能时，请遵循以下建议： 详细阅读K8s新版本的版本说明文档，并根据提示的升级风险确认集群和业务的状态，自行判断升级风险。更多信息，请参见**《容器服务****Kubernetes**版**用户指南》**>**《产品公告》**和**《容器服务**
**Kubernetes**版**用户指南》**>《**Kubernetes****集群》**>**《集群》**>**《升级集群》**。
由于集群升级不提供回滚功能，请做好充分的升级计划和预后备案。

**应用目录相关**

容器服务Kubernetes版为了丰富Kubernetes应用，容器服务基于开源软件做了适配和二次开发，提供了应用目录功能，帮助用户快速部署应用。容器服务无法管控开源软件本身产生的缺陷，请知晓此风险。
