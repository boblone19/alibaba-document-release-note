# 容器服务Kubernetes版 分布式云容器平台ACK One 用户指南

## 什么是分布式云容器平台 ACK

**One**

分布式云容器平台 ACK One（Distributed Cloud Container Platform for Kubernetes）是阿里云面向混合云、多集群、分布式计算、容灾等场景推出的企业级云原生平台。ACK One可以连接并管理您任何地域、任何基础设施上的Kubernetes集群，并提供一致的管理和社区兼容的API，支持对计算、网络、存储、 安全、监控、日志、作业、应用、流量等进行统一运维管控。

您需要为服务账号授予RBAC的权限，才能正常使用分布式云容器平台 ACK One的功能。本文将为您介绍 RBAC权限，以及如何为服务账号授予相应权限。

**权限说明**

RAM角色必须授权RBAC权限，舰队创建账号默认拥有RBAC权限，无需额外授权。授权后，RAM角色才能对ACK One集群内的K8s资源进行操作。 RAM系统策略仅控制ACK One集群资源的操作权限，若RAM角色需要操作指定集群内的K8s资源（如创建并获取多集群应用），还需要获取指定ACK One集群及其命名空间的操作权限即RBAC权限。 ACK One提供以下预置角色：

| dev（开发人员） | 具有所选命名空间下的资源读写权限。 |

### 舰队管理

#### 舰队管理概述

随着Kubernetes集群的广泛应用，企业往往需要运行和管理多个Kubernetes集群，由此带来一系列的问题，例如多集群的管理、对外提供统一的入口、多集群资源的调度等问题。ACK One舰队管理的舰队实例是由ACK托管的，可以管理任意环境的Kubernetes集群，为企业提供一致的云原生应用管理体验。

**核心概念**

**舰队实例**：基于成熟的开源社区项目ArgoCD和Open Cluster Management构建，保证了产品的开放性。
舰队为开发者提供多集群应用分发能力和一致性的Kubernetes API，通过舰队完成工作负载、应用、配置信息的调度分发，同时支持流量的治理功能。舰队实例由ACK托管，您可以省去大量的运维工作，从而专注应用开发。
**关联集群**：您可以选择将同账号下的ACK集群纳入舰队管理，成为关联集群，之后可以通过舰队Fleet实例
向关联集群下发应用和工作负载。舰队可以跨地域管理关联集群。
**舰队管理员**：即舰队创建者，此用户角色可以为其他的开发用户账号创建命名空间，配置任务优先级，以及
配置资源配额。
**开发用户**：此用户角色只能在特定授权的命名空间投递任务或发布应用。

**应用场景**

统一控制面

**如何选择地域**

舰队管理多个关联集群，提供统一管理入口。选择舰队可以根据关联集群数量及其所在地域就近选择。如上图所示，Region 1有两个关联集群，Region 2有一个关联集群，可以选择Region 1作为舰队的地域。

**重要**

舰队管理支持创建多个舰队，您可以根据业务类型、就近地域、测试环境、生成环境等因素创建多个舰队。 一个关联集群，仅可纳入一个舰队进行管理。

**如何选择专有网络VPC**

为了实现舰队对关联集群的统一管理，需要建立网络连接，使它们可以互访API Server端点。
1. 舰队所在VPC可以访问关联集群的API Server端点，如上图中标注“1”的连接。
2. 关联集群所在VPC可以访问舰队的API Server端点，如上图中标注“2”的连接。
3. 如果舰队与关联集群属于不同的VPC，需要将两个VPC网络打通，保证API Server端点可以互相访问。

**重要**

舰队和关联集群的安全组均需要允许来自对方的网段连接。 选择VPC时，优先选择关联集群数量较多的VPC，这样舰队和关联集群的连接将自动采用VPC内网连接。例如，ACK Cluster 1和ACK Cluster 2在VPC 1，ACK Cluster 3在VPC 2，可以将舰队部署在VPC 1。

**如何选择虚拟交换机**

舰队对虚拟交换机无特殊需求，您可以根据网络规划自行选择。

### 关联集群管理

#### 添加关联集群

创建舰队后，您可以为舰队添加关联集群，实现由舰队作为统一入口的应用与负载的分发。舰队可以跨地域

**前提条件**

已创建舰队，且集群状态为**运行中**。具体操作请参见创建舰队。

**约束限制**

添加的关联集群和舰队在同一个VPC。如果两者不在同一个VPC，需要打通舰队和关联集群之间的网络。 单次允许添加和删除的关联集群不超过10个。

**操作步骤**

1. 登录分布式云容器平台 ACK One控制台。
2. 在左侧导航栏，选择**舰队列表**。
3. 在舰队列表中，单击目标舰队ID或**操作**列的**详情**。
4. 在**舰队信息**页面，单击**关联集群**页签。
5. 在**关联集群**页签，单击**关联集群**。
6. 在弹出的**关联集群**面板中，勾选需要关联的集群，然后单击**确定**。
等待一段时间（5分钟以内）后，在**关联集群**页面，集群**关联状态**显示为**关联成功**，说明集群关联成功。 单击**操作**列的**详情**，可跳转至集群**基本信息**页面查看集群详情。

**说明**

添加关联集群后，需手动刷新舰队管理页面，才能显示最新的关联集群列表。关联状态说明如下：
**处理中**：集群添加请求已提交。
**关联中**：舰队收到请求，集群关联中。
**关联成功**：集群关联成功。
**关联失败**：集群关联失败。

**操作步骤**

2. 在左侧导航栏，选择**舰队列表**。
3. 在舰队列表中，单击目标舰队ID或**操作**列的**详情**。
4. 在**舰队信息**页面，单击**关联集群**页签。
5. 解除关联。
单个解除：在**关联集群**页签，找到对应的关联集群，单击其右侧**操作**列下的**移除关联**。 批量解除：在**关联集群**页签，勾选多个关联集群，单击列表下方的**批量解除关联**。
6. 在弹出的对话框中，单击**确定**。

**说明**

等待一段时间后，刷新**关联集群**页签，关联集群列表中不显示已移除的集群，表示关联集群移除成功。

### 命名空间管理

#### 创建命名空间

**前提条件**

已创建舰队，具体请参考创建舰队。

**背景信息**

在 Kubernetes 集群中，您可使用Namespaces（命名空间）功能创建多个虚拟的空间，在集群用户数量较多时，多个命名空间可以有效划分工作区间，将集群资源划分为多个用途。

**操作步骤**

1. 登录分布式云容器平台 ACK One控制台。
2. 在左侧导航栏，选择**舰队列表**。
3. 在舰队列表中，单击目标舰队ID或**操作**列的**详情**。
4. 在左侧导航栏，单击**命名空间**。
5. 在**命名空间**页面，单击**创建命名空间**。
6. 在**创建命名空间**对话框中，输入命名空间的名称以及标签，然后单击**确定**。

| 配置项 | 说明 |
|---|---|
| 名称 | 您需要设置命名空间的名称。长度为 1-63 个字符，只能包含数字、字母和“-”，且首尾只能是字母或数字。 |
| 标签 | 您可为命名空间添加多个标签。标签用于标识该命名空间的特点，如标识该命名空间用于测试环境。 您可输入变量名称和变量值，单击右侧的添加，为命名空间新增一个标签。 |

#### 修改命名空间标签

### 多集群应用管理

#### 创建多集群应用

**背景信息**

多集群应用可以简化多集群应用编排（ArgoCD ApplicationSet），通过单一应用编排并根据您的编排内容自动生成一个或多个应用。

**前提条件**

已创建舰队，具体请参考创建舰队。

**操作步骤**

1. 登录分布式云容器平台 ACK One控制台。
2. 在左侧导航栏，选择**舰队列表**。
3. 在舰队列表中，单击目标舰队ID或**操作**列的**详情**。
4. 在左侧导航栏，单击**多集群应用**。
5. 在**多集群应用**页面，单击**创建多集群应用**。
6. 在**创建多集群应用**面板中，配置以下参数然后单击**确定**。

| 参数 | 说明 |
|---|---|
| 多集群应用名称 | 应用程序的名称。 |
| chart名称 | Helm Chart 的名称，用于定义要部署的应用模板。 |
| chart地址 | Helm Chart Repository 地址（格式为 HTTP/HTTPS 前缀的 URL）或者 OCI 镜像仓库地址（比如 ACR 高级版，格式为镜像仓库地址/命名空间）。 目前仅支持公有仓库。 |
| 版本 | 指定使用的Chart版本号。 |
| 目标集群 | 应用程序部署的目标集群。 |
| 命名空间 | 应用部署集群内所在命名空间。 |

#### 查看多集群应用

本文介绍如何查看舰队下的多集群应用信息。

**操作步骤**

1. 登录分布式云容器平台 ACK One控制台。
2. 在左侧导航栏，选择**舰队列表**。
3. 在舰队列表中，单击目标舰队ID或**操作**列的**详情**。
4. 在左侧导航栏，单击**多集群应用**。
5. （可选）在**多集群应用**页面，可通过输入多集群应用名称快速筛选应用。
6. 在多集群应用列表中，可查看应用的**名称**、**类型**、**状态**、**Application**、**命名空间**、**创建时间**等。

**说明**

单击**Application**列的数字，可查看多集群应用创建出来的Application概要信息。 单击**操作**列的**查看****Yaml**，可查看多集群应用（ArgoCD ApplicationSet 资源）的 YAML 信息。
