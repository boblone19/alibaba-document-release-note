## Agent Dev用户指南

### 产品简介

百炼OpenTrek Dev产品定义、产品优势、产品架构说明

**产品定义**

百炼OpenTrek Dev作为企业级大模型应用开发管理平台和行业知识加工平台，提供了大模型应用开发、调试、评测、观测、运维、优化全生命周期管理工具链，并提供知识加工检索、工具和MCP服务注册管理、上下文工程和提示词工程等能力支持。

**产品优势**

**多模态知识高效处理**

客户价值高效构建高质量企业知识库，快速搭建RAG问答等AI应用。 能力优势提供了端到端知识解析能力：支持文档/图像/音视频/数据表等全模态数据管理，内置20+深度解析加工模板，覆盖财报/论文/政策/教材等10+类型，可实现文档版面解析、复杂表格解析、公式解析、图片理解，

**全场景智能体搭建支持**

客户价值场景覆盖全面，支持知识问答Agent、工作流Agent、自主规划Agent等类型智能体搭建。 能力优势深度整合RAG知识增强、Workflow自定义编排、ReAct单智能体推理决策多重机制，开发者可根据场景需求灵活切换工作模式，满足从基础问答到群体智能的多层次开发需求。

**MCP与工具生态开放**

客户价值支持客户高效集成多样化工具，提升开发灵活性和安全性，简化接入流程，降低集成成本，加速业务创新与响应。 能力优势支持API工具的异步调用和鉴权信息动态传入，适配多场景类型工具接入；支持SSE/STDIO双模式注册 MCP服务，支持安全沙箱独立运行，灵活支持不同接入方式，保障安全性和稳定响应；API一键封装 MCP，实现跨协议兼容，降低集成成本。

**精细化记忆管理机制**

客户价值基于短期记忆管理能力有效解决智能体任务长上下文管理问题，基于长期记忆管理能力实现智能体任务的个性化处理，使智能体越用越好用。 能力优势短期记忆管理支持历史对话轮数设置、长上下文压缩、重要实体抽取、自定义记忆读写。长期记忆支持重点问答、用户画像、任务地图，同时支持自定义记忆生成策略、整理策略、召回策略。

**产品架构**

智能体工厂 OpenTrek 户指南随着大模型成熟和产业落地加速，大模型应用开发正成为驱动千行百业智能化转型的新质生产力。然而在应用落地过程中，开发者面临全生命周期管理复杂、工具链割裂、评测体系缺失等核心痛点——从上下文工程的设计优化、知识系统的动态更新，到多工具协同的工作流编排、复杂场景的持续观测运维，每个环节都存在技术门槛高、试错成本大的挑战。传统开发模式更面临多模态数据处理能力不足等掣肘，严重制约大模型应用的规模化落地。 为了应对这一趋势，我们围绕大模型应用在企业级场景中的全生命周期管理和基础能力支持，构建了百炼 OpenTrek Dev大模型应用开发平台和数据知识加工平台，旨在为企业提供从数据加工到应用开发的一体化解决方案，助力AI技术真正实现产业落地。 平台作为企业级大模型应用生产平台，提供了专业领域的知识加工、智能体搭建、评测、观测、运维等一站式服务工具链。

通过配置智能合并、自动清除、冲突处理等整理策略，实现对常驻记忆、检索记忆和用户记忆的自动化管理，提升记忆体运营效率。本文介绍如何配置记忆体的整理策略。

OpenTrek Agent Dev控制台支持数据标注验收任务的完整操作流程，包括单个任务验收、整体验收及结果修改等关键操作，帮助用户高效完成数据标注质量控制工作。

**操作步骤**

1. 登录Agent Dev控制台。
2. 在左侧导航栏中选择**数据** > **数据标注**。
3. 选择**验收任务**页签。
4. 单击操作列**验收**。
5. 单击**通过并进入下一张**或**不通过**，直到最后一条验收任务完成。

**说明**

支持整体验收，单击页面右上角**整体驳回**或**整体通过**。 如果子任务“验收通过”，则此子任务中未验收的数据默认状态为验收正确。 如果子任务“整体驳回”，则此子任务会重新进入标注阶段，且未验收的数据默认状态为验收不正确。
6. 最后一条验收任务单击**修改验收结果**，可重新验收。
7. 单击操作列**详情**可查看详细信息。

**常用函数说明**

**get(object,key)**

此函数用于解析object类型的数据，选择指定的object中某一个key的值。 此函数需要配置“object”和“key”两个配置项属性： object配置项，配置需要被此函数解析的数据（支持引用、常量、函数）。此处输入或引用的数据必须保证为object类型，否则解析会报错。 key配置项，配置上一条配置的object数据中，需要被解析出来的key。 例如，object={"name":"张三","id"="123"}，key="id"，则此函数解析出来的值为“123”。

**get(list,index)**

此函数用于解析List类型的数据，指定List中具体某一条数据为输入参数。 此函数支持“list”和“index”两个配置项属性。 list配置项，配置需要被此函数解析的数据（支持引用、常量、函数）。此处输入或引用的数据必须保证为list类型，否则解析会报错。 index配置项，配置上一条配置的list数据中，需要被解析出的数据位次。
