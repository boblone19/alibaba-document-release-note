## CloudMonitor

This topic describes the overview of CloudMonitor and the features provided by CloudMonitor.

**Overview**

CloudMonitor provides an out-of-the-box, all-in-one, and enterprise-class monitoring solution that monitors resources in Apsara Stack. CloudMonitor provides a variety of features, including cloud service monitoring, host monitoring, alerting, statistical analysis, event monitoring, application group management, report export, namespace management, service availability monitoring, custom dashboards, event center, and log monitoring. You can use CloudMonitor to monitor the events and custom metrics of various cloud services, such as Elastic Compute Service (ECS), Server Load Balancer (SLB), Object Storage Service (OSS), and Simple Log Service (SLS). CloudMonitor helps you monitor resources in a comprehensive and efficient manner. It not only improves the availability of system services but also reduces the O&M costs of IT infrastructure.

### Architecture

r CloudMonitor has the following modules: alert center, cloud service monitoring, visualized analysis, alert service, monitoring governance, and access center. The following figure shows the architecture. Description: Alert center: In the entire monitoring business architecture, the alert center acts as a unified alerting platform for tenant-side operations. It provides features such as alert overview, alert list, alert settings, alert notifications, and alert suppression. Cloud resource monitoring: You can monitor the instances of cloud services based on various metrics. CloudMonitor allows you to view details about the metrics of cloud services in the console. Visualized analysis: You can customize dashboards across organizations and resource sets. CloudMonitor provides dashboards for cloud services such as Object Storage Service (OSS), ApsaraDB RDS, and ApsaraDB for Redis. The dashboards help you analyze hot and abnormal instances. You can also track data changes and consume data based on reports. Alert service: You can configure alert rules that are triggered by metrics and system events for cloud service instances. CloudMonitor provides single-metric rules, multi-metric rules, alert templates, and proactive alerting. Monitoring governance: CloudMonitor provides metric validity check, alert validity check, data reporting check, Elastic Compute Service (ECS) collection plug-in, metric namespace, and lifecycle management. Access center: CloudMonitor provides custom data integration for logs, metrics, and events.

### Benefits

This topic describes the benefits of CloudMonitor. CloudMonitor is easy to use. No additional activation or purchase is required. After you purchase and use cloud resources, you can directly access cloud service monitoring to view the status of the resources. You can enable alerting for all resources to quickly configure alert rules for cloud services and quickly build a basic monitoring system without any barriers.
