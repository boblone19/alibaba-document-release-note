# Apsara Uni-manager Operations Console Product Introduction 20260703

Apsara Uni-manager Operations Console ails

## Product details

Apsara Uni-manager provides a unified operations portal with general O&M capabilities, such as monitoring and alerting, inspection management, and resource management, alongsode dedicated O&M consoles for computing, networking, and storage. The platform reduces O&M costs for your cloud environment and ensures its secure and stable operation.

**Monitor&Alert**

Cloud platform O&M is carried out through the following modules: Monitor Management, Alert Management, Event Center, Inspections, Diagnosis Center, and Self Healing.

**Platform Operation**

Cloud platform basic O&M is performed through the following modules: Apsara Infrastructure Management, Capacity, Log Center, O&M Services, Disaster recovery management, O&M Change, Reports Center, Task Center, and Management and Control Service O&M.

**Product Operation**

Modules such as Computing, Networking, Storage, Databases, Middleware, and Big Data are integrated through standardized access methods to assist O&M personnel in performing in-depth product O&M.

**Security Management**

Secure and compliant management of O&M operations are carried out through the following modules: Security Audit, Security Operations, Host Security, Network Security, Account Security, Access Control, Security Compliance Center, and Data Security.

**System Config**

You can configure the system through Personalized configuration, Document Management, Card management, Authorization information, Notification Management, Region coordinate management, Third-party Authentication, and Platform Backup Management.

**User Authorities**

A redesigned ASO permission system implements a separation of duties for platform operations through hierarchical role management. This includes managing users, user groups, roles, departments, menus, and more. Apsara Uni-manager Operations e Console

## Product value

Apsara Stack O&M Platform automates operational workflows to provide proactive monitoring and alerting, root cause analysis, and automated fault remediation. This reduces operational costs and ensures the security and stability of your cloud environment.

**Unified portal**

Unifies monitoring and alerting across products. Unifies capacity monitoring and management across products. Provides a single entry point to the O&M consoles for compute, network, and storage.

**Flexible permissions**

Provides multiple built-in roles, including System Management, Security Management, Security Auditing, Role Management, and Authorized Administrator, that are ready to use out of the box. Allows you to create a custom role and define fine-grained permissions for the ASO console, product consoles, and menus. Enforces separation of duties for platform operations through hierarchical role management.

**Intelligent analysis**

Synchronizes global data in real time for unified resource scheduling. Monitors and analyzes resource usage trends to optimize resource allocation and utilization.

**Open integration**

Provides a visual API portal that simplifies and accelerates development. Provides standard northbound APIs and multi-language SDKs. Supports page-level integration and custom configurations for fast integration with thirdparty systems.

**Centralized operations**

Provides comprehensive, centralized monitoring of resources, inventory levels, and alerts to track operational status and identify potential risks. Automatically updates the resource dependency topology in real time. Its built-in algorithm engine then identifies probable root causes, narrowing the scope of investigation and accelerating fault isolation. Lets you encapsulate atomic operational scripts and perform visual orchestration. The platform also provides automated remediation for various failure scenarios, reducing manual intervention. Dynamically analyzes and automatically calculates optimal scale-out strategies to optimize cloud costs and minimize resource waste. Apsara Uni-manager Operations Console

## Use cases

**Routine O&M**

The O&M workbench provides operations staff with a centralized view of risk data, pending items, and tasks that require attention and provides quick access to frequently used tools, improving operational efficiency. alert management aggregates alerts from all modules on the cloud platform by receiving actively reported alerts or by matching monitoring data against alert rules, helping you efficiently locate and resolve faults to ensure service availability. Inspection management enables quick health checks for various scenarios to maintain your system and cloud product integrity. The diagnosis center, which includes product diagnosis and hardware diagnosis, provides a clear overview of your Apsara Stack platform's health. It helps operations staff quickly detect and isolate cloud platform issues through topology visualization, status checks, root cause analysis, and fault troubleshooting. The event center is a unified event management platform for Apsara Stack that centrally manages and prioritizes alerts from both **cloud infrastructure and applications**. By layering, aggregating, and classifying various types of alerts, it reduces alert noise and consolidates alerts into actionable events that require manual intervention, significantly improving O&M efficiency for the Apsara Stack platform. capacity management analyzes usage data and patterns to forecast capacity trends for your products, helping you plan for scaling and other operations.

**Automated O&M**

The platform provides one-click scaling. The entire scaling process is fully automated, integrating server provisioning, network expansion, and cloud product deployment. You can define custom pre-checks and post-checks to reduce change complexity and improve O&M efficiency. O&M service provides a unified entry point for common change operations, including orchestration-based automated services and hyperlink-guided services. The Service Catalog acts as a centralized portal for recommended O&M activities, integrating automated workflow entry points and frequently used change services. By using a graphical orchestration framework, you can import templates to quickly update local O&M services, improving the efficiency of automated O&M.

**Security O&M**

security audit allows you to query activity logs for user operations from the console or CLI. security policy allows you to configure security policies for platform accounts and passwords. The platform supports two-factor authentication (2FA). When users log in, they must enter both a password and a dynamic verification code generated by an authenticator app. This dual-verification mechanism effectively prevents account compromise.

**Remote O&M**

remote O&M: Tongque uses a dual-center O&M model that combines remote and local operations. This model enables the sharing of core resources and capabilities, allowing a remote center to uniformly manage and collaboratively support local sites. Incident response: During a major failure, the platform provides graceful service degradation, diagnostics, and contingency plans. This improves your response to critical incidents. Apsara Uni-manager Operations Console fault drill: This feature provides practical drill plans based on your platform's business architecture and incident response system. These drills identify stability weaknesses, help refine response procedures, and improve business continuity.
