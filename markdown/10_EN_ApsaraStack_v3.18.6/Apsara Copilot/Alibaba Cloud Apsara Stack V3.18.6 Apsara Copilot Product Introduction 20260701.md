## Product details

This topic introduces Apsara Copilot. Apsara Copilot is an intelligent cloud assistant powered by AI technologies, such as large models and agents. It helps you use cloud products and services efficiently through natural language interaction. Apsara Copilot transforms Apsara Stack management from manual processes to an AI-driven management model. Unified AI assistant: The tenant console features a single entry point for the AI assistant, named Apsara Copilot by default. This ensures a consistent user experience. Multi-agent collaboration: It uses a multi-agent architecture and intent recognition to call the most suitable agent. Cloud products can be extended with dedicated agents or tools as plug-ins, which allows for decoupled upgrades. Full product line coverage: It supports the integration of AI capabilities into the consoles of core cloud products in the Enterprise Edition. Apsara Copilot Product Introducti

## Product value

This topic describes the product value of Apsara Assistant.

**Lowers the barrier to using the cloud**

Apsara Assistant makes the cloud more accessible for non-technical users and new developers. It parses user intents through natural language interaction and automatically generates operational instructions. This reduces dependency on complex console operations and API documentation, improving usability.

**Improves operational efficiency**

Apsara Assistant quickly understands user questions and fetches accurate information from large volumes of documents, knowledge bases, and systems. This reduces manual seek time. With its natural language understanding and context memory capabilities, Apsara Assistant provides a consistent and personalized service.

**Drives an artificial intelligence management model**

Apsara Assistant creates a "Conversation as a Service" interaction model. This makes the cloud platform function more like an intelligent partner than a system of tools. It also lays the foundation for future autonomous and intelligent management. Apsara Copilot Product Introducti

## Scenarios

This topic describes the common scenarios for Apsara Assistant.

**Product knowledge Q&A**

Apsara Assistant provides accurate answers and guidance on questions about cloud product recommendations, feature operations, usage limits, and best practices.
**Usage help**: Generates operational instructions for products based on Apsara Stack user
manuals and best practice guides.
**Product help**: Recommends cloud products and instance types as needed. It also provides
direct links to the relevant product console pages.

**Operational data analytics**

Apsara Assistant processes operational data by converting natural language input into SQL queries. It then dynamically generates charts from the query results and provides analysis and optimization suggestions for resource utilization, health status, and billing costs.
**Chart-based Q&A**: Uses intent recognition on natural language input to automatically
generate SQL. The query results are then dynamically displayed in charts and lists.
**Custom reports**: You can use natural language input in the data analytics interface to
create interactive visual charts. You can perform multi-dimensional statistical and summary analysis through natural language conversations to automatically generate reports and charts.

**Assisted resource management**

Apsara Assistant supports intelligent retrieval of resources and their linked resources. It provides recommendations for resource specifications based on the scenario and assists with resource provisioning.
**Resource retrieval**: You can quickly query information about cloud resources by asking
questions or selecting text on a page. This feature also supports topology analysis of linked resources.
**Instance type selection**: Based on your application requirements, Apsara Assistant
intelligently recommends the optimal ECS instance type to balance performance and cost. It also provides a link to the instance creation page.

**OpenAPI code generation**

For developer scenarios, Apsara Assistant automatically generates sample code for calling cloud product OpenAPI and Terraform code for your reference.
**API code generation**: Generates sample code for calling a cloud product's OpenAPI. The
code is tailored to specific developer scenarios.
**One-click code debugging**: For the generated OpenAPI sample code, you can click the
debug link to go directly to the online API debugging page in the developer portal and quickly test the code.
