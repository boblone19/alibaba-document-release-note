## What is SOAR?

Based on years of experience in defending against cyberattacks, the Alibaba Cloud security team has developed Security Orchestration Automation Response (SOAR). This service can process a large amount of attack alert data and other data at a faster speed than manual processing, and identify key events that require attention for further tracking and handling.

**Background information**

To handle security events, the security operations analysis team needs to process the alert data generated by security devices and manually filter the alert data to identify attacks. When a large amount of alert data is generated, the security operations analysis team cannot manually distinguish between true and false alerts in a timely manner to effectively filter and process the alert data. This creates opportunities for attackers to penetrate the internal networks of enterprises. SOAR is seamlessly integrated with various security components in the cloud security protection system. The security operations analysis team can use SOAR to automatically process a large amount of alert data generated by security devices on enterprise networks. This service greatly shortens the response time of security events, improves the efficiency of event handling, and ensures the secure operations of the digital economy. Event investigation SOAR automates security event operations and streamlines event handling processes to improve the response speed. This frees security experts from the heavy workload of daily security operations and enables them to focus on the security events that require attention. SOAR also allows enterprises to convert the accumulated experience in security operations into interpretable and executable playbooks, which can be used as best practices for event handling. Playbooks SOAR is applicable to various processes during security operations, including event investigation, detection, response, tracing, and experience accumulation. You can use playbooks to implement processes such as information-rich survey and coordinated handling for security events. This reduces repetitive operations and improves the average response time of security events. You can use scheduled playbooks to configure periodic inspection tasks. You can also use manually triggered playbooks to manually run specific tasks. Components SOAR can coordinate with various security components in the cloud, and use API operations to call the security capabilities of various security services such as Cloud Firewall, Network Detection and Response (NDR), Web Application Firewall (WAF), Server Guard, and local threat intelligence to conduct investigation, analysis, and handling. This enables effective collaboration between people and tools and between tools to connect all security devices as a whole. Knowledge base management SOAR allows you to store the text and data records generated during alert event investigation in knowledge bases. You can also reference the stored knowledge in playbooks to implement features such as eliminating known false alerts and filtering data based on the whitelist or blacklist. Intelligence management Security Orchestration Automatio n and Response (SOAR) Product I SOAR allows you to manage threat intelligence. During the response to and investigation of alert events, you can query threat intelligence to enrich indicators of compromise (IOCs) in security events. In addition, the malicious indicators blocked by SOAR can also be used as threat intelligence for continuous monitoring and sharing. Security Orchestration Automatio n and Response (SOAR) Product I

**Case management**

Case management is a core module of SOAR. Cases can be generated by using streaming playbooks, scheduled playbooks, and manually triggered playbooks. You can view a variety of data associated within a case. The joint operations room is used by security analysts to investigate and block alerts and malicious behavior in cases. Security analysts can use the robot assistant to run various commands in the joint operations room to investigate and respond to attacks and malicious indicators for which alerts are generated. All operations are recorded in the joint operations room to facilitate the review of security events.

**Knowledge bases**

knowledge bases store the experience accumulated by security analysts during event handling. Security analysts store the features of attack behavior detected in the joint operations room in knowledge bases. This way, the accumulated event handling experience can be reused to handle subsequent security events.

**Intelligence management**

SOAR implements the closed-loop management of threat intelligence. Security analysts can use threat intelligence to query suspicious indicators and add malicious indicators to threat intelligence for continuous tracking. They can also block and unblock indicators at any time. SOAR also pushes threat intelligence to the security devices of Web Application Firewall (WAF) and Network Detection and Response (NDR). If an attack occurs, threat intelligence can be used to block malicious indicators throughout a network at the earliest opportunity.

**Orchestration engine**

Security Orchestration Automatio n and Response (SOAR) Product I SOAR supports visualized security orchestration based on standard process specifications. You can perform drag-and-drop operations to configure custom playbooks that meet your business requirements. You can also use extensive built-in playbooks to automate daily alert handling and coordinated blocking operations.

**Security components**

As the units in which commands are run, security components include various security resources of Apsara Stack Security and the operations that can be performed by using these security resources. For example, you can use NDR to detect network threats and block attacks. After you define actions in playbooks, SOAR issues commands to security components to perform the defined actions and obtains the results.

## Common scenarios

This topic describes the common scenarios of Security Orchestration Automation Response (SOAR). In emergency situations involving cyberattacks, SOAR can quickly deploy defense policies. For example, SOAR can automatically block malicious IP addresses or domain names to mitigate the impact of attacks. During daily security monitoring, SOAR enables automated monitoring and analyzes abnormal behavior to help the security operations team identify potential threats in advance and prevent security events. When multiple departments need to collaboratively handle security events, the global collaboration feature of SOAR ensures information sharing and coordinates multiple resources to respond quickly. To process complex threat intelligence, SOAR integrates intelligence management tools to accumulate security protection knowledge. After a security event occurs, the knowledge management system of SOAR provides historical data support for security operations and accelerates the event analysis and handling process. ## Terms

**component**

A playbook is an organic combination of components with processing logic. A component consists of **assets** and **actions**. An independent component represents one or more independent executable features. Assets provide the execution capability, and actions specify specific features. For example, a cyberattack blocking component uses Cloud Firewall to block cyberattacks by performing access control.

**asset**

Assets are security resources that can be scheduled on the cloud. For example, an enterprise may have multiple firewall systems. Different firewalls are created for different tenants. Based on firewall resources, alert information can be obtained, configured security policies can be queried, and new blocking policies can be issued during the handling of security events. SOAR can obtain your security resources in the cloud and allow cloud tenants to call these cloud resources to perform **actions**.

**action**

An action is a **capability** provided by an asset. Each asset can have multiple capabilities. For example, Network Detection and Response (NDR) supports the following actions: alert query, Layer 4 blocking, and Layer 7 blocking. After you select an action, SOAR calls an API operation or a feature of the corresponding security resource to perform the action.
